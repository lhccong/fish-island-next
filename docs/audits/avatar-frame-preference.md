# 在线成员头像与隐藏头像框偏好验收

日期：2026-11-15。依据 ADR-070；Windows、Chrome、Vite 开发模式，合成账号、历史消息、图片和在线成员。

## 行为

- 在线成员面板复用 `MemberAvatar showFrame={false}`，桌面和手机均只显示原头像；左侧聊天列表沿用相同规则。
- 群聊详情 → 消息显示设置，在“显示消息头像”下面新增“隐藏头像框”共享 Switch。默认关闭；开启后保留头像、隐藏消息及复读参与者的头像框，不改变账号穿戴。
- 偏好由 `ChatPreferencesPort` 和 localStorage 保存，刷新恢复；与头像显隐、图片懒加载独立。保存失败仍在当前页面生效并提示原因。
- Virtuoso context 传递呈现值，消息实体、历史分页、草稿与连接均不重置；切换主题/明暗不新增请求或重连。不增加业务通信或依赖。

## 验证范围

注册主题：像素小岛、WPS、微信、企业微信、飞书、钉钉；明亮/暗夜；桌面 1280×844、手机 375×844、390×844。

最终两组浏览器回归共 72 项通过。人工检查桌面与手机代表截图，确认新开关位置、文字、选中状态和在线成员原头像。

`online-member-avatars.spec.ts` 覆盖加载图标与文字、读取失败重试、空名单、成功、原头像保留、无头像框、搜索无结果与恢复、关闭、内部无横向溢出，以及聊天消息框不受影响。

`chat-frame-preference.spec.ts` 覆盖开关默认值、手机点按、隐藏/恢复消息及复读头像框、保留原头像、与头像显隐独立、刷新恢复、外观切换保留草稿和连接、存储失败反馈及关闭。额外点击“查看最新消息”确保断言检查实际进入虚拟列表可视区的行；手机浮层期间通过 includeHidden 检查保留的草稿和消息，不把读屏隔离误判为业务状态丢失。

单测覆盖本机头像框偏好缺省、独立保存与重建端口恢复。`npm run check` 的格式、Lint、类型及 384 项单测通过；单测退出阶段出现 worker 终止超时警告。构建因并发任务占用共享 `dist/assets` 返回 EPERM，随后使用本次独立临时输出目录的生产构建通过。

未验证真实手机硬件、Safari/Firefox、真实后端联调及长期聊天性能预算。本次未改变业务接口，不执行真实账号操作。
