# 音乐分享与今日推荐验收

日期：2026-11-18。基线提交：`41ae61b`，验证对象为本次工作区改动。环境：Windows 11 专业版、Intel i7-12700K、Chromium 158.0.8127.18、Vite 生产构建。浏览器使用合成登录、聊天和可播放 WAV，不向真实聊天室发送消息。

## 行为与实现

- 搜索结果、手动待播队列增加分享入口，当前歌曲保留“发送到聊天”。直接进入既有消息发送链路，保留聊天草稿；提交提示不冒充最终发送成功，失败在聊天中重试。
- 入口统一为“今日推荐”。未搜索、未点歌时即可获取新歌曲并直接播放，按服务端顺序续播；手动待播优先，推荐候选耗尽后按需请求下一批。不打乱已有歌单，也不以关键词搜索代替推荐。
- 后端音乐代理新增 `/api/third-party/music/recommendations?source=netease|tencent`，参考 fishmusic 的固定 Meting `type=fm` 协议。返回最多 20 首去重歌曲元数据，不返回上游音频地址、身份信息或密钥。关闭推荐、停止、换来源、切号和卸载按各自作用域取消请求，失败显式重试。
- 弹窗固定搜索栏和播放器，歌曲列表独立 reserved 滚动；分享与点歌同行对齐。手机音量另起一行，短视口紧凑重排；来源名称完整显示，移除按钮至少 44×44px，当前歌曲长元数据限制两行。使用既有语义变量、共享控件和主题，无新增依赖。
