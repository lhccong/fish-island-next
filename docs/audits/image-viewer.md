# 图片查看器验收

日期：2026-11-13。对应 ADR-046。

## 范围

聊天消息图片与鱼小圈动态/评论媒体组改为共享 ImageViewer：顶部操作栏、居中画布、图片计数、前后切图、按需缩略图、缩放、1:1、适应窗口、旋转、拖动、双指及滚轮缩放、原图新标签页、Esc 与关闭后焦点归还。手机工具栏分两行，图标触控区域至少 44px。

聊天只在打开时读取当前内存消息中的非撤回图片快照，重复 URL 合并，不请求其他历史。图片查看不订阅整个消息流，不改变消息、账号草稿和连接。浏览器保存原图由“打开原图”后的浏览器提供；无置顶、最小化、OCR、编辑等桌面微信专属入口。

## 验证结果

- `npm run check` 通过：格式、ESLint、TypeScript、58 个测试文件共 242 个单元测试及生产构建；保留既有人生重开大资源块的体积提示。
- 独立生产构建，Windows Chromium，合成账号、图片、消息与接口响应。`tests/e2e/image-viewer.spec.ts` 覆盖注册表全部 5 个主题（WPS、微信、企业微信、飞书、钉钉）× 明亮/暗夜 × 桌面 1280×720、375×812、390×844，共 60 个场景。首轮 59 通过，WPS 明亮 390px 在等待原图 popup 时超时；未改实现，单独复测该场景通过。
- 验证加载中、成功、图片错误及重试、按钮禁用、缩放/原始比例/适应/旋转、长图鼠标与模拟触屏拖动、首末图片边界、缩略图选择及内部无横向溢出、方向键切图、关闭与焦点归还、草稿保留、不新增连接或历史请求。
- `tests/e2e/image-viewer-gestures.spec.ts` 在上述三个视口的微信暗夜模式通过 3 个专项测试，验证滚轮或双指缩放、键盘缩放/复位及焦点返回。
- 已查看桌面明亮、375px 明亮、390px 暗夜的实际截图，确认画布比例、长图居中、手机工具栏分行及原图颜色保留。截图及测试追踪提取结论后清理，未作为正式交付物保留。

## 限制

未使用真实账号或真实聊天记录；未验证真机、Safari/Firefox、第三方图床有效性。双指缩放专项仅在微信暗夜下操作，其他主题复用同一交互实现；未单独验证预览打开期间的主题切换、零图片集合的共享空状态、超长缩略图列表的完整滚动流程，以及所有按钮每种悬停/聚焦状态的逐项截图。当前产品入口在零图片时不提供预览按钮。上述未验项不作为已完成实测范围。

本次独立验证使用的 `test-results-image-viewer-task*` 精确命名目录、`node_modules/.cache/image-viewer-task-dist` 与临时 Playwright 配置在任务结束前删除；其他任务已有的测试目录不在清理范围。
