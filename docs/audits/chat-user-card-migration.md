# 聊天用户卡片迁移验收

日期：2026-11-15。决策：[ADR-069](../decisions/ADR-069-chat-user-card.md)。

## 已实现

- 聊天消息名称、聊天列表成员名称和群成员名称统一打开用户卡片；保留原消息菜单的备注入口。
- 按需读取资料、查询关注状态、关注/取消关注、编辑备注、账号隔离的本机黑名单。
- 管理员复制 ID、读取禁言状态、选择时长、确认禁言与解除禁言；错误可恢复，等待期间防止重复提交。
- 宠物弹窗、所选用户的农场与动态入口；嵌套弹窗和卡片关闭后恢复焦点，原入口因屏蔽消失时回退到聊天输入框。
- 桌面资料/封面双栏、手机单栏；固定标题与操作区、reserved 正文滚动、语义配色与移动端触控尺寸。

旧版封禁账号和修改积分没有实际接口，仅显示模拟成功，未迁移。公开资料接口未返回的积分、地区等字段显示“未提供”，不伪造在线状态或活跃时间。

浏览器使用本机 Microsoft Edge / Chromium，开发服务与合成接口数据，覆盖全部注册主题：WPS、微信、企业微信、飞书、钉钉；每个主题均覆盖明亮/暗夜、1280×720 桌面、375×812 与 390×844 手机视口。

## 后续比例与数量修正（2026-11-15）

按旧摸鱼岛参考收紧桌面卡片至 680px 宽、至多 560px 高：左侧 220px 资料列（包含规范 gutter），右侧封面铺满剩余区域并独立于资料滚动；标题保留可访问语义但不占可见大标题区域，移除默认 ID 和空简介辅助行，收紧资料字号与行距，宠物/农场/动态采用 44px 图标入口。手机将封面重排为 140px 高的顶部封面带，资料独立滚动。

仅管理员可见的操作区默认收起，首次展开才请求禁言状态，收起后保留时长、请求与操作状态。关注/粉丝数量缺失的原因是后端 JsonConfig 将 Long 序列化成字符串；适配层现兼容安全非负整数字符串，保留 0，不将缺失/空值/无效值伪装成 0。关注成功后的粉丝数同步更新。

本轮 `npm run check` 全部通过（362 项单元测试）；卡片核心流程及管理员流程共 60 项浏览器用例全部通过，覆盖上述全部 5 个主题 × 明暗模式 × 桌面/375px/390px。新增布局断言验证 680px 桌面宽度、右栏占比超过 60%、封面与正文等高且以 cover 铺满、手机封面带尺寸、数量解码、普通用户无管理员入口、默认折叠、首次加载与收起重开不重复请求。截图和追踪在提取结论后清理。

### 右栏宽度校准

最新宽度校准：桌面右栏由 420px 扩至 452px，移除两栏额外间距与封面右侧内缩，680px 弹窗中的封面占比约 66.5%；左侧 212px 列保留完整 reserved gutter，页脚操作仍预留 16px。手机不改变原有边距和封面带结构。本轮 `npm run check` 通过，全部 5 个主题 × 明暗 × 桌面/375px/390px 的 30 项卡片流程通过；断言额外确认右栏至少 450px、占比超过 66%、右缘贴合弹窗。截图与临时报告已在提取结论后清理。

### 无封面名片优化

无封面时使用 420px 紧凑卡片并随内容决定高度，加载、空资料、错误也共用该布局；长内容及展开管理面板采用按可用视口封顶的 reserved ScrollArea，正文可滚动且操作栏保持独立。有封面时仍保留 680px 双栏与 452px 封面。统计改为相邻的两列，资料移除铺满的灰色底板、标签和值明确对齐，宠物/农场/动态补充可见文字；手机保留原有边距与 44px 控件。

本轮 `npm run check`（362 项单测）与 60 项浏览器用例通过，覆盖全部注册主题 × 明暗 × 桌面/375px/390px，包含长内容/短资料、请求失败恢复、关注/备注/黑名单、管理面板展开收起、触屏滚动、末项及页脚无大块空白、关闭焦点和草稿保留。已检查紧凑卡片及手机截图；截图、报告和追踪提取结论后清理。
