# 你画我猜迁移验收（ADR-066）

入口：发现 → 游戏 → 你画我猜；最近玩过；独立窗口；`/game/draw`、`/game/draw/:roomId`。旧版路由保持兼容，移除此前误指向谁是卧底的跳转。

## 范围

- 真实旧 HTTP 协议：房间列表/详情、创建/加入/退出/管理员移除、开始/轮换/结束、保存 PNG、猜词及历史记录。
- 默认/王者荣耀/成语词库、2～20 人、1～20 轮、房主绘画/轮换模式。
- 固定坐标画布，Pointer Events 支持鼠标、触屏；画笔、橡皮、颜色、粗细、最多十步撤销、清空。编辑保留在本地画布，绘画者点击「保存」才提交当前快照，同一时间最多一个保存请求。失败可用同一按钮重试，保存期间新增的笔迹留待下次提交。未保存时禁用下一轮和结束，退出有丢失提示。
- 复用唯一账号 WebSocket；房间事件按 ID 过滤，动态按稳定身份合并并最多保留 100 条。重新连接或返回可见页面时读快照，不轮询；切换主题/模式不重取数据、不重连、不重置画作和草稿。
- 进行中的房间可通过既有猜词接口发言。绘画者、已猜中和画作上传前使用聊天文案；其他玩家看到猜词输入。发言成功即在自己的聊天室显示，失败保留输入。颜料提供 18 种预设及十六进制自定义色。
- 绘画、房间读取、消息和猜词草稿各自拥有状态；源码层级及入口遵守架构规范。页面/窗口通过 app 注入同一端口。

## 界面

桌面左栏的工具、本轮信息与操作在画布上方，右栏从上到下为玩家分数、聊天与猜词记录。手机先显示本轮操作、工具与画布，随后显示聊天与猜词记录，末尾为玩家分数。聊天与猜词记录共用面板，分别保留滚动区，保存位于画布下方。画纸和颜料为作品素材，界面使用当前主题语义变量，暗夜基础背景沿用 #191A1C。

创建表单及记录使用 shared/ui/ScrollArea reserved 留白；Select/Button/Slider/Dialog 复用共享控件。手机触控目标至少 44px、保留安全区与滚动，只有绘画中的 canvas 使用 touch-action:none，手机滑轨隐藏由共享规范实现。

## 验证方法

- 端口单元测试：房间/图片解码、异常数值/状态/重复玩家、鉴权/过期/未确认失败、旧 URL/JSON 协议、消息包装、实时过滤与取消订阅。
- Playwright：摸鱼岛、摸鱼岛像素风、WPS 表格、微信绿、企业微信、飞书蓝、钉钉蓝，明亮/暗夜，1440×900、375×900、390×900。Microsoft Edge Chromium 无头运行，使用合成账号和数据。
- `draw.spec.ts`：加载、空列表、房间失败/重试、创建失败/重试、开局、鼠标和触屏绘画、绘画/撤销/清空不上传、手动保存失败/重试、单请求在途、保存中继续绘画、换肤保留未保存的画作和猜词草稿、下一轮、猜词、记录滚动、结束、退出及无横向溢出。
- `draw-navigation.spec.ts`：目录/最近玩过、加入、路由、小窗绘画、收起和恢复未保存的画作、手动保存、关闭、reserved gutter、内部滚动及失效房间。
- 发布构建命令：`npx vite build --mode development --outDir test-results-draw-20261114/build`（构建优化开启，使用开发 API 地址配置；请求全部由合成服务拦截）。设置 `DRAW_PREVIEW_DIR=test-results-draw-20261114/build` 后运行 `npx playwright test --config playwright.draw.config.ts`。未设置该变量时专用配置使用开发服务器。

## 限制

真实服务的双账号多人联机、真实计时结束、网络断线重连和真实移动设备软键盘尚未联调。房间同步使用手动保存的完整 PNG。房间动态保留当前挂载期间的内容。刷新、退出或关闭窗口后，房间只提供服务端已保存的画作。正式结果记录在任务交付说明。验收后清理测试截图、追踪、构建和临时目录。
