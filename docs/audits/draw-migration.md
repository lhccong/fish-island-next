# 你画我猜迁移验收（ADR-066）

入口：发现 → 游戏 → 你画我猜；最近玩过；独立窗口；`/game/draw`、`/game/draw/:roomId`。旧版路由保持兼容，移除此前误指向谁是卧底的跳转。

## 范围

- 真实旧 HTTP 协议：房间列表/详情、创建/加入/退出/管理员移除、开始/轮换/结束、保存 PNG、猜词及历史记录。
- 默认/王者荣耀/成语词库、2～20 人、1～20 轮、房主绘画/轮换模式。
- 固定坐标画布，Pointer Events 支持鼠标、触屏；画笔、橡皮、颜色、粗细、最多十步撤销、清空。落笔后 600ms 合并保存，串行请求；失败保留本地画作，明确手动重试，未同步时禁用下一轮和结束，退出有丢失提示。
- 复用唯一账号 WebSocket；房间事件按 ID 过滤，动态按稳定身份合并并最多保留 100 条。重新连接或返回可见页面时读快照，不轮询；切换主题/模式不重取数据、不重连、不重置画作和草稿。
- 绘画、房间读取、消息和猜词草稿各自拥有状态；源码层级及入口遵守架构规范。页面/窗口通过 app 注入同一端口。

## 界面

桌面以画布为重点，右侧玩家、猜词与房间动态分区；窄容器及手机纵向重排。主操作在画布前，画纸/颜料为作品固定素材，界面使用当前主题语义变量；暗夜基础背景沿用 #191A1C。原生 select/color 弹窗、浏览器确认、第二套 UI 和样式框架均未引入。

创建表单及记录使用 shared/ui/ScrollArea reserved 留白；Select/Button/Slider/Dialog 复用共享控件。手机触控目标至少 44px、保留安全区与滚动，只有绘画中的 canvas 使用 touch-action:none，手机滑轨隐藏由共享规范实现。

## 验证方法

- 端口单元测试：房间/图片解码、异常数值/状态/重复玩家、鉴权/过期/未确认失败、旧 URL/JSON 协议、消息包装、实时过滤与取消订阅。
- Playwright：五套注册主题 WPS 表格、微信绿、企业微信、飞书蓝、钉钉蓝；light/dark；1440×900、375×900、390×900。Microsoft Edge Chromium 无头运行，合成账号/数据，不使用真实聊天记录或凭证。
- `draw.spec.ts`：显式控制 loading → empty → HTTP 503 → 重试；创建失败/重试；Select 长列表键盘和 Esc 返回焦点；开局、鼠标/实际 CDP 触屏绘画、保存失败/重试、单请求在途、撤销/清空、换肤保留画作/草稿/请求数/连接数、跨房间过滤/重复动态、下一轮、猜词失败留草稿/成功计分、记录实际滚动、桌面滑轨显示/手机隐藏、结束/退出及无横向溢出。
- `draw-navigation.spec.ts`：目录/最近玩过、加入、路由、窗口绘画/收起/恢复草稿/关闭、reserved gutter、内部滚动及失效房间。
- 发布构建命令：`npx vite build --mode development --outDir test-results-draw-20261114/build`（构建优化开启，使用开发 API 地址配置；请求全部由合成服务拦截）。设置 `DRAW_PREVIEW_DIR=test-results-draw-20261114/build` 后运行 `npx playwright test --config playwright.draw.config.ts`。未设置该变量时专用配置使用开发服务器。

## 限制

真实服务的双账号多人联机、真实计时结束、网络断线重连和真实移动设备软键盘尚未联调。整幅 PNG 在落笔后同步，不宣称逐点实时广播；房间动态仅保留当前挂载期间内容，不宣称服务端历史聊天能力。退出房间/关闭窗口前应等待同步完成。正式结果记录在任务交付说明；测试截图、追踪、构建和临时目录按本次清单清理，不作为交付物。
