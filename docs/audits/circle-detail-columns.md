# 详情分栏、评论内滚动与回复表单

日期：2026-11-12。生产构建预览、Playwright Chromium、合成账号与接口响应。

设计：详情主内容区域达到 960px 时左右分栏，左侧正文、媒体、定位与点赞，右侧评论；低于阈值上下排列。复用同一业务组件，通过 CSS container query 响应可用空间，不根据主题或视口重挂载。

评论列表复用 ScrollArea reserved gutter，桌面限高 min(600px, 65dvh)，手机限高 min(420px, 55dvh)，短列表自然收紧；输入时进一步收短列表，为回复区留出空间。评论标题、输入、上传、发送和反馈位于列表滚动区外。桌面滑轨可见，手机仅隐藏滑轨。

回复表单使用独立样式模块与共享 Button：回复对象、实际点击评论的摘要、取消、输入和发送分区；取消回复保留草稿并回到普通评论。打开回复时确保整个表单可见并聚焦输入；列表收短后保持所回复评论可见。子回复展示实际子评论摘要，提交仍使用根评论编号与被回复者编号，保留原接口关系。

验证入口：`npx playwright test --config playwright.circle-detail-layout.config.ts`。全部 WPS 表格、微信绿、企业微信、飞书蓝、钉钉蓝 × 明亮/暗夜 × 桌面 1920×1080、手机 375×812、390×844，共 30 个场景；每个桌面场景额外调整到 1280×800 与 1024×800，检查分栏/堆叠、草稿保留及请求不增加。

结果：最终版本 30 个场景全部通过；`npm run check` 通过（含 125 项单元测试及生产构建）。构建仍有项目原有的大体积 chunk 提示。

验证内容：

- loading / error / empty / success，包括详情失败重试和评论失败重试。
- 左右边界、窄屏上下顺序、内部无横向溢出、评论高度上限、24px/20px 固定 gutter。
- 评论定位在内层视口滚动、高亮、聚焦；宽屏左侧正文不被带走；桌面滚轮/主动显示滑轨，手机实际触屏滚动/隐藏滑轨。
- 回复对象与子评论摘要正确，取消保留草稿；按钮桌面 32px/手机 44px，文案自然宽度；表单独立间距、输入与发送可达。
- 添加/移除评论图片、发送失败保留输入、重试成功、根评论/被回复者编号正确，以及返回焦点恢复。
- 保存评论加载、失败、成功分栏、回复、窄桌面和空状态截图到 `test-results-circle-detail-layout/`，人工查看桌面及手机明暗截图。

未验证：真实后端、实体手机软键盘/安全区域、Safari 与 Firefox。旧通知协议缺少独立评论编号的限制沿用 ADR-022。
