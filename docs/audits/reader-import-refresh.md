# 阅读默认配置与导入弹窗复核

日期：2026-11-12。对应 ADR-028。

## 配置与真实联调

用户明确要求复用旧版阅读服务配置；已从旧项目 constants 的 ACCESS_TOKEN 复制至 `src/app/config/reader-service.ts`，由 app 注入控制器。搜索、目录、正文共用同一 accessToken；会话覆盖只存内存，清空覆盖恢复默认，不写入书架或输出配置值。测试构建使用合成配置替换，真实值不进入测试请求记录。

真实服务验证：使用“剑来”检索，首批返回 38 个结果；选中书籍的目录返回 1310 章，正文请求成功。另在真实浏览器中完成搜索、加入书架、打开阅读器，得到 52 个正文段落。只记录鉴权和数量，不记录凭证或完整请求 URL；该结果仅代表本次选中书源，不保证所有第三方书源持续可用。

## 对照旧版与修复

| 问题/旧版行为                                   | 本次处理                                                                                |
| ----------------------------------------------- | --------------------------------------------------------------------------------------- |
| 默认搜索未传旧版所需 accessToken                | app/config 提供默认值，统一注入三个 reader3 端点；刷新继续可用                          |
| Portal 外祖先 `.workspace input` 无法命中搜索框 | OnlineSearch 自有输入样式，搜索图标、统一高度、圆角、背景、占位和单一 focus-within 提示 |
| 空内容固定占用 430px，弹窗大面积空白            | 初始/空/加载使用紧凑说明区，错误使用独立反馈卡片，只有有结果时开启列表滚动              |
| 旧版多书源结果与封面                            | 封面/失败占位、书名、作者、书源标识和添加状态；保留无封面但可读的书源                   |
| 分类、字数及简介查看                            | 补充分类、字数、最新章节；简介按纯文本呈现并提供键盘/触屏展开，不依赖桌面 hover         |
| 分页失败后继续                                  | 提交成功后才更新页码/游标；失败保留已有结果并重试同页，流式部分返回也不跳过数据         |
| 添加后重复导入                                  | 原位显示“已在书架”并禁用重复添加，跨页按书源/书籍身份去重                               |
| 本地 TXT 错误和弹窗关闭                         | 导入错误留在弹窗内；清除上次错误后可重新导入；上方关闭及底部导入/关闭均可触达           |
| 导入后原空书架入口卸载，焦点无法返回            | 关闭后统一返回始终存在的“添加书籍”按钮                                                  |

未复制旧 Ant Design/axios 和手写菜单，保留分层、统一 Button/Dialog/ScrollArea，未增加依赖。新增样式均使用语义 token，覆盖全部主题与明暗模式。

## 验证入口

最终 `npm run check` 通过：格式、lint、类型检查、101 项单元测试和生产构建均通过。阅读相关浏览器流程覆盖 76 项（包含修复后的复跑）；补齐结果信息后，又按完整主题/模式/视口矩阵复核 30 项导入流程及 3 项阅读重载流程。移动端桌面文档画中画 20 项按设计跳过。加载态测试改为控制响应完成时机，避免快响应使 loading 瞬间消失而造成误报。结果与简介的键盘展开、无封面回退、长内容换行、分页部分失败重试均通过。

- `reader-import.spec.ts`：WPS、微信、企业微信、飞书、钉钉 × 明暗 × 桌面/375px/390px，覆盖 Portal 输入样式、初始/loading/empty/error/success、长标题和书源换行、滚动、分页失败重试、添加状态、TXT 错误、触屏关闭和焦点返回。
- `reader.spec.ts`：同一完整矩阵验证搜索/目录/正文均携带合成默认 accessToken，并回归阅读进度、换肤、刷新恢复与删除。
- `reader-settings.spec.ts`：会话覆盖不落盘、刷新恢复项目默认值；`reader-pip.spec.ts` 回归真实桌面 Chromium 文档画中画。
- 单元测试覆盖默认注入、覆盖与清空恢复；生产构建使用独立 `node_modules/.cache/reader-dist`，避免开发热更新干扰。
- 本地真实效果截图位于 `node_modules/.cache/reader-refresh/`；矩阵截图保存在 `matrix-final/`，后续 Playwright 产物写入独立的 `node_modules/.cache/reader-test-results/`，避免与并行任务清理同一个 `test-results` 目录。

未验证：物理手机软键盘、Safari/Firefox、其他第三方书源和系统真实发声；手机使用 Chromium 移动设备视口与点击流程验证，画中画仅在桌面浏览器验证。额外的原生 tap 文件选择补测因浏览器会话启动未完成而停止，不作为通过证据。
