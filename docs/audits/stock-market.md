# 摸鱼股市迁移与 Web 概览验收

日期：2026-11-13。环境：Windows、Chromium，Vite 开发服务；接口使用合成账号及合成数据，不执行真实账号积分交易。

## 实现范围

- 游戏目录增加摸鱼股市入口和最近玩过记录，鉴权路由 `/game/stock/:indexCode?`。
- Web 概览铺满现有工作台内容区，移除 1200px 最大宽度；四项资产卡片、市场行情/我的持仓/交易记录页签，桌面三列指数卡片，375/390px 手机单列。
- 点击指数卡片后才进入 K 线详情；首页不请求 K 线或交易历史。返回保留概览页签，交易历史首次打开加载、滚动续载并保持分页状态。
- 日 K、B/S 同日聚合与逐笔详情、积分买入/份额卖出、持仓、交易记录；复用共享 Button、Select、Slider、Dialog、ScrollArea、InfiniteScroll。
- 五个指数分别处理行情失效，0 点占位显示不可用而不清空其他有效指数；持仓兼容后端遗漏冻结份额。今日盈亏按当前持仓市值和实时指数日涨跌估算，缺少资料显示“—”，不将持仓收益率当作当日涨幅。
- 后端补充鉴权日 K 与当前账号范围成交标记接口，公共行情缓存与私有标记分离；不修改既有积分交易和结算规则。

主题：微信、企业微信、飞书、钉钉、WPS 全部注册主题。模式：明亮、暗夜。视口：1920×950 桌面、375×950 与390×950 手机；长弹窗补测 1440×900，触屏使用375/390×844并缩小至500px高度模拟输入空间收缩。

- 30 组概览及详情：断言桌面三列且第三张卡片右边缘到视口不足80px，手机纵向单列、页面无横向溢出；概览不提前取 K 线，详情 B/S 查看、滑动历史、买入失败/重试、卖出、返回来源页签、持仓及行情失败/空数据、单指数无效不影响其余卡片。
- 全主题×双模式×三视口长成交详情：50条记录，顶部/底部可达、实际键盘滚动、保留滑轨间距、手机隐藏滑轨、Select 展开与 Esc 关闭、焦点返回、共享按钮桌面32px/手机44px。
- 全主题×双模式×375/390触屏：实际触摸点按、通过 CDP 原始 touchStart/touchMove/touchEnd 验证正文滚动，首末项可达；缩短视口后输入与取消入口可达。
- 全主题×双模式×三视口页签键盘：方向键/Home/End、来源页签恢复、手机顶部返回股市、主题切换不请求 K 线或清空分页。
- 滚动分页：第二页失败后保留内容，显式重试、按稳定 ID 去重、空页停止；兼容 React 开发 StrictMode 首次请求取消后的重建。
