# 在线成员实时同步验收

日期：2026-11-17。对应 ADR-095；基线 `922335d` 加当前工作区变更，保留原有未提交工作。

## 范围与结果

复用账号 WebSocket 的 `userOnline` / `userOffline`，连接首个合法上线帧作为全量校准，其余按 ID 增删。HTTP 请求期间重放增量，全量推送取消旧 HTTP；登出清理。成员 Provider 只传稳定控制器，详情、经典侧栏、聊天列表和 @ 候选分别订阅；工作区和消息 store 不订阅成员变化。没有修改外观样式、增加依赖、轮询或连接。

环境：Windows，Node v25.8.1，Playwright 1.65.0，Chromium 158.0.8127.18；Vite 开发服务器，全部账号、成员和通知均为合成夹具。

`chat-presence.spec.ts` 共 42 个矩阵用例通过，覆盖：

- loading、HTTP 失败及重试、empty、success；每组均截图并断言页面及成员区域无横向溢出。
- 上线添加、重复上线去重、资料更新、下线移除、重复下线、人数更新；新成员追加时保留成员区滚动位置。
- 桌面滚轮、手机原生触屏滑动，滚动后末项可达，桌面显示滑轨、手机隐藏滑轨。
- 详情关闭与入口焦点返回、关闭期间继续同步、重连全量名单替换旧成员、草稿保留。
- @ 候选随上线/下线变化；手机及 WPS 聊天列表弹窗同步增删和触屏关闭。
- 桌面实际切换主题及模式期间持续接收通知，不新增 HTTP 请求或连接，不清空草稿。
- 对全部 42 组 success 截图进行了拼图视觉核对，并检查摸鱼岛桌面经典侧栏；loading/empty/error 每组均自动断言，另抽查摸鱼岛三个视口的截图。

单元测试覆盖非法帧、每次重连首帧、HTTP 增量竞态及迟到成功/失败、账号重置取消、单请求在途、去重与消息 store 订阅隔离。`npm run check` 通过（112 个测试文件、487 个测试，包含本次测试），格式、lint、类型检查与生产构建均通过。

## 限制与观察

- 未进行线上真实多账号联调、真机软键盘、Safari/Firefox 或 30 分钟性能实测；手机使用 Chromium 触屏模拟。手机分别验证了两种模式，实际主题/模式切换流程在桌面执行。
- 开发服务器出现 `ResizeObserver loop completed with undelivered notifications` 提示；42 个最终用例全部通过，本任务未定位该提示根因。构建仍有大分块与 MomentEditor 动静态混用提示。
- 初轮测试遇到高速合成滑动的浏览器惯性吞点击，以及本机并发启动超时；改为缓慢滑动并停留、两工作进程及 120 秒用例预算后完整重跑通过，未改产品触摸或滚动行为。
