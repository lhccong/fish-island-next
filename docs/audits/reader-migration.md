# 阅读迁移与验收

后续修订：默认阅读服务配置和导入界面已按用户要求更新，当前行为及新增联调结果见 [导入弹窗复核](./reader-import-refresh.md)。下文为首次迁移记录。

日期：2026-11-12。架构依据：ADR-025。旧版参照：fish-island-frontend 的 Reader、GlobalFloatingReader 和 globalReader 模型。仅迁移协议与功能，未引入 Ant Design、axios、旧模型或旧项目内置凭证。

## 修复与边界

- 取消过期请求，切书/关窗后旧响应不能覆盖当前状态；更换外观不加载章节。
- 第 0 章和 0 滚动位置均正确保存；延迟滚动保存不会覆盖其他章节。
- 页内与画中画共用业务和 DOM；关闭画中画、切换外壳后继续使用当前章节。
- 生产构建的画中画同步复制已加载 CSS 规则，避免仅克隆样式链接导致新窗口首次出现无样式内容；跨源样式使用绝对链接回退。
- 修复本地 TXT 的宿主尚未进入文档时恢复滚动失败；避免搜索/朗读定位滚动整个固定窗口，导致标题被遮挡。
- 隐藏后恢复不重复打开最初的目录；画中画异步打开期间关闭阅读器，不留下孤立窗口。
- 存储读取损坏时保留原记录，展示读取错误；写入失败明确提示当前更改仅在内存中，不伪报持久化成功。
- 所有选择器使用 shared/ui/Select，确认使用 Dialog，文件入口使用 Button；不复制旧版手写 DOM 菜单。工具栏提供原右键菜单的上一章、下一章、目录、穿透、刷新和关闭操作。

## 验证范围与方法

主题注册表：WPS 表格、微信绿、企业微信、飞书蓝、钉钉蓝。每个主题覆盖明亮与暗夜模式，视口为桌面 1280×720、375×812 和 390×844；手机采用 Chromium 触屏模拟。

`npm run check` 覆盖格式、lint、TypeScript、单元测试和生产构建。`npx playwright test --config=playwright.reader.config.ts` 从合成账号的朋友圈实际发现入口验证阅读，并回归发现游戏导航。配置将生产快照构建到 `node_modules/.cache/reader-dist`，使用独立 4185 端口并禁止复用已有服务，避免旧 preview 或开发热重载干扰业务状态验证。

阅读浏览器流程覆盖搜索与目录/正文的 loading / empty / error / success、失败重试、去重、目录分卷跳转、设置与统一选择器、触屏关闭、焦点返回、章节搜索、隐藏恢复、主题切换不重取内容、刷新恢复和删除。另验证 TXT 导入与跨路由进度、自定义主题、凭证不落盘、朗读控制和清理、桌面拖动/全屏。真实桌面 Chromium 的文档画中画按全部主题及明暗验证切章、关闭返回和设置返回主窗口；移动项目有意不执行桌面文档画中画测试，另验证不支持时的说明。

验证结果：`npm run check` 通过，92 项单元测试通过。隔离生产快照的 54 项书架/阅读/设置/发现导航流程通过；首次生产测试发现画中画样式链接问题，修复后 10 项真实画中画流程复跑全部通过，累计 64 项浏览器覆盖通过。20 项手机项目下的桌面画中画用例按设计跳过，手机使用页内阅读并验证不支持提示。

30 组主题/模式/视口阅读截图与相关状态截图已保存于 `node_modules/.cache/reader-verification/`，总览为 `reading-contact-sheet.png`，均为合成数据；最后一次画中画复跑报告位于 `test-results/`。生产构建阅读逻辑为按需加载独立资源，不加入热榜首次访问的同步业务代码。阅读逻辑块约 14.6 KiB gzip；现有人生重开数据块体积提示不属于阅读新增依赖。

未验证：真实阅读服务凭证与书源可用性、物理手机和软键盘、Safari/Firefox、操作系统实际发声和窗口置顶表现。朗读测试使用可控语音适配模拟，不将此结果当作真实音频验收；画中画验证真实浏览器 API 和窗口生命周期。移动端保留完整页内阅读能力，不承诺浏览器不提供的文档画中画能力。

API 参考：[Chrome Document Picture-in-Picture](https://developer.chrome.com/docs/web-platform/document-picture-in-picture/)。
