# 聊天 SVG 称号验收

日期：2026-11-14。

## 资源与呈现

旧版公开称号目录、titleUtils 和 titles.less 为兼容依据；27 个自有 SVG 位于 `public/assets/chat-titles`。在 Chromium 中读取旧版 CSS 渲染尺寸、字体、字距、渐变和阴影，与 SVG 并排检查水群达人、摆烂大师、摸鱼铲屎官、电玩少女及首席摸鱼官。恢复白字、自然宽度、原始高度、渐变范围和光晕，移除初稿的 104×22px 拉伸及黑色文字。

SVG 使用原生文字、图形、渐变和滤镜，不包含脚本、位图或 foreignObject。主要渐变流动、扫光和专属光晕呼吸由 SVG/CSS 动画提供，专属光晕沿用旧版对应 keyframes 的颜色、透明度、模糊半径与周期；减少动态效果时使用静态渐变和滤镜，不增加 JS 定时器。字体及 Emoji 仍由设备字体栈渲染，未保证不同操作系统逐像素一致；装饰细节未做全部动画逐帧像素比对。图片称号继续使用原始 HTTPS PNG/JPG，未将位图包装成 SVG 冒充矢量化。

## 验证范围

生产构建，Chrome Chromium，合成账号和消息数据。浏览器覆盖 WPS 表格、微信绿、企业微信、飞书蓝、钉钉蓝 × 明亮/暗夜 × 桌面 1280×720、手机 375×812、390×844，共 30 个场景。检查初始空消息、SVG、图片待加载/成功/失败、未知称号、秒级时间、稳定图片占位、元信息换行及无横向溢出；手机触屏打开消息菜单并 Esc 关闭。切换主题和模式保留草稿，连接与历史请求数量保持不变。

另在三个视口验证 SVG 光晕实际变化、减少动态效果后的动画停用与静态渐变回退，共 33 项浏览器测试。单元测试验证全部本地 SVG 和等级映射、公开 HTTPS 目录、安全回退及原版尺寸。最终执行 `npm run check`。未验证真实手机硬件、Safari、所有字体环境、服务端真实账号消息及长期性能预算；浏览器合成图片用于成功/失败控制，不能代表所有远程图片的视觉人工验收。

## 最终检查结果

33 项浏览器场景均通过（图片预留尺寸断言改为比较宽高，避免将虚拟列表正常锚点校正误判为图片尺寸变化；修正后重跑该场景通过）。264 项单元测试、ESLint、TypeScript 与生产构建通过，本次文件的格式检查通过。最终 `npm run check` 在格式阶段被并行农场模块的 `src/domain/farm/index.ts`、`src/infrastructure/farm/decode.ts`、`src/infrastructure/farm/index.ts` 阻塞；未修改这些无关源码。
