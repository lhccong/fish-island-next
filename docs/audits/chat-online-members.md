# 群聊与在线成员验证

日期：2026-11-12。实现依据：ADR-030。环境：Windows、Playwright Chromium 158、Vite 开发服务；构建由 npm run check 单独验证。数据全部为合成用户，不含真实账号、凭证或聊天记录。

## 界面与接口范围

`/chat` 使用微信式群聊布局，右上角三个点展开右侧在线列表；手机显示独立详情区并隐藏底层聊天控件，页头、关闭与刷新始终可达。在线列表按首次展开请求，支持姓名搜索、手动刷新、错误重试、破图占位和空状态。数量仅表示接口返回的在线用户，不代表群成员总数；没有模拟消息、机器人或强行补入当前账号。

客户端调用既有 `GET /api/chat/online/user`，使用当前账号 Sa-Token，并支持取消、超时与过期处理。消息、建群接口、邀请、发送和群设置均未接入；输入仅保存当前页面草稿。

## 微信式成员区限高调整

按补充截图，桌面与手机均采用四列、默认最多四行（16 位成员）和“查看更多/收起成员”入口。默认头像网格高度桌面 254px、手机 292px；展开后最高 304px 且不超过 40dvh，全部成员在独立 ScrollArea 中滚动，群聊说明紧随其后。搜索会覆盖完整在线列表，少量结果按内容收缩，不受默认 16 人限制；展开、收起和搜索不产生额外接口请求。

本轮浏览器流程增加默认行数/高度、键盘展开与收起、展开区高度和内部无横向溢出、末项可见断言，继续覆盖全部主题 × 明暗 × 桌面/375px/390px 的 loading/empty/error/success。截图目录为 `test-results-chat-height`，新增 `online-collapsed.png`，已检查微信桌面与 375px 的收起状态截图。

本轮 `npm run check` 完整通过（110 项单元测试）。聊天异步 JS 约 9.40kB（gzip 3.53kB），构建仍保留既有人生重开分块警告。

后续修复“查看更多”挤压：收起与展开共用同样的尾端空白，取消外层和内层重复 reserved；信息正文与滑轨保持间距，内外滑轨相隔 12px。浏览器增加首行四列在展开、收起前后的 x 坐标、列宽与头像宽高完全一致的断言。复验命令：`npx playwright test --config=playwright.chat.config.ts tests/e2e/chat-online.spec.ts --workers=3 --output=test-results-chat-height-stable --reporter=line`。对应截图目录为 `test-results-chat-height-stable`，已对照检查微信桌面的展开/收起截图。

本次修复后 `npm run check` 完整通过（114 项单元测试）；聊天异步 JS 约 9.80kB（gzip 3.59kB）。首轮 WPS 暗夜桌面用例的首次页面导航耗时约 25.4 秒，整个流程超过原 30 秒预算，布局断言未失败；该多状态流程的总预算调整至 60 秒，单次交互断言保持原时限。

## 本地群名与微信式会话栏

本轮按后续要求增加本地群聊名称编辑，提供取消、空值/长度校验、保存失败与成功提示；去除首尾空白，允许 1–30 个 Unicode 字符。本地写入成功才同步更新标题、空消息区、左侧群聊和详情，刷新后恢复；不修改服务器群名或其他成员的显示。编辑区不依赖成员请求成功，加载/失败/空列表时仍可修改；输入法 Enter 不触发发送，Escape 取消编辑并归还焦点。

左侧改为微信式搜索栏与会话行，桌面聊天侧栏由 228px 增至 300px（含 WPS），背景和分隔线铺满，行内固定保留 24px 防止内容贴轨。真实获取的用户一人一行，40px 方形头像、昵称、灰色“暂无消息”及列表成功获取时间；不显示在线标题、人数或在线状态，不伪造聊天、未读或历史时间。手机使用页头图标打开“聊天列表” Dialog，仍可搜索、刷新、滚动和关闭。两个列表共用账号作用域 ChatMembersProvider，一次请求，关闭或换肤不重复请求；账号变化释放旧请求。收起/展开成员只是展示已获取数组，不属于服务端分页或“加载更多”分页按钮。

`npm run check` 在本轮主体变更完成后完整通过，包含 120 项单元测试与生产构建。全部注册主题（微信、企业微信、飞书、钉钉、WPS）× 明暗 × 1280px 桌面/375px/390px 的群名与列表流程共 60 项浏览器测试通过，覆盖持久化、存储拒绝、输入保留、空值/长度、长名称不溢出、同一请求共享、列表搜索、loading/error/empty/success、滑轨间距、触屏弹层关闭与焦点返回。截图位于 `test-results-chat-preferences-list`，已检查微信桌面列表、375px 名称保存失败、390px 暗夜聊天列表截图。

搜索框焦点随后统一为圆角外层 `focus-within`，内部 input 不叠加矩形焦点框；成员头像使用 ID/地址作为身份，地址改变可恢复破图占位。该修正使用发布版进行完整列表及登录/WPS 回归，结果另记。

上述列表修正已纳入后续群名/列表复验，覆盖登录进入聊天、刷新恢复与 WPS 外壳；独立的完整认证套件未在本轮重跑。

## 最终工作伪装呈现

按用户进一步明确的伪装要求，摘要替换为按成员 ID 稳定分配的本地工作短句，穿插服务号、公众号、项目协作群、技术评审群与服务通知；虚构条目不进入接口结果或真实成员计数，不提供入群、关注或私聊动作。提醒红点同样为本地视觉标记，没有未读数量或已读协议。昵称和长摘要单行省略，title 提供全文及本地伪装说明。真假呈现项使用不同 key 前缀，搜索同时覆盖二者；筛选、换肤不改变工作短句和红点。
