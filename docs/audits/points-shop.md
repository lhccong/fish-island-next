# 积分商城迁移验收

日期：2026-11-15。对应 ADR-071，工作区未提交变更。

## 交付范围

发现菜单提供积分商城 `/utils/avatar-frames`；旧 `/avatarFrames` 自动跳转。头像框兑换、穿戴与移除复用 auth，用积分兑换月卡、查看积分流水及会员说明由独立商城模块实现。未知道具类型不可兑换，图片缺失/失败有回退。

兑换确认防重复提交；服务器确认后单独读取账号，读取失败显示「兑换已成功」并锁定继续兑换，提供同步积分操作，切换分类仍保留该状态。账号变化取消请求；换肤/模式切换不清空确认或触发列表请求。

## 环境与方法

- Windows，本机 Chrome 157.0.8103.51，Vite 开发服务；另执行生产构建。
- 微信、企业微信、飞书、钉钉、WPS，明亮及暗夜模式。
- 功能用例：1280×800、375×844、390×844；滚动用例：1280×844、375×844、390×844。
- `points-shop.spec.ts` 覆盖加载、空、读取失败、兑换失败重试、成功及成功后同步失败恢复、积分记录、分页失败重试、重复 ID 合并、结束、旧地址及换肤保持状态。
- `points-shop-scroll.spec.ts` 使用桌面滚轮与 CDP 触屏滑动，断言真实滚动位置变化、手机 44px 操作、滑轨显隐、reserved gutter、首末操作可达及无横向溢出。
- 复查桌面与手机明暗截图的标题、分类、卡片及底部反馈；截图/追踪为临时产物，提取结论后清理。
- 协议测试覆盖旧 frameId、道具类型、价格/流水校验、ID 精度、鉴权和服务器未确认成功；账号测试验证静默刷新及退出后旧响应隔离。

## 结果与限制

最终 60 项浏览器用例通过（5.4 分钟），覆盖上述全部主题、模式与视口；30 项功能流程与 30 项真实滚动流程均通过。最终 `npm run check` 的格式、ESLint、TypeScript、93 个文件/369 项单元测试和生产构建均通过。并发任务繁忙时既有人生模拟用例曾超时，限制两个 worker 的复跑与最终默认并发检查均通过。

全部接口测试使用合成账号及拦截响应；未对真实账号消费积分，线上道具配置与真实服务兑换尚待使用环境验证。没有测量聊天吞吐、内存或输入延迟，不作相关性能结论。构建保留既有大 chunk 提示。

## 字符串分页总数修复回归

用户反馈头像框「列表格式异常」及道具「商城积分数据异常」。根因是后端 JsonConfig 将 Long 分页 total 序列化为字符串，最初夹具误用 number，未覆盖线上协议。修复头像框和商城分页的 total 规范化，保持价格/流水积分及超精度数据的严格校验。

已只读请求线上公开道具接口并通过实际解码，确认 total 为 string、解码后为安全 number，商品条目可读取；没有携带账号凭证或进行真实兑换。头像框、道具和积分记录的浏览器夹具均改用字符串 total；五种主题 × 明暗 × 桌面/375/390 的 30 项功能回归通过，协议回归 8 项通过。头像框和积分流水的真实账号请求仍未验证。

本次 `npm run check` 的格式、ESLint、TypeScript 通过，全量单测为 370 项通过、1 项失败：既有 `src/domain/life/simulation.test.ts` 的完整 ID 遍历超出 5000ms，阻断后续构建。受控并发复跑出现 worker 退出超时；浏览器 30 项均输出通过后也未正常退出，已结束本次验证进程并清理临时产物。上述全仓及进程收尾限制不能记为通过。
