# 聊天图片显示偏好验收

日期：2026-11-13。实现决策见 ADR-035 的图片按需显示补充。

## 范围与行为

- 群聊详情的“显示消息头像”下增加“默认不渲染图片”，初始关闭，偏好保存到当前浏览器。
- 开启后正文图片与图片表情不挂载 img，不发起图片请求；每张图片通过共享按钮主动加载，沿用加载、失败与重试反馈。
- 纯图片消息无气泡底板、图片框无底色和边框；竖图接收侧与名称左对齐，本人消息靠右。含文字或引用的消息保留文字气泡。
- 图片加载完成后按原图比例收紧容器，限制在原 214×160.5 的显示范围内，消除横图上下空白和竖图左右空白；未知尺寸时保留加载占位，已知尺寸的重试不重置比例。
- 虚拟列表卸载后单张展开状态不保留，浏览器保存的是默认显示策略；不改动草稿、消息与连接状态。

## 验证方法

使用 Windows 上 Playwright Chromium 开发服务器与合成 HTTP/WebSocket 数据，运行 `npx playwright test --config playwright.chat-image-preference.config.ts`。

覆盖注册表全部五个主题：WPS、微信、企业微信、飞书、钉钉；各主题明亮/暗夜模式，桌面 1280×720、手机模拟 375×812 与 390×844，共 30 个组合。

每个组合检查默认值、空消息与空成员状态下的设置入口、键盘或触屏切换、图片请求阻断、图文保留、逐张显示、加载中、失败重试、关闭恢复自动加载、重新开启折叠、刷新持久化、保存失败提示。断言纯图片背景透明、无边框/气泡内边距、左右对齐、手机按钮触控高度、消息区及页面无横向溢出；切换主题和模式保留草稿、消息、图片偏好，连接/历史及图片请求数量保持不变。

生成各组合设置、占位、失败、透明图片截图并抽查桌面和手机的明暗呈现；临时截图与测试追踪在验收后清理。
