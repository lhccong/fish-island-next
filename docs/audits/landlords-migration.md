# 斗地主迁移与验收

日期：2026-11-14。架构决策：[ADR-067](../decisions/ADR-067-landlords.md)。

## 迁移范围

- 游戏目录、最近玩过、独立窗口及 `/game/landlords/:roomId?` 鉴权路由。
- 经典房间快照、创建、按房号/列表加入、密码输入、限制房间返回、离房确认。
- 准备、房主开始、服务端叫分选项、底牌、点选手牌、出牌、不出、托管、倒计时、结算。
- 独立聊天草稿与有界记录；失败保留输入，服务端确认后才清空。
- Top 50 真实排行榜与八种既有排序，加载/空/错误/重试；接口为固定快照，无分页协议。
- 复用账号 WebSocket，释放订阅和计时器；不复制旧 Ant Design、全局模型或专用连接。

## 呈现

复用语义颜色和共享 Button、Dialog、Select、reserved ScrollArea。桌面对手横排，自己身份、操作和手牌在同一牌桌内；手机对手压缩为双列，手牌分行、44px 以上点选范围，操作自然换行。未新增依赖。

2026-11-15 样式优化：主题强调底色形成独立牌桌，对手信息改为简洁的座位行；内容宽度达到 960px 时聊天位于右侧，窄窗口及手机保持单列。准备、叫分、托管、不出和出牌集中在手牌操作区，无牌时隐藏无用的选牌按钮；牌面补充角标，选中抬起并描边，尊重减少动态效果偏好。沿用既有间距、圆角和配色 token，不新增状态、请求或依赖。

本次 `npm run check` 通过，355 项单元测试和全部 30 组主题/模式/视口流程通过。补充大厅与选牌聚焦截图，并复查桌面明亮、手机暗夜布局。Edge 在断言全部结束后收尾卡住，仅清理本次工作进程后测试命令以 0 退出，未关闭用户浏览器。真实联机及真机键盘的验证限制保持不变。

## 验证方法

最终结果：`npm run check` 通过（88 个测试文件、355 项单元测试）；30 项浏览器矩阵全部通过，包含滚动区最小预留间距断言与加入失败保留房号。已复查明暗模式桌面与手机截图。

`npm run check` 覆盖格式、依赖方向、类型、单元测试与生产构建。`npx playwright test --config playwright.landlords.config.ts` 使用本地开发构建、Edge 无头浏览器及合成账号/房间协议。

浏览器矩阵：WPS、微信、企业微信、飞书、钉钉 × 明亮/暗夜 × 1440px、375px、390px，共 30 项。覆盖大厅 loading/empty/error/success、准备、叫分、选牌失败重试、出牌、不出、托管、聊天失败与成功、手机触屏滚动、桌面滑轨、结算、离房、排行首末项及选择器键盘/Esc/焦点、按房号加入和目录独立窗口。检查横向溢出、手机牌面尺寸及换肤保留选牌/草稿且不新增请求或连接。

截图、追踪与结果存放在专用系统临时目录，提取结果后删除。其他任务目录及已有 dist 不作为本次临时文件删除。

## 限制

- 未使用真实账号进行三人生产联机、生产断网重连或长时间对局验证；合成协议测试不替代这些验证。
- 手机流程使用带触屏的浏览器仿真；真机软键盘弹出及设备安全区域尚未实测。
- 后端仅对 LANDLORDS_CLASSIC 提供房间实现；不展示旧版无可用实现的癞子模式。
- 不复用旧版近似牌型提示/比较器，完整选牌由既有服务端裁决合法性；自动出牌提示未迁移。
- 部分入房快照只有身份、手牌和底牌，缺少当前回合；下一次服务端回合广播前显示等待同步，不推测谁应出牌。缺少剩余牌数或结算积分时不伪造为零。
