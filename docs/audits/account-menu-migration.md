# 账号下拉菜单迁移

日期：2026-11-14。决策：[ADR-065](../decisions/ADR-065-account-menu.md)。

| 入口              | 实现与边界                                                                           |
| ----------------- | ------------------------------------------------------------------------------------ |
| 修改信息          | 复用现有资料编辑、图片上传、邮箱绑定、称号与会员资料                                 |
| 我的卡片          | 当前账号名片、等级、积分、地区、关注与粉丝；列表使用共享滚动分页                     |

按用户补充要求，老板键和位置重置不迁移。保留“个人资料与签到”入口，不移除此前已接入的签到功能。

## 验证范围

使用本机 Microsoft Edge 的 Playwright 自动化及合成账号、接口夹具。矩阵为微信绿、企业微信、飞书蓝、钉钉蓝、WPS 表格 × 明亮/暗夜 × 1280×800、375×844、390×844。

`npm run check` 通过，85 个测试文件、346 项单元测试通过。菜单矩阵 30 个组合均已取得通过结果：首轮两组企业微信桌面操作超时，隔离复测通过；补充的微信暗夜桌面用例曾出现弹窗定位超时，独立追踪复测通过。构建仍有既有的大分块体积提示，未执行聊天压力与长期运行性能基线。

现有资料编辑回归在微信明亮模式的桌面、375px、390px 通过。手机从总览打开账号入口，并按 ADR-033 验证隐藏滑轨及原有间距；聊天草稿保留由上述菜单矩阵另行覆盖。

验收覆盖菜单、焦点返回、弹窗边界、reserved gutter、手机触摸与桌面滚轮滚动、表单校验与提交、应用 loading/empty/error/success、失败重试、应用编辑与密钥管理、黑名单屏蔽/恢复、草稿保留、工作时间选择器、模式持久化和密码重置退出。实际截图检查了桌面暗夜和 375/390px 手机弹窗的间距、折行、按钮及滚动条隐藏。

真实邮箱投递、生产兑换码消耗、真实第三方应用联调和真机软键盘未执行。工作时间为本机估算，不包含法定节假日调休或跨夜班次。旧全局黑名单不自动归属新账号，原数据保留。

临时测试输出与截图在提取结论后清理；原有 dist 预先备份，验证后恢复，不覆盖其他任务产物。

## 样式整理验收（2026-11-14）

本轮按内容调整弹窗尺寸，重新整理个人名片、验证码行、应用信息与操作、网站设置、名单和引导；账号菜单增加紧凑分组。个人资料头像改为明确的 64px 呈现，普通按钮沿用共享尺寸与主题动作色。应用展开密钥时，面板随内容增高，手机操作以自然文字宽度分两行排布。

Windows / Microsoft Edge 157.0.4341.46，使用合成账号和接口夹具。固定发布构建下，全部五个注册主题 × 明亮/暗夜 × 1280×800、375×844、390×844 共 30 组流程通过。覆盖资料编辑及摘要、名片、名单、找回密码、兑换、应用管理、网站设置、工作时间和引导；实际检查首屏及滚动后截图、手机触摸滚动、桌面滑轨、焦点返回、错误/加载/空数据/成功状态和无横向溢出。中途开发模式复验曾受其他并行开发触发的热更新打断，最终结果以固定发布构建为准。

本轮目标文件的 Prettier 检查通过；独立 Lint、类型检查、350 项单元测试与构建曾通过。最后执行全仓 `npm run check` 时，并行斗地主模块仍有未格式化文件；此前一次复跑还报告该模块 Ranking/RoomChat 的可选 className 类型错误。未修改这些并行变更，因此不将最后统一检查记为通过。

真实生产账号、邮件投递、兑换消耗、真机软键盘与聊天压力测试未执行。本次临时截图、测试结果和固定预览构建在提取结论后清理；仅在本次 dist 未被其他任务更新时恢复原构建目录，否则保留其他任务的最新产物。
