# WPS 聊天工作表验收

日期：2026-11-14。架构决策：ADR-052。

## 呈现与状态

WPS 聊天采用 A/B/C 列、窗口内行号和消息单元格，隐藏左侧会话栏、消息称号及复读参与者的称号提示。桌面移除群聊标题行，表格上方的 ƒx 公式栏直接编辑、发送消息；编辑区高 32px，整行保留 44px 图标入口。发送和详情各占独立列，间隔至少 8px。手机保留返回页头，发送者与时间位于正文上方，输入、更多工具和详情可触屏操作。

同一消息列表、消息行和输入组件通过稳定 key 调整位置；草稿、上传、引用、分页与连接不归外壳管理。主题/模式切换不发起额外历史请求或 WebSocket 连接，不替换当前输入 DOM。未增加依赖、演示数据、公式计算或电子表格编辑能力。

## 验证范围

Windows Chrome Chromium（受干扰项另以 Edge Chromium 复测），生产构建，合成账号、成员和消息；不读取真实聊天。

| 维度     | 覆盖                                                                                       |
| -------- | ------------------------------------------------------------------------------------------ |
| 主题     | WPS 表格、微信绿、企业微信、飞书蓝、钉钉蓝                                                 |
| 模式     | 明亮、暗夜                                                                                 |
| 常规视口 | 桌面 1280×720、手机 375×812、390×844                                                       |
| 补充宽度 | WPS 761、800、1024、1920px，含详情展开后的窄内容区                                         |
| 状态     | 初始加载、空列表、历史失败与重试、正常文本/图片、发送失败与重试、禁用发送                  |
| 操作     | 复制、引用与焦点返回、详情打开/关闭、手机工具展开、图片上传失败/重试、手机换行与长草稿滚动 |
| 历史     | 初始 HTTP 与实时去重、向上连续分页、失败保留已有内容、锚点保持、结束反馈                   |
| 外观切换 | 注册主题和两种模式往返，保留输入 DOM、草稿、消息、请求次数与连接次数                       |

自动断言页面、消息行、输入区无横向溢出；工作表在侧栏隐藏后从 x=0 开始，公式栏位于列头上方，桌面标题行不可见。验证称号在 WPS 中未挂载，其他主题正常呈现；复读合并后 WPS 参与者提示仅显示名称。桌面检查按钮间距和输入宽度，手机覆盖触屏菜单、发送及工具操作。实际截图检查 WPS 明暗模式在桌面及两个手机尺寸的比例、表格对齐、输入高度和按钮分离。

## 检查与边界

分批覆盖的 100 个不同场景均获得通过结果：历史 30、输入与上传 30、工作表矩阵 30、换肤保留 3、桌面临界宽度 1、WPS 导航 6。两个手机项目中的桌面专用间距用例按不适用跳过，手机输入和布局由对应矩阵覆盖。270 项单元测试、TypeScript、生产构建及本次修改文件的 ESLint 通过。

并行验证期间出现截图超时、浏览器上下文关闭超时及测试产物目录被移除的干扰；受影响的功能场景在独立临时输出目录串行复测通过。最后一次额外重复的手机导航复测完成功能操作后，在 context 销毁阶段超过 30 秒；该场景此前通过，此次清理阶段异常仍予记录，终止了该测试进程并清理其专属浏览器。截图改为 CSS 像素尺寸，仅为受影响的 WPS 保存，减少冗余捕获。

最终执行 `npm run check` 在格式阶段被其他并行修改的 `tests/e2e/circle-notification-bulk.spec.ts` 阻塞，未通过全仓组合检查；另一次全仓 ESLint 报告通知模块公开入口的依赖约束错误。本次 WPS 文件单独 ESLint 通过，未调整通知模块的业务和依赖。

浏览器回归入口为 `playwright.wps-chat.config.ts`。换肤测试最初使用默认 role 查询，主题模态窗使背景输入区对辅助技术隐藏，因此误报“未找到草稿”；改为在模态窗期间读取 includeHidden 输入并检查原 DOM 的 isConnected，不改变产品可访问性。默认 Playwright 内置浏览器缺失时使用已安装 Chrome 通道。

未验证真实手机硬件与系统软键盘、Safari、真实服务端账号发送，以及 60 秒消息压力和 30 分钟长期性能预算。触屏操作为 Chromium 手机模拟；本次布局验收不代表完整聊天性能基线。
