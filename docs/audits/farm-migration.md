# 摸鱼农场迁移与连续田垄验收

日期：2026-11-14。架构决策：[ADR-050](../decisions/ADR-050-farm-migration.md)。

## 交付范围

游戏目录新增摸鱼农场和最近玩过入口，鉴权路由 `/game/farm`。适配旧版作物、我的地块、农场资料、可用积分、单块/批量种植、单块/批量浇水、单块/批量收获、按等级和积分解锁、互关好友拜访、单块/批量偷菜、访客记录与全部已读接口。未迁移旧版未实现的商店、仓库、任务及微信邀请占位入口；伙伴入口进入已有伙伴营地。

呈现修订移除白底地块卡片、多重方框和草地网格线。耕地共用连续土壤纹理，外侧绘制田埂；原创像素树丛、木屋和池塘构成场景，锁地融入草地，保留语义按钮与键盘焦点。服务端作物图片与表情保留，图片失败显示原创像素植物。

## 验证方法与范围

- Windows、系统 Chrome、Vite 开发服务器与 Playwright 合成接口；不使用真实聊天、账号或积分数据。
- 微信、企业微信、飞书、钉钉、WPS 全部注册主题 × 明亮/暗夜 × 1440×900、375×900、390×900，验证主农场 loading/empty/error/success、种子目录、播种失败重试、收获、批量浇水、解锁确认、好友拜访和偷菜、返回自己的农场、访客全部已读、空好友列表。
- 独立触屏上下文覆盖五主题 × 双模式 × 375×844、390×844：实际 touchStart/touchMove/touchEnd 滑动、首末种子可达、键盘 Home/End、关闭后焦点归还、末块地详情与禁用状态。单地播种、浇水及冷却、收获、好友读取失败重试、访客已读失败重试另有独立流程。
- 布局断言检查页面和弹窗内部横向溢出、种子目录 reserved gutter、桌面滑轨主动显示、手机滑轨隐藏、按钮 32px/44px 高度、田地透明背景和无卡片边框、44px 以上地块命中区、末块可达。
- 外观切换保留选种和田地状态且不产生农场请求。独立场景和目录测试遍历全矩阵，目录封面文字对比度至少 4.5。
- 实际截图复查微信明暗桌面与手机画面、WPS 手机种子弹窗；截图属于本次验证临时产物，提取结论后清理。

## 检查与限制

`npm run check` 通过：Prettier、ESLint、TypeScript、66 个测试文件/269 项单元测试、生产构建。农场按路由懒加载，像素好友菜单与顶部提示后的独立 FarmPage JS 约 30.6 kB（gzip 10.9 kB）。构建仍提示现有人生重开资源块较大。

浏览器用例入口：`farm.spec.ts`、`farm-touch.spec.ts`、`farm-scene.spec.ts`，位于 `tests/e2e/`。协议测试覆盖长整型编号、种植请求体、批量浇水部分失败、鉴权过期；纯规则测试覆盖成熟边界、冷却、跨日和每日上限。

紧凑呈现与直接收获补充：`farm-compact.spec.ts` 覆盖全部五主题 × 明暗 × 1440/375/390，桌面页头高度不超过 52px、手机不超过 110px，长昵称不挤出刷新按钮，统计与场景无横向溢出，场景桌面宽度不超过 976px、地块高度不超过 98px。375/390 使用触屏上下文，成熟田地点按直接收获，校验请求中禁用、重复点击只产生一次提交、失败后保留作物并可重试、键盘 Enter 重试成功，全程无收获确认弹窗。空地、浇水、锁地和好友操作沿用原流程。截图复查紧凑页头、缩小场景及双模式手机布局。

像素好友菜单与反馈补充：`farm-social.spec.ts` 遍历五主题 × 双模式 × 1440/375/390，检查真实字段头像、缺失与图片失败回退、本人和拜访页头像、等级正反排序、昵称搜索/无匹配、访客切换、列表首末可达、reserved gutter 和无横向溢出。`farm-social-touch.spec.ts` 使用 375/390 触屏上下文覆盖实际滑动、像素 Select 的 Portal 面板与触发器同色同圆角、Esc 关闭与焦点返回、打开弹窗时真实明暗切换保留搜索。桌面/手机微信明暗截图已人工检查木框、羊皮纸、像素头像框、文字及布局。

操作提示改为共享顶部浮层，5 秒后消失；提交/刷新期间不新增正文横幅，断言收获前后田地位置一致，并确认连续操作会重新提示。加载错误仍保留重试入口，表单中的旧操作结果不再重复显示。瞬时提示测试在提交前开始观察，避免测试进程调度延迟漏掉提示；首次冷启动的登录页 load 超时用例在单 worker 重跑后通过。

本轮 17 个不同农场浏览器用例最终通过，包括主流程、紧凑呈现、提示与好友全矩阵及独立触屏验证。像素 Select 打开后 Radix 隐藏背景的可访问树，测试在展开前读取触发器样式，再核对 Portal 面板；修正测试定位后触屏验证通过。截图、追踪和结果目录均为任务临时产物，完成验收后删除。

未验证：真实后端账号交易与网络中断后的服务端落单状态、真实手机硬件、Safari/Firefox。手机验证使用 Chrome 触屏模拟，不能视为真机实测。初始化已存在的 `dist/` 保留为原构建目录；不清理其他任务的文件。
