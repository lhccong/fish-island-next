# 摸鱼岛像素风与我的小岛验收

日期：2026-11-15。工作区包含其他未提交变更，本记录只说明 ADR-074/075/077 的范围。

## 实现范围

- 注册 `pixel-island`，主题与明暗模式独立持久化，切换时应用及清理受信任呈现 token。
- 海景铺满既有标题栏、热榜内容区与聊天消息区；正文海景透明度 0.16，不改变聊天区和输入区高度。
- 左导航采用自有像素图标与海岸装饰；热榜卡片及普通文字气泡使用现有像素纸面/木板明暗变量，图片、红包、福袋和撤回保留语义。
- 像素主题桌面侧栏为「我的海岛」；鱼小圈页签排第一并默认选中，手账保留小岛本机功能。全部主题提供独立面板，手机从聊天标题栏打开。
- 鱼小圈复用真实端口与已有发布、点赞、评论、图片查看和滚动分页；帖子使用纸面木框，点赞不铺底色。长正文默认四行，展开图标贴在正文右下侧，不单独占一行；手机保留 44px 点击区域。
- 码头使用统一 32px 自有像素图标，涵盖农场、伙伴、游戏、阅读及自定义链接；热榜来源侧栏与手机选择面板使用椰树、木屋和钓鱼海景，来源详情为木板气泡。
- 小岛提供名称、寄语、装饰、待办勾选/增删、自动保存笔记、快捷入口增删、模块排序及显隐。默认待办和笔记为空，默认码头只包含已接入的农场、伙伴；用户内容不使用演示值。
- 本机数据按账号隔离，400ms 防抖，页面离开/隐藏时刷新待保存数据；存储受限时保留当前编辑并允许重试。不是云端同步。

## 验证方法

命令：`npm run check`；`npx playwright test --config playwright.pixel-island.config.ts`。

浏览器为 Windows 上的 Google Chrome 157.0.8103.51，生产构建，合成账号、合成消息与 HTTP/WebSocket 路由夹具，不读取真实账号或聊天记录。视口：1440×900、375×812、390×844。全部注册主题：摸鱼岛像素风、WPS 表格、微信绿、企业微信、飞书蓝、钉钉蓝；各覆盖明亮与暗夜，共 36 个组合。

浏览器断言覆盖热榜 loading/empty/error/success、失败重试、主题选择/模式/刷新恢复、主题弹窗低高度滚动与 reserved gutter、手机滑轨隐藏、触屏滚动、Esc/焦点返回、内容区无横向溢出。聊天比较换肤前后的消息内容区与输入区尺寸，检查草稿、消息、历史请求和连接实例保持。

我的小岛验证待办、笔记保存、存储失败/保留/重试、自定义链接校验、岛名与寄语、装饰选择、模块排序/显隐、刷新恢复、关闭命中与焦点返回；单元测试补充账号隔离、输入边界、无自动无限重试、保存防抖与卸载刷新。关闭与主题切换不清空聊天草稿。

结果：最新 `npm run check` 通过（格式、Lint、类型、97 个文件 / 387 条单元测试、生产构建）。前期基础浏览器矩阵 108 项全部通过，耗时 15.2 分钟；像素图标增量矩阵 36 项通过。构建仍提示 index/life 等大于 500KB 的块，且 MomentEditor 同时被静态与动态导入，未实现独立拆块；本次未扩展到拆包重构或体积预算测量。

鱼小圈最新增量检查：6 个主题 × 明暗 × 桌面/375px/390px，36 个组合的用例断言均通过。覆盖 loading/error/empty/success、默认页签、发布、四行折叠及展开按钮与正文的同行位置、点赞无背景、评论按需加载与草稿、更多菜单、图片查看、滚动分页去重及模式切换不增加请求/连接。桌面使用 Edge 157.0.4341.46，手机模拟使用 Chrome 157.0.8103.51。批量执行曾在浏览器操作或项目切换/退出阶段卡住，分视口补跑缺项；已完成用例后手动停止卡住的执行器，不把中断的整批运行记为退出码通过。

热榜详情增量检查同样补齐 36 个组合，用例断言均通过：来源海景、木板消息、手机来源选择/搜索/空结果、Esc 与焦点、首末热点滚动可达、loading/empty/error/success、重试与无额外请求、无横向溢出。桌面和 375px 使用 Chrome，390px 使用 Edge；同样存在浏览器执行器退出卡顿，已完成断言后停止并清理。测试配置提供禁用 GPU 的启动参数，避免依赖硬件加速；不改变产品行为。

## 范围限制

真实 iOS/Android 系统软键盘、系统安全区和线上后端账号未验证；手机流程在 Chromium 的触屏与手机视口模拟中验证。未测量长期聊天压力、内存或输入 p95，本次不声称达到聊天性能预算。其他游戏、管理员页面及未修改功能未做穷举业务回归。

测试截图、trace、发布预览构建和一次性产物使用独立的 pixel-island、pixel-icons、pixel-hot、island-circle 测试结果目录，提取验收结论后删除并检查残留；正式交付截图另列于本文。已有其他任务的临时目录和共享构建目录不处理。
