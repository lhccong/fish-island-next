# 谁是卧底迁移验收

日期：2026-11-14。架构决定：[ADR-063](../decisions/ADR-063-undercover.md)。

## 交付范围

- 游戏目录、最近玩过、独立窗口和 `/game/undercover`；旧 `/game/draw` 跳转到新入口。
- 同屏游戏无需登录，支持 3–20 人、受人数约束的卧底数量、随机或自定义词对、昵称、逐人查看词语、描述、私密投票、平票继续、出局、双方胜负和结束确认。
- 联机复用旧房间服务：大厅、按房间号查找、创建、加入、恢复本人房间、退出、房主或管理员开始与结算、管理员移除、投票记录、猜词及房间发言。
- domain/undercover 保留纯规则与端口，infrastructure/undercover 适配旧协议，feature 的本地对局、房间同步、消息、倒计时和草稿分离，app 组装服务与账号。

## 修复与兼容

旧游戏页“加入房间”只有成功提示，本次改为实际查找与加入接口；发牌不再使用有偏的随机 sort，投票与出局更新不再变异上一份状态。降低玩家人数时同步约束卧底数量，拒绝重复或空昵称，平票不会误淘汰玩家。

同屏只有当前玩家主动确认后才挂载词语，交接或浏览器进入后台后隐藏；普通模式不提前展示身份。投票不能投自己或出局玩家，票数在本轮结束后公开。

房间消息必须带明确且匹配的房间 ID，按发送者和消息 ID 去重，最多保留 300 条；回看旧发言时不抢滚动，新增发言提供跳转入口。输入法组合输入时 Enter 不发送，发送失败保留草稿。旧服务没有发送回执，只显示“已提交”；不伪造送达成功，也不编造历史消息。

只扩展既有账号 WebSocket 的基础设施转发回调，与五子棋扩展并存，不新增连接，不将游戏消息放入公共聊天 store。旧请求取消与合并、账号切换卸载和组件卸载清理分别由对应状态所有者负责；刷新失败保留现有房间，手动重试。房间消失时保留已收到的发言供查看结果。

## 验证方法

Windows + Chrome/Chromium，合成账号、房间、词语和消息；不使用真实聊天记录或用户凭证。按注册表的 WPS、微信、企业微信、飞书、钉钉 × 明亮/暗夜 × 1440px 桌面、375px 和 390px 手机视口组织测试。完整流程视口高 900px，紧凑弹窗与滚动场景高 600px。生产快照在本次独立临时目录构建，避免其他并行任务的热更新影响。

- `undercover.spec.ts`：30 个组合的本地发牌到最终胜利；联机 loading/empty/error/success、创建失败重试、开始、词语、收发与去重、过滤其他房间、投票、猜错与猜中、主题及模式切换保留草稿与连接。外观切换使用真实主题控件；手机组合临时展开到桌面宽度以触达现有全局主题入口，切换后恢复原手机视口。
- `undercover-states.spec.ts`：30 个组合的 20 人表单和末项可达、减少人数时卧底数约束、重复昵称错误、弹窗 gutter/焦点/下拉/Esc、查找与加入失败重试、输入法、长发言列表、首末滚动、键盘及手机触屏事件、回看不抢位置、退出确认、窗口收起恢复和关闭。
- 布局断言覆盖内部及页面无横向溢出、手机文字按钮 44px、正文末端桌面 24px/手机 20px gutter、桌面实际显示滑轨、手机隐藏滑轨但滚动可用；对生产截图检查明暗模式的排版、间距和可读性。
- 18 个卧底专项单元测试覆盖本地规则、协议、HTTP 参数与认证、请求取消、错误保留及消息去重上限。全仓检查命令为 `npm run check`。

## 已知限制

尚未用真实账号组织多人真实后端联机；接口、广播和各类结果在合成服务中验证。未验证真实手机硬件与系统软键盘、Safari/Firefox、连续 30 分钟运行性能。手机触屏通过 Chromium 触屏视口及 CDP 触摸事件验证，不能视为真机实测。

旧后端不提供房间历史和送达回执，也没有结构化发言阶段；客户端显示真实广播和倒计时，不自行推断投票阶段或结算胜负。关闭同屏页会清除当前局，关闭联机页不会向服务端自动退出；界面已说明。

全仓生产构建仍提示既有人生重开等大资源块，不将此作为聊天入口体积或性能达标证明。生产快照、截图、失败追踪和测试结果均属于临时验证产物，提取结论后清理；保留任务前已有的测试目录与共享 dist。
