# 聊天福袋迁移验收

日期：2026-11-14。范围：ADR-060，当前未提交工作区的聊天福袋变更。

## 已实现

- 发送随机/平均分配福袋，校验总积分、中奖人数、单人上限、持续时间和名称长度；服务端创建接口负责广播，客户端不重复发送聊天消息。
- `[luckybag]` 混合消息解析、复制和引用摘要；卡片与系统提示纵向排列，独立成行、左侧对齐，间隔 8px，图片保持比例并提供失败回退。
- 福袋详情、参与失败重试、成功防重复参与、进行中列表、中奖记录空数据/失败重试/成功展示，以及到期、已开奖、已过期状态。
- 创建结果不明时锁定再次提交，提示核对福袋/积分；关闭面板不重置创建状态或聊天草稿。修复关闭列表的焦点返回，以及“再发一个”按钮重用造成的意外表单提交。

## 复读限制补充（2026-11-14）

红包、福袋及夹带文字的两类卡片消息均隐藏“复读机”，不提供 +1 或连续复读分组；发送用例 repeat 在创建待发送消息和请求前再次拒绝。普通文字与图片复读，以及正常红包创建发布不受影响。统一纯规则位于 domain/chat，复用同一规则约束菜单、按钮、分组和发送用例，见 ADR-043。

聊天范围 24 个单元测试文件/86 项通过；本次修改文件的 Prettier、ESLint 和 diff 空白检查通过。独立生产构建通过。`chat-reward-repeat.spec.ts` 在 Chrome 生产预览按 5 个主题 × 明暗 × 桌面/375px/390px 验证，共 30 项通过：桌面右键、手机更多菜单、键盘上下文菜单均没有复读项，复制/引用仍在；连续卡片不合并，不出现 +1，不发送复读请求，普通文字仍可复读并保留草稿。

补充核对桌面与 390px 手机菜单截图，两类卡片都只有备注、复制、引用和 @TA。补充截图首轮桌面曾在打开页面时超时，随后使用 Edge 独立复跑该桌面用例并核对截图；功能矩阵 30 项本身已完整通过。

本轮全仓 `npm run check` 已执行，停在并行改动 `src/app/components/WorkspaceAccount.tsx`、`tests/e2e/gomoku.spec.ts` 的格式检查；单独类型检查还遇到并行签到模块 `MakeUpConfirmation.tsx`、`SignInLauncher.tsx`、`SignInPanel.tsx` 的可选 className 类型及 `infrastructure/sign-in/client.test.ts` 的可能 undefined 错误，因此不能把上一轮的全仓通过结论沿用到本轮。未修改这些并行文件。真机和其他浏览器未验证；临时构建、配置、测试结果及截图仍按第 17 条清理。

## 可参与数量角标补充（2026-11-14）

“进行中的福袋”入口显示当前账号尚未参与、状态进行中且未到期的去重数量。零时隐藏，超过 99 显示 99+，提示保留实际数量。角标在按钮内部右上角，不改变原有 44px 操作范围，采用明暗语义颜色。

账号级 active store 同时服务角标和列表。登录、相关实时消息、重连、回到可见窗口按需刷新；参与与创建成功立即合并，列表中的卡片也同步服务端参与状态。单个在途请求并合并后续刷新，保护读取期间的新建/参与更新；读取失败保留已有数量与列表，弹窗提供重试。最近到期定时器只本地移除失效项，不逐秒轮询。关闭弹窗、主题/模式切换不重置数量；账号释放时取消请求、计时器与订阅。

新增 5 项独立状态测试，覆盖 loading、去重、资格/期限过滤、到期不请求、失败保留且不自动无限重试、串行刷新、旧响应、新建/参与同步、实时事件与重连、账号取消和游客不请求。聊天范围 25 文件/91 项测试通过。最新全仓 `npm run check` 完整通过，含 82 个测试文件/340 项；此前复读验证阶段遇到的并行模块错误已不再阻断本次检查。
