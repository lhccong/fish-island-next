- 表情包：30 组，验证真实懒加载 fallback 和收藏列表等待的图标、水平/垂直居中、减少动态效果、内部/页面无横向溢出，以及失败、重试、空结果、关闭、焦点返回、草稿和连接保留。已查看明亮与暗夜的实际截图。
- 热榜：30 组，验证加载图标及文案、失败重试、空数据、成功内容、无横向溢出；覆盖普通工作台与 WPS 表格外壳。
- 触屏流程：20 组，375 × 844、390 × 844，全部主题与明暗模式，模拟手机 touch/isMobile，通过 tap 打开表情包、选择收藏、等待加载、返回空结果及关闭，验证无横向溢出和连接保留。
- 上述浏览器共 80 项用例的断言均通过；热榜、触屏两批在用例结束后的进程回收阶段未及时退出，已核对命令并结束本次测试的 runner、worker 和开发服务器。这两批不计为命令正常退出成功。
- 静态检查：lint、TypeScript、生产构建通过；单元测试以 `npx vitest run --maxWorkers=2` 复测，93 个文件、369 项全部通过。初次默认并发中一个人生重开测试超过 5 秒，降低并发复测通过。

## 未验证项与边界

上述矩阵覆盖共享加载样式的代表性页面及交互，没有逐一运行每个账号工具、游戏、图片和上传入口的全部业务异常、分页滚动、悬停及禁用流程；未验证真实手机软键盘与真机浏览器，不能据此宣称全系统全部场景已完成视觉验收。所有接口测试均为本地合成数据，不包含真实账号或消息。
