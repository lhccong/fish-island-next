# 自定义聊天列表验收记录

日期：2026-11-14。决策：[ADR-058](../decisions/ADR-058-custom-chat-list.md)。

## 实现范围

列表搜索旁的自定义入口可选择默认对话或自定义清单，修改群聊摘要，增删和编辑条目名称、摘要。只保存浏览器外观文案，不提供任务完成或服务端同步。WPS 桌面通过公式栏的聊天列表按钮进入；手机通过页头的聊天列表按钮进入。

## 验证

- Microsoft Edge / Playwright：微信、企业微信、飞书、钉钉、WPS × 明亮/暗夜 × 桌面 1280px、手机 375px/390px，30 组核心流程通过。
- 覆盖空清单、空名称校验、编辑/增删、取消、存储失败保留草稿、重试保存、刷新恢复、恢复默认、末项可达、滑轨显隐、焦点返回、预留间距及内部无横向溢出。手机包含 CDP 触屏滑动；桌面主动显示滑轨并检查截图。
- 另 1 项切换主题/模式及响应式尺寸测试通过：全部注册主题间切换保留自定义列表、聊天草稿和连接，不新增历史请求；搜索覆盖名称、摘要及无匹配状态。
- 同步本地偏好没有异步 loading 状态；默认对话列表沿用已有加载/失败反馈，不制造加载请求。
- npm run check 通过：格式、Lint、类型、276 项单元测试及生产构建通过；构建仍提示既有大体积 chunk。物理手机和真实软键盘弹出未实机验证。
