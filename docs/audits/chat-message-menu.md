# 聊天消息菜单验收记录

日期：2026-11-12。对应 ADR-037。

## 交付行为

菜单依次提供复制、引用、@TA、复读机；仅本人未撤回消息提供撤回。桌面支持右键、Shift+F10/菜单键，手机支持长按和至少 44px 的更多入口。支持菜单避让、Esc 关闭及焦点返回；草稿操作将焦点移入输入框。

引用、@TA、复读机仅准备草稿，保留已有输入，不发送消息。引用预览按 ID 读取原消息，撤回后隐藏原正文。图片复制为链接；复制失败显示可恢复提示。撤回沿用服务端确认、离线/待确认禁用及失败重试逻辑。

shared/ui 新增 Radix ContextMenu 封装，依赖 `@radix-ui/react-context-menu@2.4.1`（MIT），与 DropdownMenu 共用 `@radix-ui/react-menu@2.2.1`。草稿、通信和消息实体分别管理，主题切换不重建连接或清空草稿。

## 验证结果

- 最终代码执行 `npm run check` 通过：格式、零警告 lint、类型检查、41 个测试文件中的 150 个单元测试及构建。
- 浏览器矩阵覆盖 wps、wechat、wecom、feishu、dingtalk，明亮/暗夜模式，1280×720 桌面及 375×812、390×844 手机视口；菜单、历史、媒体和实时回归共 120 个不同用例。
- 主轮结果为 119 通过、1 失败；失败为 feishu 暗夜桌面用例初始消息等待超时。调整就绪等待后，该用例单独复测通过。最终可访问名称调整后，另有 feishu 暗夜桌面及 375px 手机两项冒烟通过。上述结果不是单轮 120/120 全绿记录。
- 菜单测试覆盖五项动作、本人权限、复制成功/失败、引用撤回更新、保留草稿、离线/待确认禁用、不发送、主题切换、键盘/Esc/焦点、手机长按/点击、菜单边界和无横向溢出；测试检查无页面异常。历史、媒体、实时回归覆盖加载、空数据、失败重试与成功状态。
- 已查看桌面 WPS 明亮菜单及手机暗夜菜单、引用草稿截图，菜单顺序、危险操作色、布局和关闭入口符合要求。
- 最终构建主 index 分块为 375.30 kB，gzip 119.66 kB；这不是入口依赖链总体积，不构成 200KiB 预算达标证明。既有人生游戏大分块警告仍存在。

## 验证边界与清理

浏览器使用合成消息及模拟 HTTP/WS 和剪贴板，未写系统剪贴板。真实账号撤回权限、真实剪贴板授权、实体手机软键盘未验证；未执行 p95、30 分钟稳定性、堆内存和大负载性能认证。

本次测试产物使用独立的 `test-results-chat-menu-*-20261112` 目录，提取结论后删除；停止本次 4196 测试服务。保留仓库原有 dist、用户附件和其他任务产物。
