# 阅读切章与设置样式复核

日期：2026-11-12。对应 ADR-031。

## 对照与修复

- 对照旧版 `GlobalFloatingReader` 的设置实现，恢复阅读、主题、朗读三个页签，使用字体选择、五项排版滑条、文字/背景色板、主题卡片和朗读开关。新增正文预览，窗口/快捷键/服务配置收进折叠区，已有能力保留。
- 设置采用 420px 紧凑弹窗，固定标题、页签与完成按钮，内容独立滚动；手机控件保持触屏高度和安全区。切换页签保留未提交服务地址、自定义主题名称等草稿。
- 加载及失败状态占据阅读器剩余高度，翻章栏始终贴底；桌面给缩放手柄留出空间。覆盖悬浮窗、全屏与文档画中画。
- 重试保留失败请求的章节索引；跳过卷标题后切至下一章失败，不会错误重试上一章，也不提前覆盖已确认阅读进度。
- 生产 CSS 压缩会产生三位色值；领域颜色规则统一三位/六位十六进制为六位，避免选择配色后刷新导致整份设置恢复失败。兼容已有短色值，拒绝非法 CSS 字符串。
- 所有新控件通过 shared/ui 或原生可访问语义实现完整样式，不新增依赖或使用系统 select/color 展开面板。

## 验证

验证主题：WPS、微信、企业微信、飞书、钉钉；每套均覆盖明亮/暗夜。视口：桌面 Chromium 1280×720、375×812、390×844。

`reader-layout-settings.spec.ts` 覆盖 loading/error/retry/success/empty 的翻章栏坐标、全屏、设置宽度和横向溢出、滑条触屏及键盘操作、色板/手动颜色、页签键盘、草稿保留、朗读禁用/启用/静音、声音选择器 Esc、关闭与焦点返回、设置刷新恢复。`reader.spec.ts` 回归完整阅读流程；`reader-settings.spec.ts` 回归自定义主题、配置覆盖、朗读清理和窗口几何；`reader-pip.spec.ts` 验证桌面真实文档画中画生命周期与翻章栏位置。

`npm run check` 通过：格式、lint、类型检查、27 个测试文件的 110 项单元测试、生产构建均通过。原有人生重开大资源块构建提示仍存在。首轮阅读浏览器回归 73 项通过、20 项移动端文档画中画按设计跳过；最终底栏间距调整后，另复验 30 项完整主题/模式/视口设置布局用例与 10 项桌面真实画中画，均通过，移动端画中画仍跳过 20 项。

截图与记录位于 `node_modules/.cache/reader-test-results/`，包含 `chapter-loading.png`、`chapter-error.png`、`chapter-empty.png`、`settings-reading-initial.png`、`settings-themes-initial.png`、`settings-speech.png`。生产浏览器测试用合成服务配置，避免真实配置进入测试记录。

未验证：物理手机及软键盘、Safari/Firefox、系统真实发声；手机使用 Chromium 触屏视口，文档画中画仅验证桌面支持环境，移动端相关用例按设计跳过。
