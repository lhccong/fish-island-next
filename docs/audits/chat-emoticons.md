## 收藏加载异常修复（2026-11-13）

用户反馈“收藏列表异常，请重试”。核对后端 `config/JsonConfig.java`，其将 Long/long 全局序列化为字符串，MyBatis Page.total 因而返回 `"25"`。此前前端对原值执行 Number.isSafeInteger，只接受数字，且旧单测错误地将 `"1"` 视为异常，导致合成数字夹具通过而真实接口被拒绝。

修复仅在 infrastructure/chat 的协议边界归一化 total：接受安全非负整数或十进制数字字符串，拒绝空值、布尔值、负数、小数、指数形式、超安全整数；ID 仍保留字符串。浏览器矩阵的空收藏、非空分页、追加重试与删除回读全部改为后端真实的字符串 total，并增加有效/无效总数单测。此修复不修改布局、主题、请求参数或发送行为。沿用同一 5 主题 × 双模式 × 3 视口矩阵，覆盖 loading/empty/error/success、滚动及原有核心流程；真实账号数据未读取或记录。

修复后 20 项协议单测、30 项浏览器矩阵及 `npm run check` 均通过（51 个测试文件，208 项完整单测）；已查看桌面和手机截图，已清理并复查本次 `test-results-chat-emoticons/` 临时构建、截图与追踪。

## 右键管理与放大预览（2026-11-13）

收藏网格取消图片下方的移除按钮；收藏通过右键菜单移除，搜索结果通过同一菜单收藏。桌面延迟悬停/聚焦显示 280px 的 Portal 图片预览，不改变网格尺寸，按视口边界避让；Esc 先关闭预览，滚动、离开和卸载清理浮层及计时器。菜单还提供持久的“放大预览”，手机用角部 44px 更多入口进入，复用共享 Dialog。悬停预览使用语义主题颜色，图片 contain 展示、无反色或裁切，成功/加载失败均有反馈。

ContextMenu 增加可选局部层级 className，表情菜单高于外层面板；手机与粗指针在表情网格禁用长按菜单，使用显式更多入口，避免触屏手势误选；原消息菜单的长按行为保持不变。菜单键盘和焦点仍由既有 Radix 管理。手机角部命中区域不覆盖图片中心，网格预留顶部焦点和原有滑轨空间。

浏览器矩阵沿用全部注册主题 × light/dark × 1280×720/375×812/390×844；在原有加载/空/失败/成功、滚动分页与发送流程上增加：无常驻移除按钮、桌面悬停不改变尺寸且浮层不越界、悬停预览 Esc 关闭而面板保留、Shift+F10 打开菜单与焦点归还、手机触屏更多入口与 Esc 关闭菜单保留面板、持久预览打开/关闭、预览图片 error 事件反馈、菜单移除失败保留项目并可重试。实体手机和真实账号写入仍未验证。

最终表情包矩阵 30/30 通过，原消息菜单微信明亮模式在桌面/375/390 的 3 项回归通过；`npm run check` 全部通过（52 个测试文件、215 项单测）。专项配置每次构建独立发布产物，拒绝复用旧预览服务；已查看桌面悬停、手机网格与预览弹窗实际截图。移除菜单与更多入口沿用单一收藏用例，未新增依赖、排序接口或真实账号操作。

## 直接发送、聊天图片预览与缩略图（2026-11-13）

点击收藏/搜索图片直接发送独立的 `[img]URL[/img]`，保留文字及引用草稿；不将引用自动附给独立表情包。发送失败在消息行显式重试，复用同一 clientMessageId。面板只在成功入队后关闭，未登录、地址超限或队列满时在面板反馈，不伪造成功。

聊天缩略图名义宽度由 320px 调至 214px（约缩小三分之一），继续使用 4:3 预留框、contain 与窄屏上限。原始图片不变；点击/触屏轻点图片后才挂载大图 Dialog，尺寸受视口与安全区约束，覆盖加载、图片失败和原位重试、Esc/关闭、焦点归还。触屏长按不同时打开预览；图片状态局限于对应图片，不把弹窗或草稿提升到页面。

回归夹具验证单独图片请求、直接发送失败重试且不重复入队、原文字和引用保留、214px 缩略图尺寸、桌面和触屏大图打开、错误事件与重试、关闭后焦点/滚动位置保留。悬停组件同时修正 Portal 菜单的聚焦事件沿 React 树冒泡时误开预览的问题：只由锚点内部 DOM 的聚焦/悬停触发。

本轮 30/30 主题矩阵通过（WPS、微信、企业微信、飞书、钉钉 × 双模式 × 桌面/375/390），另有微信明亮模式三视口的旧图片加载、失败重试和头像回归 3/3 通过。已查看桌面及手机的大图实际截图，尺寸、比例、关闭入口和边界均可用。

## 限制

生产 Nginx `/emoticon-search` 代理配置已在 `docs/deployment.md` 提供，本次未修改远程服务器，正式站点搜索需要部署该配置。百度仍可能按网络环境返回验证页，界面将显示失败而非空结果。真实账号收藏写入、生产代理、实体手机软键盘、Safari 未验证。聊天性能压力预算未测量；本次构建确认面板有独立异步块，不宣称聊天整体性能达标。

本轮已执行 `npm run check`，全仓 Prettier 被其他任务的 `.tmp-composer-validation/.last-run.json` 格式阻断；未修改或删除该任务文件。本轮改动文件单独 Prettier 检查通过，独立完整 ESLint、TypeScript、54 个测试文件/228 项单测和生产构建通过。面板保持独立异步加载，大图只在点击后挂载；构建仍提示既有人生重开资源块超过 500 kB，本次未扩大该功能范围。

早期检查曾被其他任务的 `.tmp-stock-migration/`、`.tmp-chat-return-validation/` 报告阻断，本次未修改这些其他任务产物。本轮仅清理自己的 `test-results-chat-emoticons/`、`test-results-chat-image-regression/`，包含截图、trace、调试结果和独立构建；此前专用 `.tmp-chat-emoticons/`、`test-results-emoticon-menu-regression/` 也无残留。任务开始前已有的 `dist/` 由标准构建更新并保留。
