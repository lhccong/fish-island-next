# 管理工作台验收

日期：2026-11-15。决策：[ADR-076](../decisions/ADR-076-admin-workspace.md)。

## 功能范围

- 数据分析：用户总量、今日新增/活跃、本月活跃、周/月/年和日期范围趋势，点击统计进入对应用户筛选。
- 用户：按 ID、昵称、账号、角色、注册/更新时间筛选和排序，新建、修改、删除、称号分配/移除、抢红包脚本封禁/解禁。
- 称号、标签、词库：查询及新增、编辑、删除。系统等级称号 2–10 沿用旧版规则，不提供手动分配或移除。
- 装备：查询及新增、编辑、删除；完整基础属性、槽位、稀有度与百分比属性编辑，保留未知属性键；提交对象由后端统一序列化。
- 举报：按类型、处理状态和用户筛选，详情、处理/驳回、处理备注及禁言。
- 所有列表滚动分页，追加失败保留内容，显式重试，按 ID 去重，重复页停止；切换筛选取消旧请求。

## 权限与入口

桌面入口位于最左侧主导航的发现图标下方，WPS 对应顶部功能区；点击直接进入管理工作台，采用朋友圈同款列表侧栏与选中状态，取消白色下拉。手机从发现进入独立管理目录，子页提供“返回管理页”。仅服务端会话角色 `admin` 可见。入口和直接路由分别受控，游客进入登录，普通用户显示拒绝访问且不请求管理数据。

修改自身角色后刷新会话；权限错误重新读取当前角色，不循环重试管理请求。退出、账号切换、角色失效时卸载管理组件并取消请求。客户端隐藏不替代服务端权限校验。

## 验证范围

主题：摸鱼岛像素风、WPS 表格、微信绿、企业微信、飞书蓝、钉钉蓝；每种均覆盖明亮/暗夜模式。视口：桌面 1280×720、手机 375×812、390×844，Chromium 内核 Edge。

覆盖七项页面的 loading / empty / error / success，编辑失败保留输入、恢复提交、删除确认、称号分配、举报处理/禁言、普通账号和游客路由、当前管理员降权、服务端撤权、连续滚动/失败重试/重复页/筛选重置，以及主题模式切换后保留筛选、草稿和请求计数。

长表单检查 reserved gutter（桌面至少 24px、手机 20px）、内部无横向溢出、末项可达、键盘焦点、下拉面板与 Esc 返回；手机通过 CDP 触屏手势实际滚动，桌面用滚轮，截图检查顶部/底部呈现。

最终结果：此前的侧栏版本已通过 `npm run check` 与 93 项管理浏览器用例、3 项发现导航回归。本次继续按旧版调整桌面布局，详见 [旧版布局对照](admin-legacy-layout.md)：96 个管理场景均已取得通过结果，覆盖原列顺序、查询/工具栏/表格分区、统计/趋势区位置、宽表滚动及高级筛选。另补充全部主题明暗与三个视口的称号分配弹窗、举报与长表单操作验证，并抽查 1536px 日期范围控件宽度。

首次并发运行有一项请求超时，相同主题/视口复测通过；补测时临时配置在运行中被移除，导致 7 项未启动，已用独立目录重新完成 390px 的 13 项补测，全部通过。当前管理用例没有未解决的失败项。已查看用户/装备表格、数据分析和手机暗夜称号弹窗的实际截图。生产构建的既有大分包与鱼小圈动态导入提示不影响构建完成。

最终规范检查：`npm run check` 通过，包含格式、Lint、TypeScript、97 个测试文件中的 387 项测试与生产构建。手机称号查询按钮的窄屏换行问题已修复，并通过实际截图确认；补充全部六种主题 × 明暗模式 × 桌面/375px/390px 的 36 项称号查询布局与操作回归，均通过。最后修复后定向 Lint 与 TypeScript 检查通过。

该 36 项补测全部输出通过后，浏览器进程回收阶段持续未退出，已中断测试进程并清理本次临时产物；该次运行退出码为 1，不能作为完整测试进程正常退出的记录。

发现导航回归同步适配现有手机返回按钮、游戏分级返回和 React 路由提交时序，避免将过渡帧误判为导航丢失；未改变这些业务页面。

## 验证限制

接口测试使用合成账号、数据和拦截响应，核对旧版及本地后端控制器协议，未对生产账号执行真实增删改、禁言或举报处理。未使用实体手机，系统软键盘弹出后的实机行为待验。测试图片、追踪、临时配置和独立构建快照在提取结论后清理；原先存在的共享构建目录不作为本次临时目录删除。
