# 工作时间悬浮球验证

日期：2026-11-15。实现依据：[ADR-065](../decisions/ADR-065-account-menu.md)。

- 入口：登录后的工作台悬浮球；头像菜单保留显示/隐藏工作时间。
- 环境：Windows、Playwright + 本机 Chrome，开发服务；使用合成会话与接口响应，不访问真实账号数据。
- 主题：WPS、微信、企业微信、飞书、钉钉，分别覆盖明亮/暗夜模式。
- 视口：1280×844、375×844、390×844；另检查从桌面缩至 375×640 的边界。
- 核心交互：鼠标/模拟触屏拖动、拖动不误开、位置刷新恢复、方向键移动、Enter 打开、Esc 关闭与焦点返回、工作制下拉、大小周、手机真实触摸事件滚动、末项聚焦可达、正文保留 gutter、内部及页面无横向溢出、模式切换保留设置与位置。
- 状态：各主题/模式/视口覆盖上班前、午饭前、下班前、下班后、休息日、无薪资/有薪资、时间顺序校验失败、存储失败保留输入及重试成功。工作时间仅本机计算，不涉及异步 loading 或服务端空数据状态。
- 自动化入口：`tests/e2e/work-time.spec.ts`，31 项通过；桌面及 375/390 明暗截图已人工检查，临时截图、trace 与测试结果在提取结论后清理。
- 全仓验证：`npm run check`，包含格式、ESLint、TypeScript、362 项单元测试与生产构建。构建仍提示既有大体积 chunk。
- 未验证：真实手机硬件与软键盘、Safari/Firefox、真实后端会话；手机结论仅代表 Chrome 触屏模拟。

## 像素风格补充验证

悬浮球保持 80px 命中区域，按用户后续要求保留平滑圆形轮廓与轻量主题投影、五种状态的本地 SVG 像素图标与五格进度。沿用上述 5 主题 × 明暗 × 1280/375/390 测试矩阵，额外断言每种状态对应图标及球内文字不溢出；检查桌面与手机明暗状态截图。拖拽、位置恢复、表单及错误反馈使用原有回归流程。图标无需网络加载，无新增依赖或持续动画；真实手机软键盘及其他浏览器仍未验证。

圆形版本采用独立生产构建快照和预览端口验证，避免其他并行任务修改登录模块或重启开发服务时的干扰。本轮 `npm run check` 已执行，停在其他任务的临时测试产物及配置格式检查；未修改或删除这些外部任务文件。本次修改文件的格式检查、ESLint、TypeScript、362 项单元测试及生产构建分别通过。

## 侧边收纳验证

- 范围：当前注册的摸鱼岛像素风、WPS、微信、企业微信、飞书、钉钉，共 6 个主题；明亮/暗夜模式；1280×844、375×844、390×844。
- 使用独立生产快照与本机 Chrome 验证，测试初始化断言实际 `data-skin`，避免未包含新主题的旧构建回退造成误判。
- 复用设置与计时阶段回归，新增左右吸附、2.5 秒空闲收起、44×64px 侧边入口、鼠标悬停保持展开、触屏首次点按仅展开及二次打开设置、设置期间不收起、收起后直接拖动、取消恢复、Home/End/Esc/Enter、键盘聚焦不收起、刷新恢复、模式切换保持收起状态、隐藏/显示保留位置及无横向溢出。另检查减少动态效果时无过渡。
- 计时为本机同步功能，不引入新的加载或空数据状态；原表单校验与保存失败重试继续覆盖。
- 临时产物限制在 `node_modules/.cache/work-time-dock*` 的三个明确路径内，完成验证后删除；其他任务的临时文件不清理。
- 未验证：真实手机硬件与软键盘、Safari/Firefox。
