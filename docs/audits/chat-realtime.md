## 实现范围

连接、登录帧、25 秒心跳、指数退避与抖动重连、离线暂停/恢复、连接超时、可识别认证关闭码处理；公共群纯文本消息接收、按服务端 ID 幂等合并、撤回推送及本人撤回请求。撤回仅在服务端推送后生效，10 秒未确认可重试。发送按钮仍禁用。

消息列表为独立归一化 store，16ms/200 条批量提交，虚拟行按 ID 订阅；最多保留 1000 条消息、10000 条撤回墓碑。缓存逐出下界阻止旧消息重放；不同 ID 的相同正文不会被合并。回看时不强制跳底，最新入口使用共享视口的原生滚动，避免虚拟列表延迟滚动指令打断操作。

## 本地验证结果

- Windows、Node v25.8.1、Playwright Chromium 158.0.8127.18；浏览器测试运行 Vite 开发模式，生产构建另经 check 验证。
- `npm run check` 通过：格式、零警告 lint、类型检查、35 个测试文件共 133 项测试、生产构建。构建保留人生重开异步块超过 500kB 的体积提示。
- `npx playwright test -c playwright.chat-realtime.config.ts --workers=4`：30/30 通过。
- 主题覆盖：wps、wechat、wecom、feishu、dingtalk；每种主题均覆盖 light/dark × 1280×720 桌面、375×812 手机、390×844 手机。
- 各组合覆盖：已连接空状态；同批/跨批重复消息、同文不同 ID；撤回先到、撤回等待、超时失败重试、回执成功、撤回后重投；断线与自动重连、重连重复投递；保留输入草稿且发送禁用；200 条连续入站、DOM 少于 80 行；上翻到首项、保持阅读位置、返回末项；页面及消息容器无横向溢出。手机使用合成触屏拖动和真实 tap，检查 scrollbar-width 为 none。触屏拖动结束使用 cancel，避免测试惯性与后续独立跳转场景竞争。
- 桌面额外验证主题/模式切换后不新增连接、草稿与消息保留；包括 WPS 与侧栏外壳之间切换。
- 单元测试额外覆盖连接建立状态、离线/在线、心跳、握手超时、认证关闭码、StrictMode 清理、注销时清理队列与计时器、乱序排序、窗口淘汰后重放、畸形协议帧和不安全数字 ID。
- 已查看桌面及手机明暗截图，检查消息换行、输入区、连接提示与布局；本次截图/trace 为临时产物，提取结论后清理。复现时由上述浏览器命令重新生成。

## 未验证与兼容边界

- 未使用真实服务器和账号联调；服务器的实际关闭码、撤回权限/时限与拒绝响应仍需服务端验证，未确认的撤回不会伪装成功。
- 仅接收实时消息；未接入历史、发送、富文本/图片解析、引用跳转或断线补拉。协议没有确认 cursor/seq，不能保证断线期间无丢失。当前窗口与墓碑均有上限，不宣称无限历史/无限期乱序一致性。
- 离线/认证失败/握手加载状态通过单元测试覆盖，未逐主题进行这些状态的独立截图验收；未完整验收所有悬停/键盘/焦点组合及桌面滑轨主动显示截图。手机主题切换期间的业务保留没有单独进行运行时测试；手机当前聊天页没有主题切换入口。
- 未验证真实手机软键盘、输入法和物理设备；触屏测试为 Chromium 模拟。
- 未执行 30 分钟稳定性、1 万条历史回看、20 条/秒持续 60 秒输入 p95、长任务、掉帧与堆内存趋势测量；不能将开发模式功能测试当作性能基线。
- 构建主 index 块 gzip 约 109.29kB，此为单文件数字；未汇总聊天入口同步依赖加载链，不能据此宣称首屏 200KiB 预算达标。

## 2026-11-13：隐藏提示栏与指数重连复核

按用户要求隐藏顶部连接状态、漏收提示和手动重连按钮。ConnectionStatus 仅保留裁剪为 1px、绝对定位的读屏状态，不占消息区高度；消息区、输入草稿和连接所有权保持不变。

复核并沿用现有自动重连：退避基准 1/2/4/8/16/30 秒，75%～100% 抖动，达到上限持续重试；短暂 open 不重置，稳定 30 秒才重置。离线暂停、在线立即恢复；握手 15 秒超时自动重试，认证失效和主动关闭停止。
