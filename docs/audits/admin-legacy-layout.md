# 管理页面旧版布局对照

日期：2026-11-15。范围：七项管理正文与相关编辑弹窗。参照工作区旧项目 `fish-island-frontend/src/pages/Admin` 的实际实现；保留用户明确要求的朋友圈式管理导航。

## 桌面正文

| 页面     | 旧版依据                  | 本次对齐                                                                                                                         |
| -------- | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 数据分析 | `Data/index.tsx`          | 顶部全部用户、今日新增、今日活跃、本月活跃四列；下方独立趋势区，标题、右侧日期范围/查询/周月年选项、折线图与日期/人数坐标        |
| 用户管理 | `User/index.tsx`          | 独立查询表单；表格标题在左，新建/刷新在右；列依次为 id、账号、用户名、头像、简介、权限、注册时间、更新时间、操作；日期在列头排序 |
| 称号管理 | `User/Title/index.tsx`    | ID/称号名称查询；表格依次为 ID、称号名称、创建时间、更新时间、操作                                                               |
| 标签管理 | `Tags/index.tsx`          | id/标签名称/类型查询；表格依次为 id、标签名称、颜色、图标、类型、排序、操作                                                      |
| 词库管理 | `Word/Library/index.tsx`  | id/单词/分类/类型查询；表格依次为 id、单词、分类、类型、创建时间、更新时间、操作                                                 |
| 装备管理 | `ItemTemplates/index.tsx` | 默认折叠查询、展开高级字段；表格依次为物品名称、物品大类、物品子类型、可穿戴槽位、物品图标、稀有度、操作；完整属性在编辑表单中   |
| 举报管理 | `Report/index.tsx`        | 举报类型/举报人/被举报用户/处理状态查询；保留原十三列顺序，桌面操作列固定在横向视口右端                                          |

查询表单沿用 120px 标签列、按顺序排布的响应式网格和右对齐操作区。宽表只在表格自身横向滚动，页面不横向溢出。表头在加载、空数据与失败时保留，加载图标和文字在表格正文中居中。

## 弹窗

普通新增/编辑恢复旧版约 520px 单列表单结构。装备的基础字段、物品描述、主动属性及抗性属性恢复原先顺序，两类百分比属性在桌面各用两列。用户称号采用约 1000px 宽的上下两张表；举报详情采用约 640px 宽、桌面两列的详情区，手机单列。保留标题/关闭、reserved 正文滚动和底部操作的当前规范。

## 当前规范要求保留的差异

- 管理入口和外壳按用户本轮要求保留朋友圈式侧栏，不恢复旧站顶部管理下拉。
- 使用既有 React/Radix、共享 Button/Select/Dialog/LoadingIndicator 和语义颜色；不复制 Ant Design/Umi，不新增 UI 框架。
- 页码控件继续改为滚动分页（ADR-034）。桌面宽表保留横向阅读，手机在同一份表格实体上重排为带字段名的纵向列表，避免复制请求、草稿及操作逻辑。
- 不能直接操作的旧字段不伪装为可编辑能力，例如现有用户更新协议不能修改账号，账号保持只读。

## 验证

浏览器断言逐页校验原表头顺序、查询区/工具栏/表格的纵向关系、四项统计在桌面同排且在趋势区上方、列头排序、装备查询展开及保留筛选、真实横向滚轮、手机表格无内部横向溢出。继续执行七项页面和弹窗的明暗/主题/视口全矩阵与业务操作测试。最终运行结果见 [管理工作台验收](admin-workspace.md)。
