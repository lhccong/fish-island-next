# 红包消息与领取验收

日期：2026-11-13。环境：Windows 本机，Vite 开发服务、Playwright Chromium；使用明确的合成账号、消息及接口响应，不使用真实聊天或领取积分。

## 实现范围

- 兼容旧 `[redpacket]` 协议，保留前后文和混合图片。无效标记保留原文；单消息最多 12 张卡片。
- 微信式橙金封面、信封和圆形封口，移除红包消息外层灰色/本人绿色气泡。标题使用真实红包名称，领取后、抢完及过期使用淡化封面；两种模式封面文字对比度为 5.29～6.18。
- 对接现有详情、领取、答题及记录接口。按红包 ID 共享状态，领取在途互斥，成功后禁用重复领取；网络结果不明确时提示先查看记录。账号切换取消旧请求，主题/模式切换保留消息草稿和答案，不产生红包请求或重连。
- 操作使用共享 Button；记录使用共享 Dialog、reserved ScrollArea。桌面保留滑轨，手机隐藏滑轨且保留 20px gutter。记录按积分降序、稳定 ID 去重，接口无分页协议，不增加分页按钮。

## 自动化与视觉检查

测试：`tests/e2e/chat-red-packet.spec.ts`；配置：`playwright.chat-red-packet.config.ts`。矩阵为 WPS 表格、微信绿、企业微信、飞书蓝、钉钉蓝 × 明亮/暗夜 × 1280×720、375×812、390×844。

覆盖首次 loading、详情失败/重试、记录 loading/失败/重试/空列表/长列表，领取失败/成功、答题空答案/错误答案/成功、已抢完/过期、同红包重复消息、引用与撤回。断言消息区/卡片无横向溢出、手机按钮至少 44px、桌面按钮至少 32px、记录顶部至少 4px、末端预留桌面 24px/手机 20px；触屏滑动后验证首末项可达、键盘滚动、Esc/关闭按钮与焦点返回。桌面主动显示滑轨，手机确认滑轨隐藏。截图检查明暗封面、操作区和记录布局。
