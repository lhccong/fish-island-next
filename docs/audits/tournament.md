# 武道大会迁移验收

日期：2026-11-15。关联：ADR-072。

## 迁移范围

- 入口位于伙伴营地，与宠物 Boss、爬塔并列；旧 `/point/tournament` 和 `/game/tournament` 跳转 `/pet?challenge=tournament`，进入鉴权后的伙伴面板。
- 复用伙伴模块的排位端口与面板，显示本人名次、实际参赛人数、前三席与完整榜单，补足前十空位。
- 对手伙伴资料、挑战确认、服务端胜负与名次、真实回合记录。没有回合时不伪造战斗。
- 每日十次上限及只挑战更高排名与后端一致；接口不提供剩余次数，界面不声称次数无限或显示虚构积分。
- 榜单接口自动入榜，先榜单后本人名次；刷新保留已有列表。挑战串行，传输结果不明时禁用后续挑战，成功刷新榜单后恢复。

## 验证方法

使用本机 Chrome、Playwright、生产构建和合成账号/数据，不连接真实比赛。独立构建目录与预览服务隔离并行任务对 dist 的重建。

矩阵：WPS 表格、微信绿、企业微信、飞书蓝、钉钉蓝 × 明亮/暗夜 × 1440×1000、375×844、390×844。

每组检查初始加载、读取失败、重试空榜、十席空位、业务失败后重试、空位成功、24 人榜单、本人/较低排名禁用、查看对手资料与 Esc 焦点返回、有对手的胜利及 32 回合记录、弹窗 gutter、内部及页面无横向溢出、桌面滚轮与手机真实触屏滚动、滑轨显隐、首末内容可达。

另外检查网络提交结果不明时禁止重发，以及全部主题/模式切换时保留榜单 DOM 与请求次数。伙伴营地入口与原挑战分类复用同一面板；相应用例同步更新为在结果弹窗查看结算后返回。

## 限制

未使用真实账号消耗挑战次数，未验收线上排行榜竞争、真实账号鉴权过期及服务端每日结算任务。未进行长时性能采样；不宣称聊天或比赛性能达标。生产构建仍有既有大块体积提醒。

## 验证结果

- `npm run check` 通过：格式、零警告 lint、严格类型、93 个测试文件 / 371 项单元测试、生产构建。
- 伙伴内入口最终矩阵的 30 个主题/模式/视口组合，加网络结果不明保护和换肤不重发两项，共 32 项检查通过。全量运行先通过 31 项，飞书明亮 375px 的浏览器 page 夹具初始化触发默认 30 秒超时；将测试级超时提前到夹具初始化之前后，单独重跑该组合通过，未修改产品逻辑。
- 伙伴旧分类入口、资料及挑战结果回归通过；桌面与手机截图人工复查，手机真实触屏滚动、桌面滚轮及滑轨显隐均有断言。
- 临时截图、追踪、测试配置及独立构建仅用于验收，结论提取后清理。既有共享 dist 在任务开始前已存在且由并行任务共同重建，不按未知来源内容清理。
