# 聊天头像与图片呈现验证

日期：2026-11-12。架构与兼容决策见 ADR-035 补充。

## 交付范围

- sender.avatar 经协议适配校验后显示。无头像或加载失败复用 MemberAvatar 昵称占位；默认显示。
- 群聊详情（右上角 `···`）的“群聊名称”下方提供“显示消息头像”共享 Switch，桌面与手机位置一致。开关不在连接状态栏中。偏好通过现有端口保存在当前浏览器，不修改消息实体、不重连、不清空草稿；存储失败时当前页面生效并显示提示。
- 将旧版 `[img]HTTP(S)地址[/img]` 安全解析为图片，支持文本混排、多个标记、查询参数与大小写标记。拒绝脚本、data/file URL 和内嵌账号密码；无效或超出单条 12 张上限的标记保留文字。消息 HTML 仍为文字。
- 图片懒加载、异步解码、4:3 预留区域、contain 等比显示，使用原图颜色。支持加载中、成功、失败与重试；成功/失败切换保持区域高度，不主动跳动阅读位置。没有接入上传或发送。

## 验证

环境沿用 chat-realtime 记录：Windows、Node v25.8.1、Playwright Chromium 158；浏览器使用独立 Vite 开发服务，生产构建由 check 验证。数据均为合成消息及受控 SVG 图片响应。

- `npm run check` 已通过：格式、lint、类型、36 个测试文件共 137 项测试、生产构建；构建仍有原人生重开异步块超过 500kB 的提示。
- `node node_modules/@playwright/test/cli.js test -c playwright.chat-media.config.ts --workers=2 --trace=off`：30/30 通过。
- `node node_modules/@playwright/test/cli.js test -c playwright.chat-realtime.config.ts --workers=4 --trace=off`：原聊天回归 30/30 通过，覆盖去重、撤回、重连、主题切换及触屏滚动。另有 WPS 明亮/微信暗夜 × 桌面/390px 的 4 项设置位置截图复测通过。
- 覆盖 wps/wechat/wecom/feishu/dingtalk × light/dark × 桌面 1280×720、375×812、390×844。
- 每个组合验证图片加载占位、成功、失败后重试、混排文字、安全标记降级、头像显示/隐藏/无头像占位、详情内设置入口、初始已保存偏好恢复与写入、草稿保留、连接数量不变、页面和消息滚动区无横向溢出。手机操作包含 Switch 与重试按钮 tap，桌面包含 Space 切换开关。
- 单元测试新增混排解析、无效/畸形/危险 URL、标记数量上限及头像 URL 解码。
- 已查看桌面和手机明暗截图，检查头像列、图片比例、文字换行及消息气泡。截图与测试追踪为临时产物，提取结论后清理。

## 验证边界

- 初期测试在刷新后收尾及项目切换时出现浏览器进程停滞，本次仅清理自己启动的测试进程，最终使用独立服务、两个工作进程，并将偏好验证分为初始存储恢复与持久化写入，完整矩阵正常退出。
- 未验证真实服务器图片鉴权/防盗链、所有图片格式、真实手机与软键盘、超大原图解码峰值；实际网络失败显示重试入口。
- 未重新测量持续高吞吐的输入 p95、长任务、堆内存与 30 分钟稳定性；不能将虚拟列表或固定预留区域视为性能实测结论。
- 未穷举所有键盘/悬停/聚焦组合及真实浏览器存储禁用情形；存储异常恢复分支尚未端到端模拟。
