# ADR-026：紧凑且随主题变化的操作按钮

状态：已采用。日期：2026-11-12。

## 原因与决策

个人资料的保存按钮固定为橙色并有 136px 最小宽度，取消按钮最小宽度 96px；基础按钮统一 44px 高且继承大字号，造成桌面弹窗操作区笨重。采用同一个 shared/ui/Button 基线：桌面高度 32px、字号 13px、中等字重、水平内边距 12px、宽度随文字；手机高度至少 44px、字号 14px，默认不拉伸。

主按钮背景使用 color-action，前景使用 color-on-accent；悬停使用 color-action-hover，焦点使用 accent-text。次按钮为中性 surface/text/border。普通操作不得使用业务局部橙色、渐变或夸张阴影覆盖主题色；危险操作与业务状态保留对应语义。

个人资料移除操作按钮固定宽度、橙色覆盖和手机等分拉伸，保留紧凑的右对齐按钮组、8px 间距及安全区域。会员、破蛋日的暖色仍是信息状态，相关 token 改为 badge 命名，避免再被当作操作按钮 token。既有登录页等独立主任务可保留有明确目的的大尺寸；导航图标和触控控件不跟随缩小。本次不改变事件、禁用、提交与反馈逻辑，不新增依赖。

## 替代与影响

鱼小圈发布/编辑弹窗的底部原生按钮一并迁移到 shared/ui/Button，去除宽胶囊、额外水平内边距、渐变和阴影。附件、移除、位置清理等触控入口保持原有命中范围；底部操作不再受附件按钮的局部样式覆盖。

不通过 transform 缩放按钮（会造成文字与点击范围不一致），不通过全局 button 选择器影响菜单、图标和附件控件。共享按钮统一实现，业务表单不复制按钮视觉。该决策替代 ADR-021 中保留橙色保存按钮的约定。

## 验证

npm run check；全部主题 × 明暗模式 × 桌面/375px/390px 运行资料完整流程，验证尺寸、宽度、正常/悬停/焦点/禁用颜色、主题色对比度和提交/失败/取消；手机按钮保持 44px 触控高度，操作区不横向溢出。
