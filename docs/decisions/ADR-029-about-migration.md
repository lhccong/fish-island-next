# ADR-029：迁移关于页面

状态：采用。日期：2026-11-12。

## 原因与影响

将旧项目 About 的共建反馈、二维码、复制群号、需求文档和六组功能介绍迁入发现区，入口位于阅读下方。新增公开懒加载 `/about`，app 组合工作台，features/about 持有复制与图片状态。保留旧内容、200px 二维码、居中 800px 卡片和桌面三列清单，改用现有 Lucide、Button、ScrollArea 与主题语义变量；不引入依赖。手机菜单按三列重排，正文单列。群号和需求链接来自旧版页面公开内容。

## 替代方案

直接复制 Ant Design 页面会引入第二套 UI 并绕过模块边界，故不采用。功能清单保留旧版原文，但明确标为旧版能力介绍，避免误报 Next 的迁移状态。

## 验证

执行 npm run check；浏览器覆盖全部注册主题、明暗模式、桌面及 375/390px，验证导航、复制中/成功/失败、二维码加载/失败重试、滚动及无溢出。此静态页面无数据集合空状态；图片加载和错误提供文字替代，复制不具备权限时提示手动复制。外链检查目标属性，不自动加入群或修改外部文档。
