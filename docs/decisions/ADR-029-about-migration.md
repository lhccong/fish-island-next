# ADR-029：迁移关于页面

状态：采用。日期：2026-11-12。

## 原因与影响

将旧项目 About 的共建反馈、二维码、复制群号、需求文档和六组功能介绍迁入发现区，入口位于阅读下方。新增公开懒加载 `/about`，app 组合工作台，features/about 持有复制与图片状态。保留旧内容、200px 二维码、居中 800px 卡片和桌面三列清单，改用现有 Lucide、Button、ScrollArea 与主题语义变量；不引入依赖。手机菜单按三列重排，正文单列。群号和需求链接来自旧版页面公开内容。

## 替代方案

直接复制 Ant Design 页面会引入第二套 UI 并绕过模块边界，故不采用。功能清单保留旧版原文，但明确标为旧版能力介绍，避免误报 Next 的迁移状态。

## 验证

执行 npm run check；浏览器覆盖全部注册主题、明暗模式、桌面及 375/390px，验证导航、复制中/成功/失败、二维码加载/失败重试、滚动及无溢出。此静态页面无数据集合空状态；图片加载和错误提供文字替代，复制不具备权限时提示手动复制。外链检查目标属性，不自动加入群或修改外部文档。

## 补齐关于下拉菜单

旧版“关于”为五项菜单：打赏榜、外卖福利、共建与反馈、其他产品、GitHub Star。发现区入口改为 shared/ui/DropdownMenu，保留旧路由 /rank/reward、/rank/welfare、/rank/about、/rank/other；/about 兼容指向共建反馈。新增 domain/about 端口、infrastructure/about 协议适配；app 注入会话，feature 不感知凭证。打赏榜/明细分别分页，支付仅由用户明确点击创建，沿用 type=1、服务端金额/订单/二维码/跳转地址与 OD 支付成功协议，轮询最多 60 次、每次间隔 3 秒；关闭/卸载取消请求与轮询，网络错误可手动重查。外卖福利保留四张旧图与图片预览，标明活动有效性以平台为准；其他产品保留旧版五个产品、公开地址及复制交互。无第二套 UI 或状态库。

页面自带 ScrollArea，使用工作台已有 contentScroll=false 避免嵌套同向滚动。弹窗正文采用 reserved gutter，并保留 8px 内边距容纳现有 3px outline + 4px offset；标题、关闭入口和操作/错误反馈固定。榜单使用显式分页替代旧版依赖 document 滚动的加载方式，适配工作台独立滚动容器；统计明确标注本页金额，不把当前已加载金额误报为全站总额。

浏览器验收使用独立的 node_modules/.cache/about-preview 产物，避免并行构建重写 dist 造成资源 404。ESLint 的 test-results* 忽略范围与现有 Git/Prettier 规则一致，仅排除生成的验收产物。

复现：先执行 `npx vite build --outDir node_modules/.cache/about-preview`，再执行 `npx playwright test --config=playwright.about.config.ts --project=desktop-chromium --project=mobile-375 --project=mobile-390`。测试使用合成数据与模拟订单，不能替代真实支付和第三方活动有效性验证。

发现菜单一致性修复：鱼小圈不再单独拼装固定的游戏/阅读入口，由 app 复用 DiscoveryNavigation，并将功能拥有的全部动态按钮及头像作为 circleEntry 插槽传入；发现菜单的条目顺序与关于菜单仅维护一处。人生重开页补齐公共手机导航。不改变请求、鉴权、动态筛选及外壳依赖方向。

关于导航调整：覆盖此前下拉菜单方案。侧栏关于直达 /rank/reward，/about 默认进入赞助榜，/rank/about 保留共建反馈。五项模块改为页头图标加文字的路由导航，手机三列重排；使用原生链接、aria-current 和语义变量。公开接口只读探测确认记录存在且 total 为字符串，分页计数单独接受非负安全整数及十进制整数字符串，金额仍严格校验有限非负数；不记录真实支持者资料，不改变付款协议。

赞助榜呈现调整：仅第一页的前三名使用领奖台，第一名跨列居中位于第二、第三名上方，第四名及后续为连续列表；第二页延续全局排名，不生成新的前三名。右侧打赏动态参照旧版 280px 独立面板，提供头像、昵称、增加金额、留言、日期、总数徽标与页码分页，正文使用 reserved ScrollArea、页头页脚固定。宽屏左右布局，手机及不足以容纳双栏时上下排列。业务请求及支付流程保持同一实现，装饰色使用既有语义变量，不添加依赖。

赞助榜紧凑与滚动分页调整：覆盖此前卡片及点击分页呈现。移除统计、领奖台和动态面板背景框，前三名保持一上二下的紧凑布局。榜单与动态各自使用 ScrollArea 的独立视口，触底哨兵通过所属视口触发下一页追加；请求进行中和失败时停止自动加载，失败只提供重试，不提供页码按钮。按稳定 ID 去重，达到总数或返回空页后停止，支付成功刷新时从第一页重建数据。手机上下重排，保留明确滚动间距和可触达的上下区块。

赞助榜视觉优化：覆盖此前无分区和一上二下的呈现。榜单、动态采用轻边框分区，统计并排；前三名同排，第一名居中并使用主题浅色强调，第二、三名分列两侧，手机缩减间距并保留完整信息。限制正文宽度，减少空白和装饰分隔线，动态金额改用主题强调文字色。保留独立滚动、reserved gutter、加载与重试及支付逻辑。只复用现有语义 token，无架构或依赖变化。验证全部注册主题 × 明暗模式 × 桌面/375px/390px 的状态、内部溢出、滚动与支付入口，截图检查布局。

按用户后续要求隐藏赞助统计区，不再展示爱心总数与已加载赞助额，排行榜标题直接衔接前三名；动态条数和分页计数保留。

打赏视觉升级：用户要求加强入口和支付弹窗的吸引力。入口是独立支持任务，复用 shared/ui/Button，采用 44px 高、自然文案宽度及主题动作色，作为 ADR-026 普通 32px 按钮的局部例外；不影响普通确认/关闭按钮。金额选择是多行卡片控件，复用 Button 的按下语义与键盘能力，明确金额、说明和勾选态。新增局部 CSS Module，使用现有语义变量绘制爱心轨道、浅色背景与克制动效，尊重减少动态效果；不新增资源或依赖。顶部保持关闭入口，正文 reserved ScrollArea，底部固定确认金额及错误提示。福利沿用现有服务说明，不添加虚构稀缺、人数或收益。请求与支付状态机不变。验证全部注册主题 × 明暗模式 × 桌面/375px/390px，包含选择、自定义金额、备注、禁用、创建失败/等待/成功、触屏、键盘、滚动留白和关闭焦点返回。
