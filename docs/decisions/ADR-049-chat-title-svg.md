# ADR-049：聊天称号 SVG 与秒级时间

状态：采用。日期：2026-11-14。

## 原因与决策

聊天时间显示到秒。旧版 CSS 等级称号和专属称号改为仓库内可信 SVG，保留原配色、文字、标志及原有流光/呼吸效果，不迁移全局 LESS。动效封装在 SVG 内，以 CSS/SVG 声明式动画实现，不引入消息行计时器或持续运行的 JS；减少动态效果时停用动画并保留静态配色。称号在消息元信息内呈现，不新增状态订阅或网络业务请求。

按旧版 `.adminTag` 的 11px 字号、白色文字、0.85 比例、圆角、字距和原渐变/光晕生成插画，禁止统一拉伸徽章或改为黑色文字。SVG 文字与图标使用旧版字体栈，渐变保留原 background-size 的实际可见范围及高光叠层。以浏览器测得的实际尺寸预留空间：水群达人/摆烂大师为 61.2×11.05px，摸鱼铲屎官为 72.25×11.05px。图片称号按原版 14px 高度及实际原图比例预留，不能统一固定宽度。

旧版 HTTPS PNG/JPG 含抗锯齿文字和图案，无法无损还原矢量路径；保留原图接入，不以 SVG 内嵌位图冒充矢量化。仅使用旧版公开目录中的固定 HTTPS URL，不接受消息提供的 URL 或 SVG 标记。加载前预留尺寸，失败显示可读称号；未知 ID 保持明确占位。

## 影响与替代方案

SVG 作为自有插画资源保持跨主题、明暗原貌；布局和失败文字使用语义变量。未开放第三方 SVG 导入，不改变依赖方向、账号草稿、历史分页或连接。放弃复制旧版动画 CSS（全局污染、消息动画开销）和自动描摹位图（细节损失、路径膨胀）。

## 验证

执行 npm run check；全部注册主题 × 明暗模式 × 桌面、375px、390px 检查秒级时间、等级和专属 SVG、图片成功/失败、未知称号、元信息换行及无横向溢出，确认换肤保留草稿且不新增连接/历史请求。
