# ADR-008 企业微信主题与工作台入口

状态：已采用。日期：2026-11-11。

用户要求新增企业微信主题。工作台原外观入口跳转工程初始化页，主题入口不够直观。

采用现有 appearance store、SkinProvider 和内置皮肤注册表，在工作台导航提供带文字的“主题”按钮，使用现有 Dialog 原地选择主题。新增 wecom 内置皮肤，复用微信工作台结构，不引入新的业务外壳或复制热榜逻辑。保留初始化页配色预览，两个入口共享状态。

内置 token 扩展为强调色、柔和强调色、强调文字、选中次要文字、导航背景、侧栏背景和发出气泡背景。所有内置皮肤完整提供这些颜色，切换时由 Provider 清理旧变量。第三方导入白名单仍仅限原有两个强调色 token。

appearance store 将合法内置皮肤 ID 保存到 fish-island:skin。读取非法值、存储不可用或写入失败时保持可切换，默认微信绿。只保存外观 ID，不涉及账号或业务数据。

替代方案：继续跳转初始化页会中断当前浏览；新增完整企业微信外壳超出主题切换需求；引入第二套设置框架无必要。

验证：执行 npm run check；浏览器覆盖桌面、375px 和 390px 的主题选择、刷新恢复、草稿保留、关闭焦点与热榜加载/空/失败状态下的入口可用性。
