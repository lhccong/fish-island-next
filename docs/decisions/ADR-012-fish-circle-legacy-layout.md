# ADR-012：鱼小圈旧版视觉与手机布局

状态：采用。日期：2026-11-11。

## 原因与选择

按用户提供的旧版截图，仅重做工作台右侧鱼小圈内容。保留左侧应用与功能导航。桌面采用约 1060px 的封面、动态主栏与约 260px 的置顶辅助栏；移除介绍大面板。动态采用圆形头像、正文对齐、位置标签、点赞条、时间和图标操作栏；管理操作进入已有 Radix Dialog 包装的更多菜单，保留权限控制与焦点返回。更多菜单打开后续编辑/确认弹窗时，通过 Dialog 可选 returnFocusRef 返回原「更多」按钮，避免回到已卸载菜单项。

封面经 fish-circle 端口新增 profile 读取 `/api/user/get/vo?id=`，适配旧账号 `momentsBgUrl` 和头像；不把默认插画冒充账号封面。资料请求、失败重试、图片失败回退由独立封面组件拥有，取消遵循既有 HTTP 规则。域评论增加头像字段。评论默认折叠子回复、展示前三条，点击查看更多展开，草稿仍归独立输入组件。

右侧置顶仅展示当前分页实际返回的置顶动态，标注「本页」，点击定位并聚焦原动态；不伪造全站置顶列表。中窄屏将置顶折叠到动态上方；375px/390px 为单栏，筛选入口与发布、刷新均保留。封面降低高度、正文收回左边距、图标保留至少 44px 点击区域，表单与安全区沿用现有规则。

## 配色与替代方案

在默认 token 中新增 `--color-circle-*`、`--shadow-circle-*`、`--radius-circle-*`：旧版白卡、浅灰底、蓝灰文字、暖橙置顶与发布强调色。局部旧版样式与工作台主题分离，不扩大第三方皮肤白名单。复用 CSS Modules、Lucide 与现有 Dialog，不引入依赖、不复制旧版 Ant Design 单体页面。

## 验证

执行 npm run check。浏览器验证桌面、375px、390px 的加载/空/失败、封面资料/图片失败回退、真实尺寸长文字与媒体、置顶定位、更多菜单键盘关闭和焦点返回，以及发布、点赞、评论、编辑、删除和抽奖流程。测试仅使用合成资料和合成封面，不复制截图中的真实动态或账号。
