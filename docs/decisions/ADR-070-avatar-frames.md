# ADR-070：迁移账号头像框

状态：已采用。日期：2026-11-15。

## 原因与范围

旧版账号支持积分兑换、穿戴和移除头像框；Next 尚未读取或展示对应字段。本次迁移头像框，不迁移旧商城中的道具、会员和积分流水页。

## 决策

- 头像框属于账号资料，沿用 domain/auth、infrastructure/auth、features/auth 的资料端口与会话内更新流程，不新增依赖。账号菜单懒加载头像框弹窗，分页状态独立于聊天和资料编辑。
- 兼容旧 `/api/api/avatar/frame/list/page/vo`、`exchange?frameId=`、`set?frameId=` 协议，`-1` 表示移除。兑换检查 `points-usedPoints`，服务端确认才更新拥有状态和积分；读回失败保留已确认结果，避免重复扣款。
- 使用 InfiniteScroll/useInfinitePages 串行加载、去重、取消和失败重试，不重置已有列表及滚动位置。切换外观不触发请求。
- shared/ui/AvatarFrame 只负责透明图片叠层及失败回退，接收 URL，不读取业务。账号头像、资料头像、聊天成员详情、历史/实时/待发送消息和复读参与者共用；左侧会话/在线用户列表按用户要求仅显示原头像。缺失字段不请求逐个用户资料。
- 复用语义 token、Button、Dialog 和 reserved ScrollArea。桌面三列、手机双列，支持全部注册主题、明暗模式和 375px/390px；原图片不反色，叠层不改变布局和点击目标。

## 替代方案与影响

不复制旧 Ant Design 商城和全局状态；独立商城模块会增加当前单一资料能力的组装复杂度，暂不采用。头像框更新沿用资料就地刷新，不进入 checking，不重建聊天连接；消息继续保留发送时的头像框快照。

## 验证

覆盖修复（2026-11-15）：旧版头像框素材含透明留白，聊天按 160% 居中叠加；恢复该比例并只将有框头像裁为圆形，防止方角露出。预览与复读头像保留足够装饰留白，左侧列表继续隐藏头像框。不改变请求、状态及图片原色。

执行 npm run check；单测覆盖协议、无效 URL、未确认写入、兑换/穿戴和读回失败；浏览器覆盖全部注册主题 × 明暗 × 桌面/375px/390px 的加载、空、错误、成功、滚动分页、兑换/穿戴/移除、关闭和焦点返回，以及聊天字段展示。
