# ADR-030 群聊界面与在线成员

状态：采用。日期：2026-11-12。

## 原因与范围

先提供微信风格的鱼岛公共群聊界面，仅接入现有 GET /api/chat/online/user。群聊入口为客户端固定公共入口，不调用创建群组接口，不伪造会话历史、人数或在线成员。消息、发送、邀请和群设置暂不接入。

## 决策与影响

domain/chat 定义在线成员端口，infrastructure/chat 校验 DTO 与鉴权，app 注入服务，features/chat 拥有请求、搜索、草稿与展示状态。草稿独立在 Composer，在线快照由账号作用域的 ChatMembersProvider 在进入页面时加载，供会话列表与右侧详情共用，关闭面板保留结果，刷新由用户触发；切换外观不重取。账号退出卸载并取消请求，不缓存成员资料。

WorkspaceShellSlots 增加可选 contentScroll（默认 true），聊天设置 false，在功能内部布置独立消息、成员滚动区及固定输入区，外壳不感知业务。替代方案是外层整体滚动，无法同时固定输入区和独立成员列表，故不采用。

右上角三个点默认收起成员区；桌面在右侧并排，手机详情区覆盖聊天正文并保留页头与关闭入口。该区域为非模态 complementary 区域，支持 Escape 关闭及焦点返回，不使用无键盘支持的菜单模拟。只显示真实在线快照，在线数不等同群成员总数。

后续呈现调整：成员默认以四列、最多四行显示（16 人），提供“查看更多/收起成员”。展开和多结果搜索使用最高 304px、且不超过 40dvh 的独立成员滚动区，下方群聊说明紧随其后；少量搜索结果按内容自然收缩。该调整只涉及局部呈现，不增加接口或群管理逻辑。

展开前后统一成员网格的尾端预留，避免两层 reserved 叠加后挤窄列宽。外层非模态信息区采用 ScrollArea overlay，由正文各分区保持同一语义间距；内层成员区保留 reserved，外缘另预留 12px 分开两条滑轨。收起状态使用与内层 reserved 相同的固定空白，滚动条显隐不改变头像及列位置。表单/卡片类弹窗的 reserved 约定不变。

会话栏宽度与留白：WorkspaceLayout/WechatShell 增加受限 sidebarVariant="chat"，仅聊天桌面及 WPS 外壳使用 300px 会话栏，其他页面保持 228px；手机仍使用独立列表 Dialog。侧栏行背景及分隔线铺满，ScrollArea overlay 的滑轨区域由行内容固定预留 24px，避免整块空白；弹窗仍采用 reserved。该呈现差异不复制数据逻辑，不改变任何聊天权限。

左侧列表：公共入口下方按微信会话行展示真实获取的头像和昵称，不展示在线标题或状态文案，不接入私聊能力或真实未读计数。ChatMembersProvider 为左侧列表与右侧成员面板共享数据、加载、失败和刷新；app 按账号 ID 为 Provider 设 key，退出/换账号取消旧请求，主题切换不重取。手机通过页头“查看聊天列表”按钮打开统一 Dialog 中的相同列表。相较两个区域各自请求，该方案避免重复获取和不一致；不接入私聊或实时通信。

按后续微信伪装要求，列表呈现为搜索栏、选中群聊、头像/昵称/摘要/时间行，去掉可见的在线用户标题、人数及在线状态文案。用户进一步明确要求工作内容伪装，摘要使用本地预设工作短句，按成员 ID 稳定分配，并通过 title 标明“本地工作伪装摘要”；它们不是后端聊天记录，不发送、不持久化为消息，也不显示虚构未读数。时间表示最近一次成功获取列表的本地时间，通过 title 标明含义，不当作历史消息时间。手机入口及弹窗使用“聊天列表”文案。

本地群名：允许编辑公共聊天入口在当前浏览器显示的名称（去除首尾空白，1–30 个 Unicode 字符，禁止控制字符），不调用群管理接口，不影响其他成员。domain/chat 定义本地偏好端口，infrastructure/chat 适配 localStorage，app 注入，features/chat 持有名称与独立编辑表单；标题、会话栏、空消息区与详情共用同一名称。偏好属于设备展示设置，不保存账号标识或聊天数据。读取失败使用默认名称；写入成功才更新界面，失败保留输入并允许重试。相较服务端更名，该方案符合仅存本地的范围，刷新可恢复且不触发在线列表重取。

按用户后续要求，关闭全部本地伪装小红点，包括成员及服务号/公众号/通知；移除标记生成规则、渲染及专用样式变量。相较仅隐藏 CSS，该方案不保留无用标记或读屏提示，不影响真实通知、成员数据、摘要、草稿和连接。昵称与摘要仍单行省略，title 提供全文及本地伪装说明；长句不扩大列宽。通过全部主题、明暗模式及桌面/375px/390px 的列表状态与搜索验证红点不再出现。

用户明确要求穿插虚构服务号、公众号和工作群：由 feature 的纯呈现模型插入五条固定本地伪装会话，与真实成员实体分开，使用独立 key 前缀及 title 标识，不合并进成员接口结果、人数或任何缓存。支持同一搜索；不提供关注、私聊或入群动作。服务/公众号使用蓝色抽象图标，通知使用橙色，群聊使用四格文字头像；颜色由 `--color-chat-cover-*` 默认语义变量提供，品牌图标明暗保持原貌，不新增图标库。

## 验证

校验接口错误、过期、取消、格式不符；浏览器覆盖全部注册主题 × 明暗 × 桌面/375px/390px 的 loading/empty/error/success、搜索、刷新、关闭、焦点和无溢出；验证外观切换保留草稿且不重复请求。执行 npm run check。真实后端和完整聊天性能尚未验收。
