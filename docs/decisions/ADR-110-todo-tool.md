# ADR-110 工具栏账号待办

状态：已采用。日期：2026-11-26。

## 决定

「工具」注册 `/utils/todo`，旧 `/todo` 转至该页签。页面保留工作台导航，游客通过现有登录弹窗进入，认证后按账号加载。`domain/todo` 定义待办及日历规则，`infrastructure/todo` 通过已有会话凭证调用 `POST /api/todo/get` 和 `POST /api/todo/save`，`features/todo` 管理读取、显式保存、错误恢复和视图。外观切换保留所选日期及草稿。

默认查看当天任务，视图栏提供当天、整月和日历。日历视图标记各天的任务数量，并跟随选中的日期显示任务。桌面月历和任务并排，手机先选日期再看列表。日期按钮也可在列表视图临时展开月历选日。待办页不挂载工作时间悬浮球，为日历和行内操作保留完整点击区域。任务行左侧提供完成与撤销，右侧保留编辑与删除，正文按内容自然换行。添加、修改、完成、撤销完成和删除复用站内控件，表单使用预留滚动区及明暗语义颜色。

描述旁的色板和表单复用同一选色组件，支持预设色、饱和度与明度色域、色相滑块、六位十六进制输入及恢复默认。色域支持拖动与方向键，色值变化即时预览。选择的颜色原样作为描述背景，根据相对亮度选择高对比文字色，页面其余区域沿用主题语义色。沿用 `bgColor` 字段并兼容历史十六进制与 RGB 值，无需迁移数据。

## 兼容与替代方案

沿用旧账号快照，避免新建待办表或要求用户导出导入。读取兼容空快照及旧任务字段，保存保留快照中的周报、无法识别的记录和任务扩展字段。每个打开的待办实例一次只提交一个写请求，成功才替换已显示快照，失败保留已读列表和草稿。旧协议没有版本校验，多个客户端同时保存时仍以最后一次写入为准。旧 `todoTasks` 浏览器缓存没有账号标记，因此仅从服务端读取该账号的正式数据。

## 验证

执行 `npm run check`。使用旧协议夹具验证日期边界、旧记录读取、周报保留和最后一条待办删除。按全部注册主题、明暗模式、桌面及 375px/390px 检查入口、布局、加载、空列表、失败重试、录入、更新、完成、撤销、删除、键盘焦点和触屏滚动。验证预设色或滑块选色、十六进制输入校验、保存后回读、浅深底色的文字对比及表单焦点和滚动间距。
