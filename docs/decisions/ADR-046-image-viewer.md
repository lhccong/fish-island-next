# ADR-046：微信式图片查看器

状态：采用。日期：2026-11-13。

## 原因与方案

聊天和鱼小圈的普通图片弹窗缺少缩放、旋转及连续查看能力。新增无业务依赖的 shared/ui/ImageViewer，复用 Radix Dialog、Button 与语义颜色；顶部紧凑工具栏、居中画布，手机重排两行并保留安全区。Dialog 增加可访问标题的视觉隐藏选项。

查看器提供前后切图、按需展开缩略图、缩放、适应窗口、1:1、旋转、鼠标/触屏拖动及双指缩放、打开原图。浏览器不提供桌面微信的置顶、窗口最小化、OCR、编辑能力，不展示这些入口。原图通过独立窗口打开，由浏览器提供保存能力，不把跨域下载伪装为可用功能。

聊天仅在打开时读取当前内存消息的图片快照，不订阅整个消息流、不拉取额外历史，不加载已撤回图片；鱼小圈只传入当前媒体组。切图重置几何状态，主题/模式切换不重挂载、不请求业务数据。图片保留原色。加载失败提供重试；空集合提供空状态。

## 影响与替代方案

不引入依赖、状态库、图片处理服务或新的外壳。相比各业务复制工具栏，共享组件统一触控、键盘、焦点归还与明暗适配。相比引入第三方查看器，保留现有 Radix 和主题技术栈。

## 验证

执行 npm run check；合成数据浏览器测试覆盖全部注册主题 × 明暗 × 桌面/375px/390px，检查加载、错误重试、空状态、图片切换、缩放旋转、拖动、键盘关闭与焦点返回、草稿和连接保持、无横向溢出。真实手机与外部图床另行列明验证限制。
