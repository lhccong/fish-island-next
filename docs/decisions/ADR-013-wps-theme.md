# ADR-013：WPS 表格主题

状态：已采用。日期：2026-11-11。

## 原因与决策

用户希望根据 WPS 表格截图增加主题。沿用 skinId 与 shellId 分离的约定，在内置注册表加入 `wps`，名称为“WPS 表格”，使用浅灰导航、白色工作区、绿色强调色及浅绿发出气泡，完整配置既有十二个颜色 token。主题选择器和初始化页自动列出新主题，选择后立即应用并保存。

## 影响与替代方案

只新增受信任的内置配置，不增加依赖、token 或第三方导入权限。复用现有响应式工作台和业务组件，切换时保持当前内容与输入草稿。未采用重建电子表格功能区的方案：本次范围为主题配色，不新增表格编辑功能或外壳。

## 验证

执行 `npm run check`。复用主题浏览器用例验证桌面、375px 和 390px 的预览、消息及尾角、导航配色、草稿保留、刷新恢复、切回默认主题、焦点归还、弹窗关闭及页面无横向溢出；覆盖加载、空数据和失败状态的主题切换。
