# ADR-103：迁移小黑屋模拟器

状态：已采用。日期：2026-11-21。

## 原因与决策

旧版 `/game/darkRoom` 嵌入原站托管的 A Dark Room 简中页面。原页面使用固定宽度，并在手机浏览器跳转兼容提示。Next 的游戏目录保留同一路由、免登录和简中玩法，点击后写入最近玩过。复用工作台返回入口，通过独立路由懒加载游戏。

封面、目录卡片右下角的小窗入口和游戏页左上角的返回及小窗入口遵循 ADR-051。整页和浮窗使用同一个游戏组件。小窗打开期间整页暂停挂载游戏并保留返回及小窗入口，避免两个游戏同时写同一个存档。小窗收起后保留现场。关闭小窗后整页从已保存进度恢复。

将上游 [A Dark Room 1.4](https://github.com/doublespeakgames/adarkroom/tree/7ee96fd1083ec86246f818e5118ca00b478e7720) 固定为静态游戏资源，保留原规则、数据、简中翻译、音效和许可。上游游戏自带的脚本依赖仅在隔离文档中使用。适配层导入站点语义颜色，桌面并排、窄屏重排为纵向操作、库存与日志。游戏场景图形保留原貌。游戏界面保留文字冒险的冷却和自定义事件流程，统一调整交互语义、焦点、触控区域和弹层。语言固定为简中，明暗跟随站点。

iframe 只允许执行脚本，不能读取站点存储或账号。features/dark-room 通过专用消息端口提供主题语义变量、本机非敏感游戏存档和同源音效二进制。只接受限定消息与资源路径，不传递账号、凭证或聊天数据。内嵌页面不加载第三方分析。原版存档码可在两端手动导出和导入。

内嵌文档内保留游戏自己的剧情选择与冷却组件，补齐键盘、焦点和禁用语义。游戏内固定简中入口取代旧语言菜单。隔离文档使用固定的 jQuery 3.7.1，并以属性访问取代上游存档逻辑中的动态求值，允许使用严格脚本策略。

## 影响与替代方案

原 URL 跨域嵌入无法重排手机布局、同步明暗或确认游戏引擎已启动。独立改写游戏引擎可能改变后期玩法和存档协议，因此采用固定版本的隔离游戏与适配层。无需新增 npm 依赖、服务端接口或外观规则。音效仅在游玩时加载，主题或模式切换只更新颜色。

## 验证

检查加载反馈、启动失败与重试、开局操作、地图和存档、键盘与触屏。按全部注册主题 × 明暗 × 电脑/375px/390px 验证目录、游戏和返回，以及滚动、语义颜色、窄屏无溢出和外观切换保留当前局。执行 `npm run check`。
