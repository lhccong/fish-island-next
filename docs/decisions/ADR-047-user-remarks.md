# ADR-047：接入账号私有聊天备注

状态：已采用。日期：2026-11-13。

原因：新版缺少旧摸鱼岛的用户备注读写与显示。

决策：domain/chat 定义备注端口，infrastructure/chat 校验旧版 GET /api/userRemark/get 的 content JSON 字典，并以 POST /api/userRemark/save 的 { content } 保存完整字典。app 注入账号级端口，features/chat 独立控制器持有读取、串行保存、取消与错误状态；备注只改变显示，不改消息实体、引用协议或 @ 原昵称。消息菜单与成员名称提供共享编辑弹窗，聊天列表按原名和备注搜索。清空删除对应键。仅服务端确认成功才更新字典；读取失败禁止保存，避免覆盖未知备注。退出/切换账号取消请求并清空内存，不迁移旧版无账号隔离的 localStorage。

影响：全部主题与外壳复用同一逻辑，主题/模式切换保留备注、表单、草稿和连接。消息行只订阅自身发送者的备注，编辑输入不广播消息流。弹窗复用 Dialog、reserved ScrollArea、Button 和语义颜色，手机单列表单。

消息头部保留原有纯文本昵称与时间排版，不将昵称变为 44px 按钮，避免撑高头部或出现悬停色块。消息内通过既有右键/键盘菜单及手机 44px 更多入口设置备注；成员列表保留可点击名称入口。

替代方案：复制旧页面的全局状态和乐观 localStorage 保存会造成账号混用与失败误报，故不采用。后端目前整份覆盖，不支持跨设备并发合并；此变更不修改协议。

验证：适配器与控制器测试覆盖空数据、格式错误、鉴权、取消、失败保留与串行保存；浏览器按注册主题 × 明暗 × 桌面/375px/390px 检查读取重试、编辑、失败重试、清空、搜索、焦点、间距、滚动与无溢出。交付前执行 npm run check。
