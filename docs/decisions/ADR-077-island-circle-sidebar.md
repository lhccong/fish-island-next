# ADR-077：我的海岛手账与鱼小圈侧栏

状态：采用。日期：2026-11-15。

## 决策

按用户参考图，像素主题聊天侧栏使用「我的海岛」标题、设置入口、手账/鱼小圈分段页签、邮筒海岸横幅和紧凑动态流。尽量对齐参考图的尺寸、留白和层级；动态、头像、照片、计数来自现有鱼小圈端口，不使用示例内容冒充真实数据。明暗与窄屏沿用语义变量，手机独立面板提供相同页签。

按用户后续调整，鱼小圈排第一并默认选中；点赞人名行与点赞操作不铺背景，帖子采用低对比度木纹、轻木框与纸面。桌面像素侧栏可见时加载，其他外壳/手机在首次打开面板时加载；已激活后不因外观或页签切换重新取数。

长动态在侧栏默认限制四行，用 ResizeObserver 按实际溢出显示独立的向下/向上图标按钮，支持键盘、触屏、aria-expanded 与焦点。展开只改变该条正文，不收起点赞、评论与更多；主鱼小圈保留原有 500 字展开逻辑。

app 组合我的小岛与鱼小圈的公开入口，两个 feature 互不导入。手账的本机数据继续由原独立 Provider 持有；app 仅管理侧栏页签。鱼小圈侧栏 Provider 首次打开后激活，复用现有 usePage、InfiniteScroll、MomentCard、MomentEditor、Comments、MomentMenu 与媒体查看器，不复制发布、点赞、评论或分页协议。账号级聊天组合持有单一侧栏数据源，桌面/弹窗读取同一份数据；主题、模式和页签切换不重新获取列表或重建聊天连接。

MomentCard 增加 island 呈现变体，头像、作者和时间位于顶部，正文与图像紧随其下，点赞/评论/更多横排；仅用户展开评论时加载评论，避免侧栏初始逐条请求。手账与动态面板保留挂载以保留草稿和滚动，隐藏的滚动续载观察器不继续请求。发布窗口由 Provider 单独持有，关闭与焦点返回由现有共享控件管理。

侧栏账号切换取消请求并重建；追加失败保留已有动态并提供重试；空页/重复页/总数停止规则沿用共享分页。正文使用实际 ScrollArea，保留 reserved gutter 与手机隐藏滑轨。

## 替代方案与验证

不截图覆盖 UI、不引入假动态，不从 app 绕过 fish-circle/index.ts 访问内部组件，也不在我的小岛 feature 中调用鱼小圈。沿用已有领域/通信端口，无新增依赖。

验证全部注册主题 × 明暗 × 桌面/375px/390px：页签与键盘、真实滚动分页及停止、错误重试、发布/点赞/评论/更多、图片查看、切换时草稿和请求/连接保持；用实际截图对照参考图，记录差异与未验证项。
