# ADR-007：当前页面弹窗登录与微信主题强调色

- 日期：2026-11-11
- 状态：采用，更新 ADR-005/006 的表现与登录入口

用户要求移除热榜消息气泡中的可见序号，并使用旧摸鱼岛的弹窗登录形式；随后要求分类选中态与平台缎带采用微信色系。总览排名仍保留，消息详情只显示正文。总览布局保持旧模块，强调色通过现有主题变量改为浅绿选中底、深绿选中文字、微信绿缎带。

登录沿用已接入的账户/邮箱接口和会话控制器，仅将登录入口改为路由弹窗。使用 React Router backgroundLocation 保留原页面和热榜选择状态，在 /user/login 上覆盖旧模块风格的居中登录弹窗。关闭恢复原页面并归还焦点；直接访问登录地址时以热榜为背景；访问受保护页面仍保留 redirect，登录成功进入目标。取消登录不访问受保护内容。

扩展 shared/ui/Dialog 支持受控显隐、可选触发器、自定义内容样式和关闭图标，复用 Radix 的焦点与 Escape 行为，不引入第二套组件库。使用旧弹窗的摸鱼岛标题与副标题，不加入未迁移的注册或第三方登录按钮。手机弹窗限制高度、内部滚动，并验证键盘与关闭入口。
