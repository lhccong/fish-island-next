# ADR-011：补齐内置主题细节配色

状态：已采用。日期：2026-11-11。

## 原因与决策

飞书、钉钉仅覆盖强调色，沿用微信导航、侧栏与绿色发出气泡，导致主题预览和实际消息区细节不完整。保留单一工作台和消息组件，通过受信任的内置配置补齐配色。

内置 SkinTokens 在原七个颜色变量基础上增加 `--color-message-incoming`、`--color-rail-active`、`--color-hover`、`--color-canvas`、`--color-surface`。所有内置主题必须提供全部十二个 token，使用六位十六进制颜色；默认值与微信主题一致。飞书、钉钉显式提供对应的导航、侧栏、双向气泡和交互背景。预览使用与实际组件相同的气泡、画布和输入区变量。

## 影响与替代方案

仅影响外观，不改变布局契约、业务状态、请求或草稿所有权。第三方导入仍仅开放 accent 与 accent-soft，不扩大白名单。没有新增依赖。

未采用按 data-skin 复制组件 CSS 的方案，以免主题散落和预览不同步；未新增平台聊天外壳，当前仍是工作台配色。

## 验证

执行 npm run check；浏览器验证桌面、375px 与 390px 下双向气泡及尾角、导航、侧栏、悬停背景、预览、换肤草稿保留、刷新恢复，以及加载、空数据、失败状态中的主题操作与弹窗关闭。
