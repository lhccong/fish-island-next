# ADR-025：表单滚动区预留滑轨间距

状态：已采用。日期：2026-11-12。

## 原因

个人资料编辑区使用覆盖式滚动条，正文末端仅有 4–6px 内边距，卡片边框、输入框和焦点环贴近滑轨。隐藏滚动条不能解决布局问题，扩大整张弹窗也不能保证窄屏可用。

## 决策与影响

- shared/ui/ScrollArea 新增 `gutter="reserved"` 呈现变体。视口行末预留桌面 24px、手机 20px，使用现有间距 token，预留空间不随滑轨显隐改变。原有密集列表默认保持覆盖式布局，后续触及对应表单/弹窗时按规范整改。
- 滑轨宽 8px，预留后的内容边缘到滑轨外缘分别为 16px、12px；普通视觉间距最低桌面 12px、手机 8px，另容纳 4px 焦点描边空间。正文起始及顶部预留至少 4px，避免焦点环被视口裁切。
- 个人资料表单采用预留变体，移除自身重复的末端补丁；标题、关闭入口、底部操作与错误提示保留在滚动区之外。业务、请求、草稿和焦点语义不变，不新增依赖。
- 不全局压缩来源列表、消息列表等已有密集区域；不通过隐藏滑轨、透明遮罩、负边距或减小触控控件掩盖问题。原生 scrollbar-gutter 无法为 Radix 覆盖式自绘滑轨提供所需空白，因此采用明确的布局预留。

## 验证

执行 npm run check。全部注册主题 × 明亮/暗夜模式 × 桌面、375px、390px，覆盖个人资料的 loading/empty/error/success 和完整操作；断言正文与滑轨间距、横向无溢出、首末控件焦点环空间及固定操作栏可触达。截图检查顶部、中部、底部，不能仅凭滚动条默认隐藏判定通过。
