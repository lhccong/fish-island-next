# ADR-004：固定热榜卡片与微信演示输入区

- 日期：2026-11-11
- 状态：采用，更新 ADR-003 的呈现细节

按用户要求，总览卡片统一高度，内部通过 ScrollArea 显示完整榜单，标题与底部进入消息详情。移除主内容页头的搜索与刷新控件，保留来源搜索、分类与错误重试。

消息详情采用小尺寸灰色左气泡、平台头像和居左的紧凑消息间距，去除卡片式排名/热度分区。来源更新时间仍真实显示。通过 WorkspaceShellSlots.footer 放置独立演示输入区，与消息滚动容器分离，避免整个输入区被滚走。演示区可输入文字，工具与发送按钮不绑定服务，明确标注演示；用户已授权使用假交互，不制造真实发送结果。

卡片外观使用更柔和的 12px 圆角；手机卡片高度适当缩短，消息区域随 100dvh 调整，输入区考虑底部安全区域。验证桌面、375px、390px 的内部滚动、消息详情、返回、演示输入与失败/空数据状态。
