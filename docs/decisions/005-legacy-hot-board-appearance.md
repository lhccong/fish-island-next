# ADR-005：复刻旧摸鱼岛热榜总览

- 日期：2026-11-11
- 状态：采用，替代 ADR-004 的总览卡片表现

用户明确要求红框内总览完全参考旧摸鱼岛热榜模块。以旧项目 src/pages/Index.tsx（桌面 Card / List / Badge.Ribbon）及 Index.less 为实现参照：16px 网格间距、白色卡片、平台 20px 图标、14px 常规标题及同行 12px 相对更新时间、蓝色平台缎带、12px 正文内边距、400px 内滚动榜单、前三名红橙金排名方块、后续灰块、单行省略标题与火焰热度。移除新加的宣传行、卡片分类副标题和底部栏。保持原文链接，并通过卡片标题进入现有消息详情。

保留可横向滚动的胶囊分类栏与设置入口；设置允许在本次页面会话中选择总览显示的来源，关闭或恢复全部来源均可操作。响应式网格：桌面三列、中屏两列、手机一列。来源侧栏和微信消息详情保持现有行为。使用 CSS Modules 和局部语义 token 复刻外观，不为视觉复刻引入整套 Ant Design，也不复制旧页面业务或广告。

领域 HotSource 增加 badgeLabel，对接旧响应 typeName，缺失时回退来源名。时间格式化与热度处理保持纯函数，并验证置顶 0 值及空值。400px 滚动区域在手机端同样保持可读与可操作。
