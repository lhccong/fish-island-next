# ADR-038 HTTP 群聊发送

日期：2026-11-13。采用。

## 原因与范围

客户端只提交正文、可选引用 ID 和 clientMessageId，不提交身份、称号、等级、地区或时间。HTTP 负责发送，既有 WebSocket 继续接收并广播给包含本人在内的所有连接，旧 WS 发送协议保持兼容。

## 决策与影响

- domain 增加发送端口；infrastructure 适配 POST /api/chat/message/send；feature 独立发送用例拥有取消、临时消息和失败重试，app 注入。草稿与归一化消息状态保持分离。
- 后端从会话、用户资料、积分/VIP 与当前请求 IP 拼装 Sender；引用从公共房间历史读取并裁掉嵌套引用。定位失败使用未知地区，不阻断发送。校验登录、封禁、禁言、空白和 5000 字上限，保存成功后全员广播并返回同一实体。
- 复用已有 Redis/Redisson：账号与 clientMessageId 作用域锁、七天发送回执与 ID 预留，重试沿用原消息 ID。全局递增毫秒 ID 兼容旧版时间戳消息 ID 与历史游标，避免改用雪花 ID 破坏历史顺序。回执对应已删除消息时拒绝重发。不是永久 exactly-once 或跨实例 WS 广播的承诺；既有连接表仍属单进程。
- 本地消息立即显示，左侧转圈表示 HTTP 尚未结束；失败保留正文并显示重试。请求和广播任意顺序按 clientMessageId 合并，保持临时渲染 key，服务端字段覆盖本地预览。HTTP 超时后如已收到广播，以确认实体为准。账号退出取消请求并清空状态，主题/模式/路由变化不重发。
- 桌面 Enter 发送、Shift+Enter 换行，输入法组合不发送；手机 Enter 换行，使用发送按钮。主动发送跟随到底部。临时/失败消息不提供引用或撤回菜单，避免引用未落库 ID。
- 不新增依赖或复制旧页面。引用仅发 ID；@TA 保留现有可编辑文本语义，机器人按旧版正文 @摸鱼助手 触发。

## 替代方案

不继续 WS 发送，不信任客户端完整 Sender；不按正文去重（相同正文可以合法重复发送），不把临时 ID 替换成服务端 key 引起列表重挂载。数据库新增唯一发送键可提供更长期保证，留待独立迁移。

## 验证

单测覆盖发送合并顺序、失败重试、取消隔离、协议错误；后端 mock 测试覆盖身份补全、引用、禁言、保存/全员广播、幂等。浏览器覆盖全部注册主题 × 明暗 × 桌面/375/390 的空、发送中、成功、失败重试、引用、滚动、输入法和无横向溢出。运行 npm run check；实际执行结果与限制记录在 docs/audits/chat-send.md。
