# ADR-074：摸鱼岛像素风主题

状态：采用。日期：2026-11-15。

## 原因与方案

依据用户确认的像素海岛 UI 概念图，增加 `pixel-island` 内置主题。以薄荷海色、奶油纸面、低圆角和像素框线组织真实热榜、聊天与发现入口，插画仅作装饰，不伪造频道、人数、消息或功能。

app 显式映射 `pixel-island` 到同名外壳标识，复用 WechatShell 稳定的 slots 与业务组件，仅以 `island` 呈现变体调整布局。热榜、聊天、发现根页的海景铺满既有标题栏，以透明语义色遮罩确保文字可读；不新增横幅、品牌栏或标题栏高度，聊天消息与输入区保持原高度。桌面导航使用自有像素图标、阶梯框线与海岸装饰，侧栏增加像素列表框线和低透明度岛屿。手机保留既有分层导航，不额外占用软键盘与正文空间。

热榜通过 app 注入 `island` 呈现，复用同一请求、筛选与卡片组件。海景以低透明度伪元素铺在内容区域下方；卡片采用现有 `color-pixel-paper/ink/wood` 明暗变量，提供木板边框、标题木牌与纸面正文。普通按钮仍使用主题 action。装饰不捕获指针，也不加入读屏内容。

热榜来源详情同样接收 island 装饰，其只读消息采用相同纸面/木板变量；不改链接、来源切换或演示输入状态。来源栏在标题下显示独立的树木、小屋与钓鱼海景，并以木框组织来源条目；该场景只占来源栏，不增加主内容页头高度。手机来源选择 Dialog 使用同一纯装饰组件，保留搜索、reserved 滚动正文与固定关闭入口，低高度时压缩装饰。

聊天由 app 注入独立 `decoration="island"`，仅在消息区背景显示同一低透明度海景，输入区保留实色；不改变消息 presentation、虚拟列表、行订阅或历史加载依赖。装饰不增加布局尺寸、不随消息重复挂载，也不改变原有滚动容器。

基础十二色 token 保持契约；新增受信任内置呈现 token 类型，仅覆盖文字、边框、滑轨、面板、圆角及阴影，不开放第三方导入权限。SkinProvider 同时应用和清理呈现 token，离开主题恢复原默认值。明暗独立，暗夜以 #191A1C 为画布；插画原色保留，无滤镜、持续动画、新字体或依赖。

## 影响与替代方案

手机聊天标题栏保留可触达的主题入口，可就地换肤和切换明暗，无需离开聊天路由。

不复制聊天、导航、请求、分页或状态逻辑。切换主题保持已有输入、列表与连接实例。未采用独立聊天页面（会复制业务），也未将整张概念图作为背景（文字不可交互，手机不可用）。共享控件继承主题语义变量，普通按钮保持既有紧凑尺寸。

主题选择弹窗增加第六个选项后采用固定头尾与 reserved ScrollArea，避免窄屏/低高度遮挡关闭入口；像素选项展示真实海岛资源预览。

## 验证方式

执行 npm run check。Playwright 按全部注册主题 × 明暗 × 桌面/375px/390px 验证主题选择、加载/空/失败/成功、布局边界、滚动、键盘关闭及焦点返回；检查聊天草稿、消息、请求和连接在外观切换期间保持，刷新恢复偏好。截图核对像素主题桌面与手机比例。结果及未覆盖范围记录在 docs/audits/pixel-island-theme.md。
