# ADR-010：鱼小圈迁移

状态：采用。日期：2026-11-11。

## 原因与选择

复用旧后端 `/api/moments` 协议，新增 domain/fish-circle 端口、infrastructure/fish-circle HTTP/解码适配、features/fish-circle 业务界面。app 注入会话凭证读取与过期恢复，按账号重挂载功能，路由 `/moments/fish-circle` 懒加载且要求登录。工作台沿用微信外壳，侧栏名称支持业务自定义。

后端 JsonConfig 将 Long（包括分页 total）序列化为字符串，适配层兼容字符串总数并保持 ID 为字符串。列表和评论分别分页；评论、草稿、上传、操作弹窗状态归所属组件。请求支持取消与超时，写操作只在后端确认后提示成功，点赞返回值表示当前点赞状态。图片地址仅允许 HTTP(S)，正文纯文本；不执行旧 HTML。沿用 Minio `user_post` 上传。编辑保留原可见范围，不把私密动态改为公开。

## 影响与替代方案

不新增依赖。拒绝直接复制旧单体页面及 Ant Design/moment 依赖。提供动态浏览、个人筛选、图文发布编辑、图片预览、点赞、评论回复删除置顶、动态删除置顶、积分打赏、点赞抽奖和关注。兼容旧版 `[img:url]` 图片评论，解码时仅接受 HTTP(S)。旧版表情包搜索尚未迁移，界面不展示入口。分页采用服务端页码，不宣称实时一致性；刷新会从第一页读取，不无限保留旧页。

## 验证

执行 npm run check。单元验证协议映射、错误和取消；Playwright 在桌面、375px、390px 验证列表加载、空、失败重试、分页、发布、点赞、评论、编辑删除、弹窗关闭和横向溢出。测试使用合成数据；未使用真实账号执行积分消耗或发布。
