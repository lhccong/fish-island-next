# ADR-075：本机「我的小岛」面板

状态：采用。日期：2026-11-15。

## 原因与边界

按用户提供的侧栏方案，像素主题聊天页用「我的小岛」替代本地伪装会话列表。支持岛名、寄语、小屋装饰、待办、自动保存随手记、快捷功能/链接，以及模块排序和显隐。默认待办与笔记为空，不预填用户内容；默认快捷入口只指向已经接入的功能。原聊天列表保留手机入口；其他主题的侧栏不变。

domain/my-island 定义纯模型、限制、URL 校验与偏好端口；infrastructure/my-island 实现带版本、按账号隔离的本机存储；features/my-island 持有独立 store、保存定时器和编辑界面，app 注入存储、账号和导航。无服务端请求、新依赖或跨 feature 内部访问。存储失败明确提示并可重试，卸载前刷新待保存内容；不把本机状态当作云端同步。

独立 Provider 位于账号聊天组合内，切换主题仅更换纯呈现，笔记、待办、快捷入口不进入聊天消息或草稿 store。自动保存使用 400ms 防抖，小岛各模块精确订阅，输入随手记不更新聊天列表。模块管理使用按钮调整顺序与共享 Switch 显隐；外链只允许 HTTP(S)，站内链接必须为同源绝对路径，拒绝脚本与协议相对 URL。

桌面为固定标题、reserved ScrollArea 正文和本机保存反馈；手机通过标题栏入口打开独立 Dialog，同一 store、固定头尾、触控高度和安全区。编辑和模块管理复用 shared/ui 的 Dialog、Select、Button、Switch；不叠加原生系统菜单。所有主题明暗均可使用手机/通用面板；像素主题自动呈现桌面侧栏。

聊天木板气泡由消息区的装饰标识和 CSS 选择器呈现，不增加行订阅或修改实体。使用既有 pixel 纸面/木板语义色，区分自身消息；图片、红包、福袋和撤回保留原有语义与样式。

快捷码头统一使用 shared/ui/PixelIcon 的自有像素 SVG：农场、伙伴、游戏、阅读、鱼小圈、热榜及自定义链接均有对应图形。显示尺寸统一 32px，禁止用整张插画的缩略图或局部裁切充当图标；标签可换行，图标不收缩，手机入口保留至少 44px 高度。使用现有语义颜色，不增加图标依赖。

## 替代方案与验证

不把小岛数据塞入页面或消息 store，不复制一套聊天界面，也不通过 DOM 隐藏原列表保留额外请求。验证模型边界、账号隔离、保存失败和防抖；全部主题 × 明暗 × 桌面/375px/390px 验证面板核心交互、模块显隐与顺序、刷新恢复、外观切换、布局与焦点。执行 npm run check，结果记录至 pixel-island-theme 审计。
