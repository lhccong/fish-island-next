# ADR-102 聊天室大肥鱼

日期：2026-11-19。状态：已采用。

## 决策

大肥鱼是公共聊天室里的角色。后端在 HTTP 或旧 WebSocket 消息保存成功后匹配正文子串 `肥鱼`，覆盖 `大肥鱼` 和带 `@` 的写法。少量普通文字消息可进入插话候选。Redis 对触发消息去重，并对用户开启对话和群内插话分别限频。模型可放弃插话。模型调用使用独立的有界任务队列，对话在队列满时收到失败反馈。pre 环境通过 `application-pre.yml` 的 `fish.big-fish.api-key` 配置 DeepSeek，默认读取服务端 `DEEPSEEK_API_KEY`，未设置时留空。模型默认 `deepseek-flash`，可通过 `fish.big-fish.model` 调整。

同一用户首次命中关键词时开启 10 秒滚动续聊窗口，发言间隔不超过 10 秒的普通跟进也会更新最后发言时间并触发回复。模型请求按用户串行，上一批生成期间收集的短句合并发出，带最近六条本轮发言与台词。HTTP 与旧 WebSocket 均从已认证用户读取公开昵称，在模型上下文中将昵称、正文与引用标为独立文本字段。大肥鱼开口时根据当前发言人的昵称自然称呼，缺少昵称时称为「岛友」。独立的本机内存缓存有长度、数量和时效限制，按用户隔离，间隔超过 10 秒后通过关键词另开一轮。明确引用来自已认证的 HTTP 发送链路。长期记忆暂不接入，多实例部署依赖现有同一聊天室消息处理节点，短期上下文不跨实例同步。

复用已认证账号的 WebSocket。下行类型 `bigFish` 的 `data` 包含触发消息 `id`、`roomId`、`status` 和 `text`。公共室 `roomId` 为 `-1`。`thinking` 和 `error` 仅通知触发续聊的用户。成功台词以独立消息 ID、服务端角色身份及 `bigFish` 标记保存到现有房间消息表，再使用 `speech` 帧附带已保存的 `message` 广播。保存失败不广播成功台词。infrastructure 将实时及历史台词映射为同一种角色消息，列表沿用按消息 ID 合并与滚动分页。发送区按触发消息 ID 内联反馈等待和失败。客户端发送的内容不能指定角色身份或标记。

成功回复以 10% 的概率查询用户 1 的收藏并随机选取一张表情包。服务端只读取选中的 HTTP(S) 图片地址，以可选 `bigFishEmoticonUrl` 字段随台词保存和广播。收藏为空、地址无效或读取失败时仍发送文字。前端复用聊天图片的预览、加载和失败反馈，紧凑工作表使用既有图片展开控件。

历史满页以最后一条消息的 ID 作为游标。大肥鱼台词处在页尾时，原样传回已保存的字符串 ID，后端在同一房间定位记录后沿用 `(createTime, id)` 分页。实时帧使用台词 ID 合并同一条历史记录，外层触发消息 ID 用于发送区反馈。

角色使用用户提供的 `https://oss.cqbo.com/moyu/pet/dapangyu.webp` 图集。普通聊天将放大的角色居中放入与普通消息一致的头像列，昵称和时间从共用起点排列。台词使用当前主题的默认接收气泡。工作表在台词所在单元格内并排展示角色与气泡，窄屏和紧凑工作表按可用宽度缩放。点击或用键盘激活头像、昵称时，沿用聊天草稿提及功能追加 `@大肥鱼` 并聚焦编辑器。可见消息行装载角色后播放短帧动画，保持每帧布局一致，减少动态效果偏好展示静帧。台词、时间与角色同属消息行。

## 替代方案

浮层会遮挡聊天内容。单独建表会重复房间分页、排序和撤回能力，当前使用群聊消息的服务器标记呈现角色形象。独立 AstrBot 服务可提供媒体与长期记忆，当前范围采用已有后端和 DeepSeek 文本接口，省去额外服务与运行时依赖。

## 管理开关

管理页通过现有 admin 端口读取及保存 `/api/admin/big-fish/settings`，读写均要求管理员权限。启用状态存于 Redis 的 `chat:big-fish:enabled` 键，无过期时间，键缺失时默认开启。管理员明确保存后生效。大肥鱼工作线程在使用关键词、续聊或插话时读取状态，模型返回后再检查一次，关闭时丢弃尚未保存的台词并结束已经开始的等待反馈。Redis 读取故障沿用任务失败处理。相比静态 YML 或进程缓存，共享 Redis 允许管理员即时切换，聊天正常发送路径无需新增 Redis 读取。

## 验证

后端测试覆盖关键词命中、带 @ 的写法、10 秒滚动续聊边界、昵称来源和缺失回退、普通消息预筛、限频、模型静默、先保存后广播、收藏来源及取图失败，以及开关默认值、关闭时静默、待生成台词处理。前端覆盖畸形与重复帧、输入区等待和错误、角色对齐及默认气泡、短动画及减少动态效果、实时和历史表情包、紧凑单元格展开、头像和昵称提及，以及设置加载失败、保存失败重试和刷新回读。按全部注册主题 × 明亮／暗夜 × 桌面／375px／390px 验证，执行 `npm run check`。合成模型和 WebSocket 测试与线上联调结果分别记录。
