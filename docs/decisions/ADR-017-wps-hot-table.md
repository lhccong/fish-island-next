# ADR-017：WPS 热榜多维表格

状态：已采用。日期：2026-11-11。

## 原因与决策

用户要求 WPS 热榜参考多维表格，并修复主题按钮出界。app 根据内置外观选择向 HotBoardWorkspace 注入 cards/table 呈现变体，功能模块不订阅其他 feature 的外观 store。保持同一热榜请求生命周期、来源选择和草稿组件，切换展示不触发重取；WPS 隐藏演示输入区但保持已选来源的草稿挂载。

WPS 热榜使用全宽网格表格，提供排名、标题、来源、分类、热度、更新时间列，工具栏提供实际可用的查找、来源/分类筛选、排名/热度排序和刷新。没有数据的字段显示破折号，不提供虚假的新增、编辑或导出功能。加载、空数据、查找无结果、失败与旧数据反馈显式呈现。手机保留排名、标题和标题内来源标签，隐藏次要列，不依赖整页横向滚动。隐藏侧栏属于布局参数，不复制外壳或请求逻辑。

主题按钮原最小宽度 52px，加上父级左右各 4px 内边距超过 52px 网格列。主题列改为 60px，父级 min-width: 0，触发按钮宽度约束在可用空间内；验证按钮和焦点均在工具栏及视口内。

## 影响与替代方案

不增加依赖、第三方 token 或表格编辑内核。其他主题保持卡片与消息呈现。未采用复制热榜请求或单独路由方案，以避免换肤重取和状态分叉；未引入电子表格库，因为本需求是只读数据展示。

## 验证

执行 npm run check；桌面 1920px、1280px 与手机 375px、390px 验证表格展示、长标题、查找、筛选、排序、刷新与失败重试、空数据及加载状态、链接、模式切换草稿保留，以及主题按钮边界、弹窗关闭和焦点归还。保存截图。
