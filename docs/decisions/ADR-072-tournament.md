# ADR-072 武道大会迁移

状态：已采用。日期：2026-11-15。

## 原因与方案

旧版 `/point/tournament` 提供每日排位、空位挑战、对手资料及战斗记录。现有 pet 端口已具备协议，但排位仅藏在伙伴面板且空榜无法挑战。武道大会归入伙伴营地，与 Boss、爬塔并列提供入口；复用 ChallengePanel 与 TournamentPanel，不创建独立业务页面。旧地址跳转到 /pet?challenge=tournament，按需打开伙伴挑战面板。

榜单端点会自动为有宠物的用户入榜，故先读取榜单再读取本人名次，避免并发返回旧名次。沿用 pet domain/infrastructure，严格遵循服务端仅能挑战更高名次及每日十次限制；不伪造剩余次数、积分或成绩。空位成功允许无回合。提交失败保留反馈；传输结果不明时要求关闭并刷新名次确认，不自动重发。

## 影响与替代方案

app 负责路由、鉴权和服务注入；feature 独立管理榜单、挑战和资料弹窗。拒绝复制旧 Ant Design 页面或另建排位通信模块；不新增依赖或连接。协议返回完整榜单，无分页接口，完整显示已返回排名并补足前十空位，不引入前端翻页。

桌面前三席采用三列，窄容器及手机转纵向，榜单使用共享主题语义色；确认及记录复用 reserved ScrollArea，关闭返回触发焦点。主题及模式不参与请求依赖，不重置挑战状态。

## 验证

执行 npm run check，协议测试覆盖顺序、空位与有回合结果；浏览器验证全部注册主题 × 明暗 × 桌面/375/390 的加载、空榜、失败重试、挑战、资料、滚动与焦点。真实账号比赛不作为自动测试数据，验收限制记录于交付说明。
