# ADR-086 气泡操作栏与消息举报

日期：2026-11-16。采用。

## 原因与决策

用户需要悬停气泡即可发现复读、引用、举报、撤回。MessageMenu 的同一动作定义同时服务上下文菜单和图标栏；桌面图标栏位于气泡下方，预留高度以免悬停改变虚拟列表测量，键盘聚焦可见，粗指针桌面常显，图标命中区域 44px（桌面紧凑尺寸例外见下文）。手机隐藏图标栏，以已有长按菜单提供操作。保留桌面更多菜单、长按、右键及原有权限；不可执行的常用动作禁用并说明原因。全部外壳使用现有语义 token，包含 WPS 工作表与聊天小窗。

举报经 domain/chat 的 ChatReportPort、infrastructure/chat 的旧协议适配和 app 注入，GET /api/report/reasons、POST /api/report/add，reportType=1，ID 保留字符串。仅打开时读取原因，独立 ChatReportProvider/MessageReportDialog 持有选择和请求；卸载/账号切换/关闭取消请求，提交串行、失败保留表单并允许重试，服务端确认后才提示成功。不把弹窗状态放入消息 store，不为每条消息挂载弹窗，不增加连接。

## 影响与替代方案

手机误触与拖动修正：760px 及以下隐藏整组气泡快捷操作（含更多），不预留工具栏高度，使用已有 Radix 长按菜单；桌面仍保留悬停、聚焦、右键和键盘入口，粗指针桌面仍保留触控尺寸。触摸开始即暂停自动跟随，触摸结束不强制跳底；向上滚动优先退出跟随，即使仍处于底部 64px 阈值内。继续向下到达底部或主动发送/查看最新时恢复跟随。监听器使用 passive 并在卸载时释放，不阻止原生触屏滚动。不采用缩小手机更多按钮或阻止触摸默认行为的方案。验证全部主题明暗及桌面/375px/390px 的短按、拖动取消长按、长按菜单、关闭/焦点、连续滚动与新消息不抢位。

不采用每种外壳各写一套操作或复制旧页面；不采用只在更多菜单中提供入口，也不显示文字链接代替所需图标。保留已有红包/福袋复读与撤回限制及管理员权限，服务端最终校验。举报不自行增加默认原因，不伪造提交成功。不引入依赖，不改变主题协议或草稿生命周期。

## 验证方式

执行 npm run check，举报适配测试及浏览器矩阵：全部注册主题 × 明暗 × 桌面/375px/390px；验证悬停/聚焦、手机操作、引用与复读保留草稿、撤回权限/等待/确认、举报 loading/empty/error/success/重试/取消、菜单键盘与焦点、无横向溢出。测试产物在独立临时目录内，验证后清理。实际执行范围与限制在交付中报告。

用户随后反馈工具栏过大：桌面按明确要求改为 14px 图标、26px 按钮，移除工具栏外框和底色，作为桌面 44px 图标命中规范的局部例外；手机及粗指针保留 44px 触控区域。

后续收紧消息纵向间距：普通会话及经典外观桌面行上下留白统一为 4px，手机为 6px，气泡与操作栏之间不另加外边距。保留操作栏本身的稳定高度，避免悬停引发虚拟列表跳动；WPS 工作表继续沿用网格布局。通过相邻消息首行起点与前一气泡底边的布局断言检查间距，桌面不超过 36px、手机不超过 58px，覆盖全部主题明暗和桌面/375px/390px。

2026-11-16：`npm run check` 通过（104 个测试文件、421 个单测，生产构建成功；构建仍有大块与鱼小圈混合静态/动态导入警告）。`chat-hover-actions` 的 42 项 Chromium 浏览器测试通过，覆盖摸鱼岛、像素岛、WPS、微信、企业微信、飞书、钉钉 × 明暗 × 1280px 桌面/375px/390px；断言无边框、透明背景、图标与按钮尺寸、悬停不改变行高、引用保留草稿、举报加载/空/失败/提交中/重试/成功、管理员撤回等待与确认、焦点及无横向溢出，抽查实际截图。

摸鱼岛明亮模式下另有 15 项回归通过，覆盖桌面/375px/390px 的原菜单、复读发送/重试、管理员撤回他人及超时重试、普通账号和红包/福袋限制。动作使用稳定 shortcut 标识，避免展示文案影响图标关联；快捷引用后清理菜单的待返回输入框标记，避免下一次 Esc 错误返回草稿。

浏览器测试使用合成账号及拦截接口，不操作真实聊天。未验证真实管理员账号/线上服务的授权状态、实际举报入库、真机软键盘、跨浏览器及长时间聊天性能。测试截图、追踪与临时结果不作为交付物，提取结论后清理。
