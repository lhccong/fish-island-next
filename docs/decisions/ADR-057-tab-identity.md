# ADR-057 标签页名称与图标本地偏好

状态：已采用。日期：2026-11-14。

## 原因与方案

迁移旧摸鱼岛网站设置的标签页名称和图标能力。appearance feature 独立持有标签页偏好及编辑表单，沿用该模块已有的本地偏好持久化方式；app 的 TabIdentityProvider 负责 document.title 与 favicon DOM 副作用。入口置于主题弹窗内，游客也可使用。偏好与主题、明暗模式、账号及路由独立，不触发请求、重连或重置草稿。

仅保存名称与图标到 fish-island:tab-identity；写入成功后才应用，存储失败保留编辑内容并反馈。名称去除首尾空白、限制 60 字；图标允许 HTTPS 地址或本地 PNG/JPEG/WebP/ICO（最多 256 KiB），本地文件读取为 data URL，不上传服务端。校验格式并验证图片可解码后再保存；损坏的本地配置回退默认。恢复默认先更新表单，保存后生效。不迁移旧版其他网站配置，不修改公开 SEO 元数据。

## 影响与替代方案

不新增依赖、公共业务端口或皮肤权限。相较复制旧版账号菜单和上传接口，本方案独立于登录、不会上传图片；相较添加全局导航按钮，复用主题入口避免挤压手机导航。在线地址仍需浏览器加载；本地图片可离线恢复。暂不提供在线图标目录或跨设备同步。

## 验证

执行 npm run check；测试非法/损坏配置、存储写入失败和恢复；浏览器按注册主题 × 明暗模式 × 桌面/375px/390px 验证编辑、图片加载/失败、保存恢复、取消、键盘关闭与焦点返回、正文滚动和无溢出，并检查主题切换不丢编辑内容。
