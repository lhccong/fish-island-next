# ADR-065 账号下拉功能迁移

日期：2026-11-14。状态：采用。

## 原因与范围

迁移旧头像菜单的十三个入口，复用当前资料编辑、网站身份设置、外观状态与退出用例。新增 account-tools 领域端口、HTTP/本地存储适配和按需加载的功能面板；app 负责组合，禁止跨 feature 导入。开放平台保留旧应用管理协议，Secret 仅在用户主动查看时请求并短暂存于组件内，关闭即释放，不持久化。

本地黑名单按账号隔离，通过 domain 端口注入聊天行与消息菜单，行精确订阅屏蔽状态，不删除历史实体、不改变分页与草稿。旧浏览器全局黑名单只读导入当前账号，不删除原数据。工作时间是本机计时工具，不能伪称服务端考勤；位置重置恢复计时工具位置及已打开共享浮窗的边界，不重挂载业务。

老板键保留 F1～F4 跳转 HTTPS/HTTP 网址的行为；手机提供显式执行入口。网站引导介绍已接入入口，不宣称旧版未迁移能力可用。网站设置复用现有名称与图标表单，布局和主题通过既有主题入口设置，不引入旧版无对应能力的开关。

## 替代方案与影响

拒绝复制旧 AvatarDropdown 巨型组件及 Ant Design。独立面板避免输入、弹窗和聊天列表共用状态。新增本机偏好仅保存在明确命名的浏览器键中，存储失败向用户反馈。账号切换取消请求并释放面板，主题和模式切换不触发请求、重连或清空草稿。

## 验证

执行 npm run check；接口适配单元测试覆盖鉴权、错误和旧协议。浏览器使用合成账号与请求夹具，按全部注册主题 × 明暗模式 × 1280/375/390 验证菜单、表单、列表、异常恢复、键盘、触屏、滚动与焦点。真实邮箱、兑换码和应用创建不在验收中调用，交付明确说明限制。临时产物使用独立目录，验收后清理。
