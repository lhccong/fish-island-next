# ADR-065 账号下拉功能迁移

日期：2026-11-14。状态：采用。

## 原因与范围

按用户确认排除老板键与位置重置，迁移旧头像菜单其余十一个入口，复用当前资料编辑、网站身份设置、外观状态与退出用例。新增 account-tools 领域端口、HTTP/本地存储适配和按需加载的功能面板；app 负责组合，禁止跨 feature 导入。开放平台保留旧应用管理协议，Secret 仅在用户主动查看时请求并短暂存于组件内，关闭即释放，不持久化。

本地黑名单按账号隔离，通过 domain 端口注入聊天行与消息菜单，行精确订阅屏蔽状态，不删除历史实体、不改变分页与草稿。旧浏览器全局黑名单不自动归属新账号，避免串号；原数据保留。工作时间是本机计时工具，不能伪称服务端考勤，保留单休、双休、大小周和收入估算，不接入节假日调休。

网站引导介绍已接入入口，不宣称旧版未迁移能力可用。网站设置复用现有名称与图标表单，布局和主题通过既有主题入口设置，不引入旧版无对应能力的开关。

工作时间使用 WorkspaceShellSlots.status 独立状态行，由 app 注入并在当前外壳内单次挂载。替代旧版悬浮按钮，避免遮挡聊天发送、手机输入与游戏操作；隐藏后归还布局空间。计时更新只发生在自身组件中，不驱动页面、消息或草稿重渲染。

## 替代方案与影响

### 视觉整理（2026-11-14）

账号工具按内容使用不同尺寸：兑换与引导为紧凑弹窗，资料与名单为中等面板，开放平台使用较宽的管理面板。标题、说明、正文与操作区明确分开，短内容不再套用 700px 高度；长内容保留 reserved ScrollArea。应用的操作跟随所属应用，创建入口置于列表顶部；个人卡片以头像、姓名、简介和统计表达层次。手机按单列重排，并保持 44px 触控、全部主题与明暗模式的语义颜色。仅调整呈现，不改变接口、账号、草稿或请求生命周期。

拒绝复制旧 AvatarDropdown 巨型组件及 Ant Design。独立面板避免输入、弹窗和聊天列表共用状态。新增本机偏好仅保存在明确命名的浏览器键中，存储失败向用户反馈。账号切换取消请求并释放面板，主题和模式切换不触发请求、重连或清空草稿。

## 验证

执行 npm run check；接口适配单元测试覆盖鉴权、错误和旧协议。浏览器使用合成账号与请求夹具，按全部注册主题 × 明暗模式 × 1280/375/390 验证菜单、表单、列表、异常恢复、键盘、触屏、滚动与焦点。真实邮箱、兑换码和应用创建不在验收中调用，交付明确说明限制。临时产物使用独立目录，验收后清理。

### 工作时间悬浮球（2026-11-15）

按用户要求，以可拖拽悬浮球替代固定状态行，继续由现有 app 宿主单次挂载，不改变依赖或计时状态边界。悬浮球显示当前阶段和倒计时，环形进度表示当日班次进度；点击进入原设置，正文先展示已保存作息的今日概览，再编辑设置。所有颜色沿用语义变量。

位置以可用视口内的比例保存到本机，窗口缩放时保持可达；手机避让底部导航与安全区。鼠标和触屏使用 Pointer Events，超过拖动阈值后阻止误开设置；方向键提供无需拖动的移动方式。存储不可用时仍可在本次会话移动。隐藏再显示及主题/模式切换保留位置和草稿，不新增请求。保留固定状态行的替代方案因不符合用户期望而不再采用。

验证覆盖全部注册主题 × 明暗 × 1280/375/390，检查拖动、点击、键盘移动、边界、刷新恢复、设置与反馈、焦点返回及滚动间距。此功能仅本机计算，无异步 loading 或服务端空数据状态；覆盖休息、上班前、午饭前、下班前、已结束、无薪资和有薪资、保存成功及失败。

### 像素化呈现（2026-11-15）

保留 80px 悬浮入口及原拖拽坐标、键盘移动和位置存储，外轮廓按用户后续要求保留平滑圆形；以本地 SVG 呈现咖啡杯、公文包、餐碗、时钟和小屋，分别对应休息、上班前、午饭前、下班前与下班后。底部五格刻度表示班次进度。图标为装饰，文字状态保留；无需图片请求、字体或新依赖。使用 surface/border/accent-soft/accent-text 语义变量提供圆形轮廓、轻量投影、悬停和图标颜色，焦点环不裁切，不引入持续动画。全部注册主题、明暗模式和桌面/375/390 视口复用同一实现与业务状态。

### 侧边吸附与自动收起（2026-11-15）

按用户要求增加类似桌面悬浮球的侧边收纳：松手位置距离左右可用边界 40px 内时吸附到该侧，保留纵向位置；中间位置仍可自由悬浮。默认右侧。贴边后空闲 2.5 秒收成 44×64px 半球入口，桌面移入即展开、移出后延时收起；触屏首次点按仅展开，展开后再次点按打开原设置。圆形外观、像素图标与进度刻度继续使用现有主题语义变量。

拖动、鼠标停留、键盘聚焦或设置打开期间不自动收起。方向键继续移动，Home/End 可吸附左/右侧，Esc 可主动收起；从收起入口也可直接拖动，拖拽结束不误开设置，取消拖动恢复起点。位置仍按原键保存比例，主题/模式切换不重置位置或计时，不增加业务请求。定时器仅在本组件管理并在卸载释放，尊重减少动态效果；收起入口完整位于视口内，不通过页面横向溢出实现半隐藏。

替代方案是把大半个球平移到视口外，因会造成触控入口过窄和横向溢出，采用视口内的半球入口。验收覆盖全部主题 × 明暗 × 1280/375/390：两侧吸附、延时收起、鼠标/触屏唤醒、键盘、从收起状态拖动、取消、刷新恢复、设置与焦点、主题切换及无溢出。
