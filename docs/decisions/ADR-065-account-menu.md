# ADR-065 账号下拉功能迁移

日期：2026-11-14。状态：采用。

## 原因与范围

按用户确认排除老板键与位置重置，迁移旧头像菜单其余十一个入口，复用当前资料编辑、网站身份设置、外观状态与退出用例。新增 account-tools 领域端口、HTTP/本地存储适配和按需加载的功能面板；app 负责组合，禁止跨 feature 导入。开放平台保留旧应用管理协议，Secret 仅在用户主动查看时请求并短暂存于组件内，关闭即释放，不持久化。

本地黑名单按账号隔离，通过 domain 端口注入聊天行与消息菜单，行精确订阅屏蔽状态，不删除历史实体、不改变分页与草稿。旧浏览器全局黑名单不自动归属新账号，避免串号；原数据保留。工作时间是本机计时工具，不能伪称服务端考勤，保留单休、双休、大小周和收入估算，不接入节假日调休。

网站引导介绍已接入入口，不宣称旧版未迁移能力可用。网站设置复用现有名称与图标表单，布局和主题通过既有主题入口设置，不引入旧版无对应能力的开关。

工作时间使用 WorkspaceShellSlots.status 独立状态行，由 app 注入并在当前外壳内单次挂载。替代旧版悬浮按钮，避免遮挡聊天发送、手机输入与游戏操作；隐藏后归还布局空间。计时更新只发生在自身组件中，不驱动页面、消息或草稿重渲染。

## 替代方案与影响

### 视觉整理（2026-11-14）

账号工具按内容使用不同尺寸：兑换与引导为紧凑弹窗，资料与名单为中等面板，开放平台使用较宽的管理面板。标题、说明、正文与操作区明确分开，短内容不再套用 700px 高度；长内容保留 reserved ScrollArea。应用的操作跟随所属应用，创建入口置于列表顶部；个人卡片以头像、姓名、简介和统计表达层次。手机按单列重排，并保持 44px 触控、全部主题与明暗模式的语义颜色。仅调整呈现，不改变接口、账号、草稿或请求生命周期。

拒绝复制旧 AvatarDropdown 巨型组件及 Ant Design。独立面板避免输入、弹窗和聊天列表共用状态。新增本机偏好仅保存在明确命名的浏览器键中，存储失败向用户反馈。账号切换取消请求并释放面板，主题和模式切换不触发请求、重连或清空草稿。

## 验证

执行 npm run check；接口适配单元测试覆盖鉴权、错误和旧协议。浏览器使用合成账号与请求夹具，按全部注册主题 × 明暗模式 × 1280/375/390 验证菜单、表单、列表、异常恢复、键盘、触屏、滚动与焦点。真实邮箱、兑换码和应用创建不在验收中调用，交付明确说明限制。临时产物使用独立目录，验收后清理。
