# ADR-063：谁是卧底本地与联机迁移

状态：采用。日期：2026-11-14。

## 原因与决定

旧版游戏页的同屏玩法和聊天房间是两个独立实现；游戏页“加入房间”只有成功提示，并未接入服务。本次在游戏目录、独立窗口和 `/game/undercover` 提供同屏游戏与真实联机房间，旧 `/game/draw` 重定向至新入口。

domain/undercover 定义不可变的本地轮次规则、房间模型与端口；infrastructure/undercover 校验旧 HTTP/WS 协议；features/undercover 分别拥有本地对局、房间同步、消息列表和输入草稿。app 注入服务、账号和登录导航。普通模式只显示本人词语，不提前揭示身份；本地发牌和投票逐人交接、平票无人出局、结算后才公开身份。限制卧底少于平民，避免开局已经满足卧底胜利条件；洗牌使用 Fisher–Yates，禁止旧版随机 sort 和浅拷贝后变异。

复用账号现有唯一 WebSocket。连接适配器增加可选的基础设施扩展回调，由 app 将原始帧、连接状态和发送函数接入独立卧底协议适配器，不进入公共聊天消息 store，不新增连接或事件总线。只接受明确匹配房间 ID 的消息，按稳定 ID 去重并限定内存，重连同步房间快照；没有旧版房间历史接口，明确说明只显示当前会话收到的消息。旧版发送不回执，界面只表达“已提交”，不伪造送达确认。房间刷新合并请求并取消过期作用域，错误保留已加载内容，手动重试；外观切换不参与请求依赖。

## 影响与替代方案

不复制旧大型聊天浮窗、Ant Design、全局 eventBus 和原生 select，不新增依赖。另建 WebSocket 会破坏账号单连接所有权；用公共聊天代替房间发言会串房间，因此均不采用。旧服务没有结构化发言阶段字段，投票按服务端当前规则开放，倒计时仅显示服务端通知，不在客户端推断裁决。房间列表旧接口一次返回全部数据，无分页按钮及伪造分页。

界面使用既有 surface/canvas/text/muted/border/action 变量和共享 Button、Select、Dialog、reserved ScrollArea。桌面房间信息与发言分区，手机纵向排列，保留安全区、44px 控件和滚动间距；全部注册主题与明暗共用。登录只用于联机，同屏无需登录；账号切换卸载联机状态。

## 验证

本地规则测试覆盖非法人数、洗牌、身份保密、逐人投票、平票、出局和双方胜利；协议与控制器测试覆盖房间过滤、去重、取消、错误恢复和发送失败。浏览器使用合成账号与房间，覆盖全部注册主题 × 明暗 × 桌面/375/390 的本地完整操作、联机 loading/empty/error/success、创建/加入/退出、开始/投票/猜词、滚动、控件、外观切换与窗口入口。执行 npm run check；实际验证结果及真实后端/真机限制记录在 docs/audits/undercover-migration.md。本次验证临时产物在最终回复前清理。
