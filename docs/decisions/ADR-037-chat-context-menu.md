# ADR-037 消息上下文操作菜单

日期：2026-11-12。采用。

## 原因

按用户给定列表实现复制、引用、@TA、复读机、撤回，移除气泡下方常驻撤回按钮。复制使用 Clipboard.writeText，图片复制其链接；引用、@TA、复读机只准备草稿，不接入此前明确排除的发送能力。保留撤回权限、离线/待确认禁用、超时重试和服务端确认语义；不展示转发、收藏等其他能力。

## 决策与替代方案

- 新增 shared/ui/ContextMenu，按既有 Radix 技术栈使用 `@radix-ui/react-context-menu@2.4.1`（MIT，React 19 peer 兼容）。通过 npm 元数据核对，它和当前 DropdownMenu 共用 `@radix-ui/react-menu@2.2.1` 等底层依赖；仅新增 ContextMenu 适配，不引入第二套 UI 或新锁文件。生产构建记录体积，不能只凭共享依赖宣称零体积影响。
- 不手写全局事件、坐标浮层、键盘菜单或可点击 div；不用 DropdownMenu 模拟指针位置的右键菜单。Radix 提供指针/长按、菜单导航和边界避让，shared 封装语义、主题样式、Shift+F10/菜单键与焦点返回。
- feature 的 MessageMenu 复用同一菜单项和用例；桌面气泡右键，键盘聚焦后 Shift+F10/菜单键；手机可长按，也可用 44px 更多图标触发现有 DropdownMenu。其他人的消息不提供撤回项；已撤回消息不提供菜单。
- 独立账号级草稿 store 由 ChatRealtimeProvider 创建，Composer 精确订阅，输入、引用和反馈不进入消息 store。引用只持有消息 ID/昵称，预览订阅原实体，撤回后不能继续显示旧正文。@TA 为可编辑文本提及；复读机追加原内容到草稿，保留已有输入。所有草稿动作明确提示发送未接入，不伪造消息发送或提及通知。复制失败提供可恢复文字提示，不调用浏览器 alert。
- 撤回待确认和失败仍在气泡下方提供文字反馈；普通关闭/撤回后焦点返回稳定气泡，草稿动作将焦点移入 Composer，不依赖成功后消失的按钮。断线或待确认期间禁用撤回，确认后清空正文。菜单不持有连接或消息副本。
- 全部外壳和模式使用语义 token；操作项危险语义为 color-danger，悬停/聚焦/禁用复用基础菜单约定。正文保持文本选择；菜单不照搬翻译、收藏等其他未接入项。
- 引用和操作反馈会改变输入区尺寸；滚动写入放到下一帧并在卸载取消，Virtuoso 保留默认的 ResizeObserver 帧调度，避免同步测量/滚动造成循环通知。

## 验证

定位成功反馈在 2.5 秒后自动收起，仅清除反馈文字，保留定位目标、消息高亮与尚未查看的 @ 提醒。再次定位重新计时，取消及账号作用域释放时清理计时器，旧计时器不能清除新的定位中或失败反馈。相较组件局部计时，该方案由既有导航控制器统一拥有生命周期，不增加消息订阅或请求。验证超时收起、连续定位、失败反馈保留与卸载清理，并覆盖全部主题、明暗模式及桌面/375px/390px 的 @ 提醒和引用定位流程。

检查全部注册主题 × 明暗 × 桌面/375/390：右键、Shift+F10/菜单键、Esc 与焦点返回、手机长按/更多、边界避让、离线和待确认禁用、失败重试、服务端确认、无越权入口、滚动和草稿/连接保留。运行 npm run check，并回归历史、媒体和实时流程；新增依赖后的体积与未验证项写入交付记录。
