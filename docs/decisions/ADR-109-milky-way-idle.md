# ADR-109：嵌入奶牛放置官网

状态：已撤回。日期：2026-11-25。

## 撤回

按产品要求下架《奶牛放置》，移除目录卡片、最近玩过入口、路由、独立小窗和内嵌组件。既有的本地访问记录由目录忽略，旧站内链接由通用「页面不存在」处理。仅隐藏目录卡片会保留可访问的旧路由，因此一并移除游戏接入代码。

验证全部注册主题、明暗模式及桌面、375px、390px 视口下的目录和最近玩过，确认旧路由不会初始化第三方游戏，并回归其他游戏的整页和独立小窗入口。执行 `npm run check`。

## 原因与决定

将《奶牛放置》加入游戏目录与最近玩过。站内整页 `/game/milky-way-idle` 与 ADR-051 独立小窗复用 `features/milky-way-idle` 的嵌入组件。小窗打开时整页让出游戏实例，收起小窗保留已挂载的 iframe；关闭后整页可重新打开官网文档。已保存进度和登录会话沿用游戏及浏览器自身机制。

iframe 指向固定的 HTTPS 官网。沙箱允许脚本、表单、弹出链接与游戏在自身域名下的存储，不开放顶层导航，不传递站内凭证或来源地址。游客试玩、注册和登录发生在官网文档中。摸鱼岛无需新增依赖、账号接口或代理。

宿主使用主题语义颜色和响应式布局，手机为游戏预留全宽内容区。官网保留自身界面、滚动、语言及外观设置。游戏画面直接接在工作台或小窗的页头后，加载阶段显示共享加载反馈，超时提供站内重试。跨域文档的 load 事件只能确认文档加载，游戏服务状态由游戏页面自行呈现。

## 影响与替代方案

仅提供外链无法站内操作。复制游戏或代理其账号请求会引入游戏版本和会话维护，放弃该方案。主题、明暗或小窗收起不重新挂载游戏。

## 验证

在全部主题 × 明亮/暗夜 × 桌面/375px/390px 验证目录、最近玩过、整页和两个小窗入口，覆盖加载、超时重试、可见与收起后继续、回焦及横向溢出。另打开真实官网 iframe 验证实际首屏和交互入口，执行 `npm run check`。
