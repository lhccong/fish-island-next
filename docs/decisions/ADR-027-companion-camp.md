# ADR-027：伙伴营地与二维分层场景

状态：采用。日期：2026-11-12。

## 原因与范围

将旧宠物养成模块迁至 `/pet`，采用原创伙伴营地命名和游戏面板。保留旧服务端养成、装备、外观和回合结算协议；不将场景内移动冒充联网探险，不新增实时群怪结算。页面、代码和资源不引入参考作品的专属称谓、角色或标志。

## 决策与影响

- domain/pet 定义领域实体和服务端端口；infrastructure/pet 校验 unknown DTO、处理 fetch/取消/鉴权；features/pet 拥有请求、交互和场景；app 注入服务与账号身份并懒加载。
- 使用原生 SVG 绘制原创斜俯视草地和独立景物，精灵以脚底锚点定位并按纵坐标排序。移动仅为本地营地互动，界面明确说明。无需新增依赖、Canvas 或三维引擎。
- 动作表按已解码图片尺寸识别既有 1536×1872 图集，不再按 URL 目录猜测；其他图片静态显示，加载期间与失败均显示可识别占位。素材无后端地址时不伪造已拥有宠物。
- 第 0 行待机；跑动行由资源配置决定：luobo 左 2 / 右 1，wutiaowu 左 1 / 右 2。两张原图已分别核对，不再用同一动作行顺序覆盖所有外观；其他未登记图集暂沿用旧契约，不能据此宣称方向已实测。营地根据实际水平位移切换动作，上下移动延续水平朝向，停止恢复待机。对战同样使用资源动作配置，不使用镜像替代已有方向帧。
- 移动以 requestAnimationFrame 更新实际位置，不再用目标坐标配合 CSS 延迟插值判断方向。鼠标/触屏设置目的地，WASD/方向键按住连续移动并支持组合方向；释放、页面失焦、隐藏或打开浮层时清除按键并停止。输入框、可编辑区域、组合输入及浮层内不截获，箭头不抢占场景外导航控件；WASD 在普通按钮焦点下仍可控制可见的营地。监听与帧循环在卸载时释放，主题切换保持当前位置。方向回归使用两张真实图集，不能只用按实现假设绘制的合成图替代真实资源检查。
- 保留 `/api/api/pet/skin/*`、`/api/api/pet/rank/list` 等旧路径；不在迁移时擅自规范化。积分、冷却、胜负、装备属性由服务端决定，不以客户端动画决定收益。
- 排位挑战和幸运补给复用旧活动接口，积分消耗在提交前明确确认；不在前端生成奖励或伪造保底概率。活动状态独立于营地主数据，请求按打开面板懒加载。
- 单独请求的控制器有取消、卸载清理、重复提交保护。账号切换重建功能实例；主题和模式切换保持实例、面板状态及场景位置，不额外请求。
- 面板与操作使用已有语义变量和 shared/ui。场景插画使用 `--color-pet-*` 局部 token，明暗分别提供，不扩大第三方皮肤白名单。普通按钮遵循 ADR-026，表单弹窗遵循 ADR-025 的 reserved 滚动区。

## 替代方案

- 全量复制旧 Umi/Ant Design 页面：违反模块边界及单一 UI 技术栈，拒绝。
- 引入 PixiJS：大量实体和粒子场景时可重新评估；当前固定营地和回合演出无需新增运行时。
- 三维引擎：需要额外模型与动作资源，超出当前二维资源复用目标。

## 验证

执行 npm run check；以合成接口数据验证空营地、领养、养成、装备、外观、排行、挑战及错误恢复。按注册表全部主题 × 明暗 × 桌面/375px/390px 检查入口、场景、面板、无横向溢出、滚动间距与键盘/触屏操作；验证切换外观不重取、不丢业务状态。真实后端未联调时明确报告，不以合成浏览器结果替代真实接口验证。

## 补给铺购买数量

- 可叠加商品在卡片内填写购买数量，默认为 1，按钮和确认框显示总积分。不可叠加商品沿用单件购买，服务端会拒绝批量入库。
- pet 端口将购买与装备实例操作分开，适配层一次提交模板 ID 和数量。相比逐件发送请求，复用服务端事务可避免部分成交。数量和积分总价都须处于接口整数范围内，积分余额由服务端校验。
- 草稿属于商品卡片，失败保留数量，成功刷新行囊并重置当次数量，保留商品列表和滚动位置。用既有主题变量、紧凑按钮和 reserved 滚动区；手机使用数字键盘，并沿用 ADR-097 的可视视口变量调整弹窗。
- 验证全部注册主题、两种颜色模式与桌面/375px/390px 下的数量校验、总价、提交载荷、错后重试、滚动和焦点。接口校验使用合成响应。

## 已穿戴装备词条

- 营地装备格、行囊已穿戴装备和他人伙伴资料通过同一只读 Dialog 展示所选装备的锻造等级、词条属性、数值、品质和锁定状态。详情由入口按需挂载，关闭取消读取并返回入口焦点。主题与模式共用语义变量和 reserved ScrollArea。
- 适配层通过既有 `GET /api/pet/forge/list` 读取目标宠物的锻造记录，按实际槽位匹配并复用锻造词条解码。宠物资料中的汇总加成无法还原独立词条及品质，锻造详情接口可能初始化记录，因此使用只读列表。
- 以合成接口覆盖全部注册主题、明暗及桌面/375px/390px 的本人及他人装备、真实槽位匹配、加载、无词条、失败重试、关闭与焦点回归。
