# ADR-060：迁移聊天福袋

状态：采用。日期：2026-11-14。

## 原因和决策

迁移旧版发送、参与、消息卡片、进行中列表及中奖记录。domain/chat 定义福袋端口、校验和消息标记解析；infrastructure/chat 适配原有 `/api/luckybag` 协议；chat feature 独立管理账号作用域的创建、详情缓存和请求，app 注入端口。无新增依赖，不改变现有分层。

创建接口已由服务端发布 `[luckybag]id[/luckybag]` 消息，客户端不得再次发送聊天消息。创建请求结果不明确时禁止自动重试，提示核对进行中的福袋；明确业务拒绝可修改后重试。参与串行提交，成功立即更新参与状态，再刷新详情。中奖记录仅打开时读取，不轮询；到开奖时间后允许刷新详情，状态 0/1/2 分别为进行中/已开奖/已过期。

混合文本福袋消息按阅读顺序纵向呈现：系统提示文字在上，福袋卡片独立成行，二者保留 8px 间距；卡片按内容宽度显示，不与前缀并排，也不撑满消息列。图片保留原比例。该布局同时应用于会话和 WPS 工作表呈现。

## 影响与替代方案

补充可参与数量角标：账号级独立 active store 统一持有进行中快照，入口只订阅未参与、状态进行中且未到期的数量，零时隐藏、超过 99 显示 99+。首次登录读取，收到新福袋/系统福袋开奖消息、重连和窗口重新可见时按需刷新；创建、详情和参与成功合并同一快照，参与后立即减数。单个在途读取合并后续刷新，失败保留已有数据并由列表提供手动重试，不自动无限重试。使用一个最近到期定时器本地移除失效项，不逐秒轮询。账号切换取消读取、订阅与定时器；主题/模式切换不参与依赖。列表复用该 store，避免入口和弹窗各自请求。较仅打开列表读取的旧方案，该调整使关闭弹窗时也可看到真实可参与数量；不新增通信协议或全局页面状态。

消息按行订阅福袋缓存，不订阅输入草稿；虚拟列表卸载不清除已取得的详情，账号切换释放请求和缓存。主题、模式及外壳不参与网络依赖。进行中列表与数量角标共用账号快照，打开时按需刷新；服务端返回完整列表和完整中奖记录，没有分页协议。复用共享 Dialog、ScrollArea、Select、Button 和语义变量，手机重新排布详情信息。避免复制旧页面的全局状态、轮询和 Ant Design 控件。未采用客户端二次广播或逐秒全列表刷新，以免重复消息与额外请求。

## 验证

单元测试覆盖标记、金额/人数/时间边界、协议状态、重复参与、取消和创建结果不明。浏览器覆盖注册主题 × 明暗 × 桌面/375/390，发送、参与失败重试、记录空/失败/成功、加载和结束；检查滚动、焦点返回、下拉键盘和溢出。执行 npm run check；具体已验证结果在交付中记录。
