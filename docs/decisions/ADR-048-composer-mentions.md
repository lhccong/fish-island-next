# ADR-048：输入框 @ 在线成员匹配

问题：消息菜单支持 @TA，但手动输入 @ 缺少候选匹配。

采用 shared/ui/InlineAutocomplete，基于已有 Radix Popover 的非模态锚点与边界避让，集中处理 listbox、方向键、Enter 选择、Esc/Tab/外部关闭。编辑器保留焦点与软键盘，中文组合输入期间不匹配、不拦截确认键。候选采用 reserved ScrollArea、44px 选项与主题语义变量，全部外壳、明暗模式共用。

chat feature 复用账号作用域在线成员快照，按昵称忽略大小写筛选、排除本人，不添加请求或消息列表订阅。仅在折叠光标前的未完成 @ 片段匹配；邮箱不触发。选中后以原生编辑事务替换该片段，保留前后文字、Emoji、引用与撤销能力，仍沿用纯文本 @昵称 发送协议。名单仅覆盖在线快照，不能宣称搜索全部离线成员；加载、空列表、无匹配与失败重试显式呈现。

替代方案：复用居中成员弹窗会中断输入；独立搜索接口需要新增协议且重复已有快照；直接手写浮层会重复边界和关闭逻辑，均不采用。

验证：npm run check；在线名单 loading/error/empty/success、筛选、键盘/触屏选择、Esc、组合输入、选区及保留后文；全部注册主题 × 明暗 × 桌面/375px/390px 检查布局、滚动、选中及焦点状态。测试使用合成数据，临时报告与截图验证后删除。
