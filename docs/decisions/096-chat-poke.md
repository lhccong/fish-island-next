# ADR-096：聊天戳一戳与被戳文案

状态：采用。日期：2026-11-17。

2026-11-17 撤回样式补充：按用户提供的微信参考图，将撤回改为提示条内同行文字操作。shared/ui/Button 增加通用 inline 变体，仅供嵌入正文的动作，保留真实 button 与原撤回状态机；普通按钮尺寸不变。提示使用 text/canvas 混色浅底、muted 正文、accent-text 操作色，全部主题及暗夜共同适配，不硬编码单主题配色。手机保留透明 44px 点击范围及提示行留白，长文自然换行；验证全部主题 × 明暗 × 桌面/375/390 的同行比例、悬停、聚焦、禁用、等待撤回和触屏命中。此呈现例外依据用户明确要求，替代方案为普通描边按钮，但无法保持参考图的文字层级；不复制撤回业务或改动协议。

用户要求聊天支持戳一戳，并由被戳用户设置后缀。复用现有 HTTP 发送、幂等回执、消息存储、历史、账号 WebSocket 与撤回链路，避免新增连接或独立消息列表。发送请求增加可选 pokeTargetId；此类请求不接受正文或引用，服务端读取目标用户的昵称与 pokeSuffix，保存结构化 poke 快照和兼容旧客户端的纯文字正文。不触发发言积分或 AI 回复，遵守封禁与禁言；同一发送者串行执行并限制三秒一次，重试原请求优先返回原回执。

个人资料复用既有 auth 更新/回读链路，pokeSuffix 最多 30 个 UTF-16 字符，留空清除；数据库新增非空默认空串字段，部署先执行后端 SQL。旧客户端不传该字段时保留原值。消息快照不因后续设置变化而改变。

domain 定义可选结构与请求字段，infrastructure 校验 HTTP/实时/历史消息，chat 独立发送用例复用待确认、失败重试及撤回状态；消息行按 ID 订阅，戳一戳单独居中呈现，纯文本显示昵称和后缀，禁止解析其中图片/奖励等标签，也不参与复读合并。消息菜单和用户卡片共用发送用例，不修改输入草稿。外壳与连接生命周期不变。

全部主题/明暗共用 muted/action/border 语义变量；手机允许长文换行，按钮复用共享 Button。待发送和失败保留原消息，使用 LoadingIndicator 与重试；成功显示可撤回的弱化提示。替代方案是独立系统事件，但会重复历史、去重与撤回逻辑；将文案作为普通文本发送则无法防止伪造，也无法可靠呈现。

验证：后端测试身份、目标有效性、默认/自定义快照、幂等/撤回、禁言、节流及不触发积分；前端测试解码、发送/重试/去重和复读隔离。浏览器按全部注册主题 × 两种模式 × 375/390/桌面检查入口、加载/失败/成功、长后缀、资料保存清除和草稿保留。执行 npm run check；未完成的验证如实列出。
