# ADR-085 摸鱼岛经典主题

状态：采用。日期：2026-11-16。

## 原因

新增「摸鱼岛」主题，按旧版截图还原顶栏、热榜三列卡片和聊天室圆角分栏。仅更改配色不能表达旧版结构。

## 决策与影响

- 注册 `moyu-island`，app 显式映射同名外壳，共用 WechatShell 的 classic 呈现及顶部导航布局；现有外壳默认行为不变。
- app 组合旧版导航和鱼小圈侧栏；聊天继续复用独立草稿、消息虚拟列表、成员快照及通信控制器。经典成员侧栏只呈现已有快照，不增加请求。
- 热榜使用 classic 呈现，保留来源详情、筛选和设置能力，桌面隐藏来源侧栏并展示三列卡片。
- 可信内置呈现变量提供蓝色普通操作、橙色导航/缎带、浅灰背景；暗夜基底仍为 #191A1C。不扩大第三方导入权限，不新增依赖。
- 手机沿用 760px 断点，底部导航、单列热榜及独立聊天输入；鱼小圈通过已有路由访问，成员使用现有手机入口。
- 经典主题手机版权随内容滚动，避免悬浮版权覆盖榜单；桌面聊天版权放在分栏下方。
- 未迁移的旧导航能力不伪装成已接入功能，不复制旧页面业务、真实聊天和账号数据。

## 替代方案

仅增加 token 无法还原布局；复制旧页面会引入第二套业务和状态，均不采用。

## 验证

收起入口视觉调整：仅使用 Lucide 图标，放在鱼小圈标题旁，通过 IslandCircleFeed 的 headingAction 插槽注入；收起后聊天页头只保留展开图标，不再显示“鱼小圈”文字按钮。两处入口均有可访问名称、悬停提示和 44px 点击范围，切换后焦点移至对应入口。

2026-11-16 鱼小圈收起：app 持有独立的侧栏展开状态，通过既有 hideSidebar 隐藏侧栏，保留挂载与滚动位置；聊天页头提供共享 Button 展开/收起入口，使用 aria-expanded/aria-controls。经典聊天隐藏侧栏时保持卡片、上下留白和版权位置，主内容扩展到原分栏整体宽度。手机保留既有弹窗查看与关闭流程。相比卸载动态栏，此方案不丢失列表状态；收起偏好后续按 ADR-088 保存到本机，不增加业务请求或连接。验证双模式、全部主题、桌面及 375/390px，检查草稿、连接、动态请求次数、滚动恢复和键盘操作。

经典群聊页头只显示现有 Lucide 聊天气泡图标，不再显示群名文字；h1 的 title/aria-label 继续提供真实群名，其余主题保持标题文字。

平铺布局的明确例外：聊天室左侧鱼小圈和右侧聊天区恢复原白色/暗夜 surface 圆角卡片及阴影，恢复原顶部 32px 和底部 80px 的卡片周围间距。普通菜单页面继续平铺并去掉固定上下留白，不将聊天室的间距复制到其他页面。

Web 平铺调整：经典外壳各菜单页面移除工作区和侧栏的外层圆角、阴影和白色包裹底，并移除固定的顶部 32px/底部 80px 预留；内容接顶栏，版权仅按实际高度占位。保留内容自己的卡片、聊天消息区与功能面板；居中宽度及手机重排不变。经典在线成员按实际 level 降序排列，同等级稳定保留快照顺序，缺失等级排最后；排序生成副本，不改变共享成员、其他外壳或通信状态。

经典聊天室移除欢迎公告的文案和蓝色公告外观，保留群名与详情/手机入口。加号改用 shared/ui/DropdownMenu 的 chat-tools 呈现，从触发器上方弹出操作列表，不再展开输入区；红包、福袋及进行中列表复用原有表单与账号控制器，菜单外独立持有 Dialog 并将焦点返回加号。上传图片复用原文件输入框，小窗复用现有切换回调；未接入能力不复制为可用项。共享菜单仅增加 side/align 及可信呈现变体，其余主题保持既有工具栏；不新增依赖、请求或全局状态。验证菜单边界、键盘/触屏、Esc/外部点击、弹窗转场、输入区尺寸、草稿和连接保留。

后续产品调整：摸鱼岛主题下，聊天室保留鱼小圈动态栏，管理页保留导航；其他普通菜单页面隐藏左栏，主内容居中使用原分栏的整体可用宽度；首页热榜仍通栏。仅由 app 注入 centerContent 布局标记，不改变其他外壳或状态。顶部移除玩法、工具菜单；关于直接进入 `/rank/reward` 赞助榜，其他主题导航保留。

2026-11-16 校正原版细节：经典成员栏采用 28px 圆形头像、46px 行距、居中标题与单个隐藏入口，等级徽标读取现有在线接口的可选 level 字段（安全整数校验；缺失不伪造）。继续使用共享快照与用户卡片，不新增请求。签到沿用同一 Launcher，新增经典呈现变量，将蓝色圆形日历入口定位于右上角；手机保留既有底栏和 44px 触控。其他外壳保持默认呈现。相比复制旧控件，此方案保留统一焦点、签到反馈、账号生命周期及明暗 token；通过全部主题双模式三种视口与合成接口验证。

执行 npm run check；Playwright 使用合成接口覆盖注册主题、双模式、桌面及 375/390px，验证热榜四态、聊天、草稿/连接保留、主题持久化和无横向溢出。截图仅用于本次验收，完成后清理。

## 桌面导航位置

旧版在网站设置提供导航布局选择。摸鱼岛主题的网站设置使用共享 Select 提供顶部和侧边菜单，顶部为默认。保存时与其他网站设置一起写入同一本机记录，缺失或未知的值回退到顶部，刷新与切换主题后保留已保存选择。手机可以设置电脑端菜单位置，当前页面继续使用既有底部标签与内页返回入口。

app 将偏好映射为经典外壳的导航布局。侧边菜单沿用相同链接、权限入口、签到、账号和外观控件，桌面左栏用图标与文字纵排，较短窗口允许滚动菜单。内容区与鱼小圈、管理导航等业务侧栏各自保留布局和状态。直接复制旧版混合菜单或使用第二棵导航树会增加重复入口及状态，本次只通过样式移动现有区域。

验证全部注册主题、明暗模式和桌面、375px、390px 视口，覆盖热榜四态、键盘和触屏设置、保存失败与重试、刷新恢复、导航和聊天草稿、历史请求及连接保留。

侧边菜单对齐参考旧版。菜单行水平居中，图标与文字左对齐，列表两侧保留等宽滚动槽，较短窗口滚动时两侧留白一致。账号入口与主题入口固定在侧栏底部两端。账号与菜单使用稳定的组件标识，Tab 按菜单、账号、主题的顺序移动，从账号打开的网站设置在切换位置时保留并归还焦点。验证长短桌面窗口的居中、滚动、菜单避让及焦点返回。

桌面侧栏将最新、鱼窝与鱼小圈放在首组，阅读至成就作为中组，关于、工具、管理和签到放在末组。用现有玩法链接容器绘制两条分隔线，两侧各留 8px 及对称的细滑轨槽，菜单行占满中间宽度。末组按登录状态呈现管理和签到入口。仅侧栏使用行内未读角标，沿用原有未读快照。分组通过留白和细线表达，键盘顺序与视觉顺序一致。验证 44px 导航命中范围、选中、悬停、焦点、短窗滚动，以及有无未读数和管理权限时的布局。

侧栏占据固定宽度时，剩余宽度归主内容，右侧用固定边距收尾，解决宽屏受居中布局上限约束而形成的大块空白。鱼小圈保留左右摆放和收起偏好，列宽按视口限制在 220–320px。经典侧栏的聊天室可用宽度不超过 520px 时，用容器查询隐藏常驻成员栏，并沿用页头聊天列表入口查看成员。此时工具独占输入框上方一行，输入框和发送按钮共享下一行。相比增加更大的宽度上限，由网格分配剩余空间可同时覆盖宽屏和窄桌面，内容和成员组件按原位置挂载。验收 1920px 桌面下的左右摆放和收起、800px 桌面的草稿输入与成员入口，并校验外观变化期间的草稿、历史和连接。
