# ADR-058：本地自定义聊天列表外观

状态：已采用。日期：2026-11-14。

用户希望用自定义名称和摘要将左侧对话列表呈现为 Todo 清单，不引入任务完成、通知或同步能力。

chat 领域增加独立的列表外观偏好端口；infrastructure 保存并校验浏览器本地 JSON，app 注入，chat 内独立 Provider 共享桌面侧栏与手机弹窗的配置。编辑草稿由弹窗持有，保存成功后才更新列表；关闭放弃未保存编辑。默认仍展示原会话，选择自定义后只替换群聊下方条目，群聊入口和摘要仍保留，摘要可编辑。自定义条目不关联真实成员，也不显示虚构消息时间。

配置只含用户主动输入的外观文案，不保存账号、聊天消息或令牌；当前浏览器共享，不提供云同步。读取失败明确反馈并允许重新保存，写入失败保留草稿。限制最多 50 条，名称 30 字、摘要 100 字，空名称禁止保存。无异步取数，不产生 loading 或分页；原成员列表的加载与失败行为保持不变。

替代方案：修改在线成员名称会混淆真实身份；新增任务系统超出需求；在外壳保存业务状态违背分层。采用独立偏好，避免订阅消息和输入草稿。WPS 仍隐藏桌面侧栏，通过公式栏列表入口访问同一功能。

全部主题、明暗模式共用语义变量、Dialog、Select、Button 和 reserved ScrollArea；手机使用 44px 控件、单列编辑与安全区，切换外观不重挂载聊天内核。

验证：偏好解码与失败单元测试；全部注册主题 × 明暗模式 × 桌面/375px/390px 验证增删编辑、空状态、保存失败、恢复默认、刷新持久化、焦点/滚动及聊天草稿和连接保持；执行 npm run check。实际结果记录于交付说明。
