# ADR-032 手机分层导航与底部 Tabbar

状态：已采用。日期：2026-11-12。

## 原因与方案

手机端顶部全局菜单占用聊天、成员及阅读的纵向空间。外层 `/` 热榜与新增 `/discover` 发现入口使用底部 Tabbar，内层工作台隐藏全局菜单，并在原页头左侧提供返回入口：聊天返回热榜，其他功能返回发现。账号与主题入口保留在外层底栏。桌面继续使用侧轨或 WPS 功能区。

app 判断路由层级并向外壳传递纯布局属性，外壳只控制区域位置。所有主题的手机布局一致，WPS 装饰功能区在手机隐藏。Tabbar 使用语义颜色、44px 以上触控区域和底部安全区；布局占据独立网格行，不覆盖正文或输入区。业务组件保持原挂载与状态边界。

## 替代方案与影响

仅把所有页面的顶部菜单移到底部仍会占用内层空间；完全删除全局入口会使功能难以到达。采用外层底栏加内层返回，不引入依赖。发现底栏在手机称为“发现”，桌面保留原鱼小圈入口。现有发现页内菜单继续可用。

## 验证

全部注册主题 × 明暗模式 × 桌面、375px、390px 检查外层底栏位置、内层导航隐藏、返回及触屏操作、无横向溢出；聊天在线成员 loading/empty/error/success 沿用浏览器流程验证。执行 npm run check，记录实际结果及未验证范围。

后续按用户要求将手机外层账号头像移到页头右上角，去掉热榜页头右侧说明文字。底栏仅保留热榜、聊天、发现、主题四个入口并等宽排列；桌面账号位置不变。WPS 手机使用同一页头，隐藏表格内重复标题。账号入口共用 app 的 WorkspaceAccount 组合，不新增认证状态或请求。

手机朋友圈按用户要求采用封面返回：隐藏工作台页头（含标题与发现菜单），将唯一返回入口放在封面左上角；个人动态先返回全部动态，全部动态返回发现。app 注入返回发现回调，feature 只呈现返回操作，外壳通过 hideMobileHeader 纯布局属性隐藏手机页头，桌面不变。发现根页在手机隐藏菜单内部的重复标题。复用封面语义颜色和 44px 命中区，不新增依赖、不改变业务状态和请求。替代方案为保留独立页头返回，但会继续占用手机纵向空间。验证覆盖全部注册主题、明暗模式及桌面/375px/390px，检查封面返回、过滤返回、加载/空/失败/成功和无横向溢出。

本次验证（2026-11-12）：`npm run check` 通过（29 个测试文件、118 项单元测试及生产构建）。`playwright.circle-navigation.config.ts` 覆盖 WPS、微信、企业微信、飞书、钉钉 × 明亮/暗夜 × Chromium 桌面、375px、390px，共 30 个场景，检查动态 loading/empty/error/success、封面返回位置与 44px 命中区、与工具栏无重叠、键盘聚焦、手机触屏返回发现并重新进入、个人动态返回及无横向溢出。截图保存在 `test-results-circle-navigation/`，已人工查看手机朋友圈和发现页代表截图。使用合成接口数据；未验证真实手机设备、Safari 及真实服务端数据。

手机发现内层页面补充（2026-11-12）：游戏、阅读、伙伴、关于及人生重开采用 app 组合属性 `mobileHeader="back-only"`，手机页头仅保留 44px 以上返回入口，隐藏标题、说明及发现菜单；桌面仍呈现原页头和侧栏。人生重开返回游戏目录，其余返回发现。关于的业务分区导航在手机移至正文顶部，确保子页可达。替代方案为只删除菜单但保留大标题，仍占用用户要求释放的顶部空间。复用现有语义颜色、外壳和状态，不新增依赖或通信；朋友圈继续沿用封面返回。验证覆盖全部注册主题 × 明暗 × 桌面/375px/390px 的导航、返回、无溢出及相关状态。

本次内层页头验证（2026-11-12）：`npm run check` 通过（36 个测试文件、137 项单元测试和生产构建）。`discovery-mobile-header.spec.ts` 覆盖 WPS、微信、企业微信、飞书、钉钉 × 明亮/暗夜 × 1440px、375px、390px，共 30 种组合：检查游戏、人生重开、阅读、伙伴及全部关于子页的手机仅返回、桌面导航、触屏返回、焦点和页面无横向溢出，并切换伙伴 loading/empty/error/success。独立端口批次 28 项通过，2 项浏览器建页/首次导航超时；这 2 项串行重跑通过。另检查手机关于分区跳转，并人工查看手机伙伴、关于和桌面伙伴截图。使用合成接口数据，未验证真机、Safari、真实服务端及阅读/游戏/关于各自完整业务异常流程。本次临时配置、截图、追踪和测试结果在提取结论后删除。
