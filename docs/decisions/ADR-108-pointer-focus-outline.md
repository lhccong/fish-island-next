# ADR-108 按输入方式显示焦点轮廓

状态：采用。日期：2026-11-24。

## 原因与范围

Chromium 在键盘聚焦滚动视口后，再点击同一个视口时仍可能保留 `:focus-visible`。文本输入框也可能在指针聚焦时匹配该伪类。阅读 Word 模式因此会在正文周围保留一整圈主题色轮廓。

各文档使用捕获阶段的 `pointerdown` 和 `keydown` 标记最近的输入方式。主文档由 app 注册，阅读画中画在自己的文档注册和释放。标记挂在 body，由 CSS 继承给 Portal、弹窗和组件。组件使用 `--focus-outline-style` 控制焦点轮廓，继续使用原主题色和宽度。输入、滚动、焦点转移及选中、悬停反馈沿用原交互。标记不进入 React 状态、存储和画中画主题同步。

## 替代方案与验证

仅依赖 `:focus-visible` 无法处理同一元素的输入方式切换。逐个移除 tabindex、调用 blur 或隐藏所有焦点样式会破坏键盘滚动及弹窗焦点管理。

按全部注册主题、明暗模式、桌面和 375px/390px 验证指针与键盘切换、Word 正文、阅读翻章、空正文和失败重试。共享视口和控件同时检查触屏点按、Tab、方向键及滚动位置。画中画验证文档间输入方式独立。
