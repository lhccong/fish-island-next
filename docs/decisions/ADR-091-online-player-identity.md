# ADR-091 联机游戏玩家资料呈现

状态：已采用。日期：2026-11-16。

## 原因与方案

五子棋旧版 joinSuccess 只广播对手 ID，不包含昵称与头像。app 向五子棋注入现有 UserCardPort 的只读 userCard 能力及本人会话资料，feature 按对手 ID 补读一次公开资料；支持取消、失败重试并校验用户 ID，外观切换不参与请求依赖。兼容已有 playerInfo 快照，资料失败不阻止落子。

你画我猜与斗地主保留服务端 userAvatar / avatar 字段，谁是卧底使用已有 avatar。shared/ui/UserAvatar 仅负责图片和昵称首字回退，不请求资料。各功能保持现有状态和通信所有权，禁止逐条玩家额外查询或跨 feature 依赖。

## 影响与替代方案

无需后端发布或新依赖。放弃只给后端增加字段的方案，因为已部署五子棋服务仍只提供 ID。头像缺失、非法地址或图片失败使用占位；长昵称允许换行。全部主题和明暗模式复用语义 token，手机保留玩家、棋色及操作层级。

## 验证

协议单测覆盖真实字段及非法头像；浏览器按注册主题 × 明暗 × 桌面/375/390 检查四项游戏的玩家身份、回退、加载/失败重试与核心交互；执行 npm run check，实际验证范围随交付说明记录。真实账号与真实多人服务不写入测试数据。

2026-11-16 验证：Windows / Edge Chromium / Vite 生产构建，合成用户与拦截的 HTTP/WebSocket。摸鱼岛、摸鱼岛像素风、WPS、微信、企业微信、飞书、钉钉 × 明亮/暗夜 × 1440×900、375×900、390×900，共 168 个不同场景完成验证。覆盖头像成功、缺失/图片失败回退、长昵称、内部无横向溢出、五子棋资料 loading/error/重试/ready、换肤不新增资料请求及重连，以及落子、触屏绘画同步、投票确认/Esc/焦点返回和手牌触屏选择。斗地主同时覆盖大厅 loading/empty/error/重试及玩家头像。
