# ADR-073：统一加载图标与文字

日期：2026-11-15。状态：采用。

## 原因

表情包懒加载面板及多处页面仅在左上角显示文字，缺少明确且一致的等待反馈。

## 决策与影响

在 shared/ui 新增纯表现 LoadingIndicator，通过公开入口引用。默认在可用主体区域内居中，紧凑变体适用于按钮、局部状态和分页边界；图标与文字整体居中，保留原有业务文案。复用 Lucide LoaderCircle、语义文字颜色及现有字体栈，无新增依赖。图标为装饰，状态使用 role=status；减少动态效果时停止旋转，文字仍可识别。

替换全部文字加载入口与懒加载 fallback，图片保留原定位容器；按钮等待阶段使用紧凑图标与文字。追加加载不清空内容，不移动滚动锚点；切换主题、模式不新增请求，不重挂载业务。空、失败、结束和成功反馈保留各自语义，不显示加载图标。

## 替代方案

全局 CSS 为含文字的元素添加伪图标无法可靠识别状态，也缺少统一可访问语义；逐业务复制 spinner 会造成外观分叉。骨架屏可以保留，但不能取代图标与文字。

## 验证

执行 npm run check；浏览器覆盖注册主题 × 明暗 × 桌面、375px、390px 的主体和紧凑呈现、真实表情包等待及失败恢复，检查居中、无横向溢出、关闭和焦点返回、减少动态效果。完整业务异常流程若未逐一验证，交付报告明确范围。
