# ADR-043 连续消息复读与展示合并

状态：已采用。日期：2026-11-13。

## 原因与行为

连续两条正文完全一致且无引用的已确认普通消息，在第二条右侧显示 +1。三条及以上仅展示首条气泡，气泡下沿紧贴排列按账号去重的 20px 圆头像；不展示次数、昵称或称号文字，次数与参与者信息保留在辅助说明与头像悬停提示中。+1 经既有发送用例直接发送正文，不修改草稿。红包、撤回、发送中、失败、空白正文均打断连续段。

## 边界与影响

红包和福袋（含带前后文字的混合消息）不支持任何复读入口：右键/键盘上下文菜单、手机更多菜单均隐藏“复读机”，不生成连续复读分组或 +1 按钮；发送用例的 repeat 也拒绝这两类消息，避免只限制界面。统一通过 domain/chat 的纯内容规则判定；正常红包创建发布和普通消息发送保持原协议。

不删除或改写消息实体。chat feature 在消息批次和发送确认后派生稳定的展示 ID 与分组，行仅订阅自身实体和分组；虚拟列表继续使用稳定 ID，历史前插按展示行维护索引。撤回重新派生，恢复拆分展示。按用户截图反馈移除合并消息的展开/收起入口；保留首条气泡的既有消息菜单，其他原始实体仍保留，服务端撤回会重新计算分组。无新依赖。

称号接口仅提供本人拥有的称号，其他查询要求管理员权限，因此迁移旧客户端 config/titles.json 的公开编号/名称数据到 domain 纯规则；使用 sender.titleId 与 level 解码真实头衔，不迁移旧组件或样式。未知自定义称号显示“称号未收录”，缺失等级显示“称号未提供”，不伪造名称。后续可由服务端公开目录替代静态兼容表，本轮不新增网络请求。头像圈、操作与动效复用语义变量，手机 44px 触控，减少动态效果时停用动画。

## 替代方案

不采用删除重复实体或将分组合并写回消息正文，避免破坏撤回、引用、重试与服务端事实。复读按钮不使用现有菜单的填入草稿动作，满足点击即发送。

## 验证

纯规则与 store 测试覆盖阈值、精确比较、分隔、确认、撤回、去重和历史前插。浏览器按全部内置主题 × 明暗 × 桌面/375px/390px 检查直接发送、草稿保留、失败重试、紧凑头像条、无展开按钮与可见名称、换肤与边界布局。执行 npm run check；实际验证范围与限制记录在交付说明。
