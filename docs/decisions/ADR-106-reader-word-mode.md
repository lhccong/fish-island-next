# ADR-106 阅读器 Word 模式

状态：已采用。日期：2026-11-23。

## 背景与决策

旧摸鱼岛 `src/components/GlobalFloatingReader/index.tsx` 的 Word 模式从阅读工具栏进入全屏文档，显示 Office 风格功能区、居中纸面、当前章标题与正文，以及固定的上一章、下一章和退出入口。保留旧版纸面上的 QQ 阅读首页链接。功能区仅作为静态文档外观。原有工作伪装和画中画各自保留入口。

Word 模式由阅读器呈现层持有。章节内容、缓存、请求、翻章、失败重试及进度继续由既有阅读模块管理；切换时保留正文滚动元素，并按当前段落恢复位置。新章节沿用原来的进度重置行为。界面沿用共享 Button、ScrollArea 与 LoadingIndicator。桌面保留标题栏、功能区与底栏，手机收拢为标题栏、页签与固定翻章操作，使用共用语义色和安全区。

## 替代方案与验证

采用完整定制样式的原生模态 `dialog` 提供浏览器顶层、背景惰性和焦点隔离。已有阅读 Portal 的容器可以移入文档层并再移回页面，使章节和搜索等组件持续挂载。另建 Radix 弹窗内的第二套正文会产生两套阅读状态；直接沿用旧样式表会引入全局选择器及远程固定明色界面资源。

按全部注册主题、明亮与暗夜、桌面与 375px/390px 检查入口、文档正文、加载、错误重试、空正文、翻章、滚动、关闭与焦点返回。通过本地与模拟在线书籍验证请求复用、跳过分卷和进度。执行 `npm run check`。

## 验证记录

### 旧版截图对照

桌面采用 40px 标题行、31px 页签与 114px 功能区，在 900px 纸面内复现留白、居中章名、虚线分隔与两字缩进。标题栏及功能区的静态元素用 CSS 和既有图标绘制。状态栏显示真实章节位置与当前正文字数，翻章与退出保持共享按钮语义；QQ 阅读入口置于纸面末尾。共享 ScrollArea 允许在 Word 专用正文持续显示桌面滑轨，手机仍按全局规范隐藏。手机保留紧凑标题、退出及翻章，去掉占用阅读空间的静态桌面信息。移除普通阅读器工具栏的「W」快捷入口，书架的「努力学习」和紧急隐藏沿用原流程。

验收增加 1920×911 明亮桌面截图对照，以及两档手机视口的纸面和按钮布局断言。继续按全部已注册主题与明暗模式验证入口、状态及翻章。

Chromium 的桌面 1280×720、触屏 375×812 和 390×844 覆盖摸鱼岛、摸鱼岛像素风、WPS 表格、微信绿、企业微信、飞书蓝和钉钉蓝的明暗模式。42 项 Word 交互用例包含「W」入口移除检查。另有 1 项 1920×911 截图对照、1 项本地 TXT 与画中画并发测试和 14 项桌面画中画回归，共 58 项通过。生产构建、595 项单元测试及改动文件的格式与 ESLint 检查通过。全仓 `npm run check` 停在 13 个本次未改动文件的格式检查。原阅读端到端套件上轮在查找「阅读」或「游戏」链接时有超时，本轮未重跑该套件。

未实测手机真机、Safari、Firefox 和线上书源。
