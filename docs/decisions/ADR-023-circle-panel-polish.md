# ADR-023 互动消息面板与旧版发布弹窗

状态：采用。日期：2026-11-12。

原因：首次迁移的通知面板留白过大、操作与未读标签抢占内容；发布表单暴露原生文件控件，与旧摸鱼岛不一致。

方案：通知使用非模态浮层，操作收拢到顶部更多菜单，保留紧凑列表、头像、互动图标、时间和缩略图；标题描述供辅助技术读取。共享 Dialog 增加可选非模态、描述隐藏和定位样式，默认行为不变；DropdownMenu 可传局部样式以适配浮层内菜单层级。桌面浮层从通知按钮下方展开，窄屏收拢为安全区域内面板。发布弹窗按旧 PublishMomentModal 的 520px 居中布局、四行输入、三列图片预览、添加图片按钮与粘贴提示、位置输入和右对齐圆角底栏重建；配色通过现有语义变量适配主题和双模式。保留既有鉴权、上传与发布端口，批量选择及粘贴图片均受九张及10MB约束。

影响：无新依赖；通知非模态关闭后恢复焦点；发布期间禁止重复提交，上传或保存失败保留内容。

替代：直接复制旧 Ant Design 组件违反单一 UI 技术栈约束；继续扩展通用表单样式无法还原专属发布布局。

验证：全部主题×明暗×桌面、375px、390px，覆盖通知菜单、已读/删除与加载失败；发布空内容、文字、上传、图片移除、粘贴、发布失败和关闭焦点；npm run check。
