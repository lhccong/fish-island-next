# ADR-079：像素抽奖转盘

采用旧摸鱼岛 Lottery 的九宫格、顺序减速高亮、单抽/十连抽、每日首次免费、保底进度、中奖记录与十连结果弹窗。修正此前“幸运补给”的错误命名。复用 pet 端口和已有像素纸面/木框 token，不引入依赖或复制旧版 Ant Design 组件。

领域补充服务端进度与奖池项标识，记录按当前转盘过滤。抽奖结果只能由服务端决定，动画只展示真实中奖位置，匹配失败不随机伪造落点。请求与动画共用单一操作锁，关闭取消请求并清理动画；主题和模式不参与请求依赖。每日首次免费次数在所有转盘共享，以全局最新中奖记录判断；首次十连按服务端现有规则抵扣一抽，仅收九抽积分，实际扣费以响应为准。记录沿用共享滚动分页，替代旧版页码。

桌面转盘与记录双栏，手机纵向、奖格维持三列；中奖记录标题固定，列表采用独立 reserved ScrollArea（桌面最高 440px / 55dvh，手机 300px），绑定真实内部视口续载。桌面显示滑轨，手机按 ADR-033 隐藏滑轨但保留滚动。使用共享 Button、Dialog、ScrollArea、LoadingIndicator。保留 reserved gutter，原图不染色。替代方案为继续沿用通用物品卡片，但无法表达抽奖过程，因此不采用。

验证：解码与记录过滤测试；全部注册主题 × 明暗 × 1440/375/390 交互、状态、滚动和布局检查；npm run check。实际执行范围见交付说明。
