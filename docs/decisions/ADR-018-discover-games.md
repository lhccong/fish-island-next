# ADR-018：发现区游戏入口

状态：已采用。日期：2026-11-11。

## 原因与决策

发现区增加与朋友圈同级的“游戏”菜单，游戏目录独立懒加载，首个条目为人生重开模拟器介绍卡片。沿用旧项目 `/game/life` 的游戏入口与免登录约定。

app 负责路由与发现导航组合，游戏目录 feature 只展示介绍并接收打开回调，不依赖鱼小圈、鉴权或外壳。手机将发现菜单放在内容页头，桌面保留侧栏；全部内置主题共用语义 token 与功能实现。

目录路由为 `/discover/games`，卡片进入站内 `/game/life`。按用户明确要求迁移完整旧版模拟器：经典、名人、修仙、成就与本地存档。纯引擎位于 domain/life，通过 index.ts 暴露；features/life 拥有游戏状态、存档交互与分步组件，app 只组合页面。引擎及完整数据在游戏路由懒加载，不进入目录或聊天首屏。

迁移来源为 `fish-island-frontend/src/pages/Game/Life`。把旧版 Immer 更新替换为小型纯状态复制函数，避免新增状态依赖；对 Map/Set 明确复制。数据表转换为本地 JSON，保留原始内容与 ID，通过逐表对比、数据引用完整性与原有测试验证迁移。旧 Excel 转换器不属于运行时，不迁入。旧 Less 在迁移时编译为 CSS Modules，原始颜色统一映射为语义 token，稀有度使用独立默认 token。游戏存档为非敏感本地数据，不承诺跨域同步旧站存档。

引擎数据与规则保持旧协议，遇到超过 300 行的纯规则文件优先按职责拆分；不豁免组件行数、类型安全或依赖边界。

## 影响与替代方案

发现菜单在朋友圈和游戏目录中共享；不增加依赖，也不把游戏代码放入聊天首屏。相比复制旧页面到发现目录，独立入口保留业务边界，并允许后续增加游戏。

## 验证

执行 `npm run check`；浏览器验证全部注册主题在桌面、375px、390px 下的菜单切换、卡片打开地址、键盘可达性与无横向溢出。目录为本地静态内容，无请求加载或失败状态；路由懒加载显示加载提示。

目录按“最近玩过 + 每日一荐”呈现，仅展示已迁移的一款游戏。最近游玩记录真实写入当前浏览器；未玩过时展示空态，不填充虚构游戏或热度。经典流程、修仙和名人模式、成就空态/搜索及存档错误需要浏览器与领域测试覆盖；游戏路由提供加载及错误恢复入口。
