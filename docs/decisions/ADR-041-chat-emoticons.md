# ADR-041 聊天表情包

状态：采用。日期：2026-11-13。

## 原因与决策

迁移旧版收藏表情包的增删、分页及 `[img]URL[/img]` 协议。domain/chat 定义表情包端口，infrastructure/chat 校验 DTO、URL 和鉴权；app 注入，feature 持有账号隔离的收藏变更状态。面板及搜索动态加载，不把草稿或弹窗状态提升到页面。图片菜单与手机更多菜单共享收藏用例，多图消息按图片提供明确入口。

使用现有 Dialog、Button、ScrollArea reserved gutter 和 InfiniteScroll。收藏滚动分页去重、串行、空页/重复页停止，失败保留内容并允许重试。选择图片插入当前光标处的草稿，保留引用，由用户点击发送；删除收藏即时持久化后回读。主题、模式切换不改变请求身份。

按用户要求，搜索沿用 uTools 的百度 `/search/acjson`，关键词补“表情”，每批 30 条，pn 为从零开始的偏移，选图优先 middleURL、回退 thumbURL。通过同源 `/emoticon-search` 固定目标代理访问：Vite 开发/预览代理及生产 Nginx 配置一致，避免 uTools 桌面环境与浏览器跨域能力差异。代理清除 Cookie、Authorization、Origin，并固定 Referer，不转发聊天凭证；前端搜索 credentials omit。生产需部署文档中的代理配置。

搜索复用滚动分页去重，按有效页大小决定继续，空页、重复页停止，追加失败保留内容。百度异常、验证码或非 JSON 返回展示搜索失败，不冒充空结果。旧版源码中的硬编码凭证不迁移；替代方案是浏览器直连百度，因跨域限制不采用。不新增依赖或复制旧 UI。

## 影响与验证

2026-11-13 交互更新：收藏网格取消常驻移除按钮，以 shared/ui/ContextMenu 提供右键与键盘移除；手机另有 44px 更多入口，提供放大预览与移除。搜索结果同样通过菜单收藏。shared/ui/HoverPreview 提供桌面延迟悬停/聚焦预览、Portal 边界定位、Esc 关闭及滚动/卸载清理，不改变图片布局或分页；菜单的放大预览使用既有 Dialog，供手机和持久查看使用。图片使用 contain 保留原貌，预览覆盖加载/失败反馈。移除仍复用同一账号用例，不引入排序接口或新依赖。以全部注册主题 × 双模式 × 三视口验证右键、键盘、手机更多、预览与关闭、移除失败重试及分页。

2026-11-13 兼容修复：后端 JsonConfig 对 Long 使用 ToStringSerializer，收藏分页 total 为十进制字符串。适配层同时接受安全非负整数和十进制数字字符串，转换后交给领域模型；不接受空值、布尔值、小数、指数形式、负数或超出 JavaScript 安全整数范围的值。收藏 ID 保持字符串，不做数值转换。单测及浏览器夹具覆盖后端实际字符串总数，避免数字夹具掩盖协议错误。

菜单方向键、Esc 和焦点继续由 Radix 管理。手机和粗指针在此网格禁用长按上下文菜单，使用 44px 更多按钮，避免图片手势与点击冲突；不修改原消息菜单的长按行为。悬停预览从 window 捕获 Escape，先于弹窗处理，仅关闭当前预览。

复用当前图片安全规则与发送失败重试；不新增消息类型或 WebSocket 连接。关闭面板取消读取，账号切换取消读写并丢弃旧反馈。收藏写入以服务端返回 true 为成功。

运行 npm run check；单测验证协议和取消、失败、去重，浏览器以合成数据验证全部注册主题 × 双模式 × 桌面/375/390 的添加、搜索、收藏续载、删除、草稿、发送及失败恢复、焦点、滚动和溢出；外部真实搜索可用性与真实账号写入单独报告。
