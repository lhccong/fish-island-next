# ADR-041 聊天表情包

## 2026-11-18 本地图片加入聊天收藏

聊天收藏网格预留首格作为加号入口，使用共享 Button 和系统文件选择器。每次选择一张 PNG、JPEG、WebP 或 GIF 图片，复用聊天图片的 10 MB 限制、处理方式及上传端口，再通过已有收藏接口保存。选择、加载和操作反馈由收藏面板与账号级收藏用例管理。借用输入框的图片上传状态会与待发送图片冲突，因此仅复用端口与图片准备逻辑。

上传与其他收藏写入串行，账号切换取消在途请求。成功后刷新当前收藏查询，保留搜索关键词，清空关键词可查看最新收藏。失败保留已有收藏，可重新选择图片。各外壳共用语义配色及现有响应式网格，手机保留至少 44 px 命中范围。使用模拟上传和收藏接口覆盖全部注册主题、明暗模式、桌面及 375 px、390 px 手机视口，验证文件选择、上传反馈、失败恢复、收藏回读、草稿及分页。

## 2026-11-18 收藏内容搜索

后端使用 `io.github.mymonstercat:rapidocr` 0.0.7 与 ONNX PP-OCRv4 在本地识别新收藏图片中的文字。明确打包 Windows/Linux x64 原生库，保证从 Windows 打包也能部署到既有 Linux x64 容器。WebP 解码使用 TwelveMonkeys ImageIO；动图识别首帧。通过限时、限量的公网图片下载和有界像素解码提供本地 PNG 输入，不记录图片地址或识别文字。

Linux 容器使用多阶段构建，在构建阶段以 patchelf 清除上游库的可执行栈标记，运行时从 RapidOCR 的临时目录加载处理后的库，保留系统栈保护。以 Temurin 17 容器内的实际识别验证原生库兼容性，独立运行 JAR 的准备步骤见后端部署文档。

收藏记录同时写入识别任务。独立单线程从数据库领取到期任务，跨实例以条件更新抢占，短暂故障有限重试；已有收藏无任务，保留原列表和交互。OCR 结果存入 `ocrText`。现有收藏分页接收可选 `keyword`，只在当前账号的识别文字中做字面子串匹配，按创建时间及 ID 倒序。采用账号内数据库过滤，避免只过滤已加载图片，也避免引入全文搜索服务；采用持久化任务，避免同步 OCR 延迟收藏或内存队列丢失待识别任务。

聊天收藏及评论表情面板在网格上方使用共享搜索表单和既有语义配色，提交或清空时重新起算分页并中止旧请求。手机输入字号 16px，控件至少 44px。聊天网络搜索继续使用独立页签。搜索不进入聊天草稿、消息订阅或连接生命周期。验证包括实际 OCR、账号过滤及通配符转义，以及全部主题 × 明暗模式 × 桌面/375px/390px 的查询、加载、空结果、失败重试、清空、选择和滚动边界。

状态：采用。日期：2026-11-13。

## 原因与决策

迁移旧版收藏表情包的增删、分页及 `[img]URL[/img]` 协议。domain/chat 定义表情包端口，infrastructure/chat 校验 DTO、URL 和鉴权；app 注入，feature 持有账号隔离的收藏变更状态。面板及搜索动态加载，不把草稿或弹窗状态提升到页面。图片菜单与手机更多菜单共享收藏用例，多图消息按图片提供明确入口。

使用现有 Dialog、Button、ScrollArea reserved gutter 和 InfiniteScroll。收藏滚动分页去重、串行、空页/重复页停止，失败保留内容并允许重试。选择图片通过已有发送用例直接发送独立图片消息，保留当前文字及引用草稿；删除收藏即时持久化后回读。主题、模式切换不改变请求身份。

按用户要求，搜索沿用 uTools 的百度 `/search/acjson`，关键词补“表情”，每批 30 条，pn 为从零开始的偏移，选图优先 middleURL、回退 thumbURL。通过同源 `/emoticon-search` 固定目标代理访问：Vite 开发/预览代理及生产 Nginx 配置一致，避免 uTools 桌面环境与浏览器跨域能力差异。代理清除 Cookie、Authorization、Origin，并固定 Referer，不转发聊天凭证；前端搜索 credentials omit。生产需部署文档中的代理配置。

搜索复用滚动分页去重，按有效页大小决定继续，空页、重复页停止，追加失败保留内容。百度异常、验证码或非 JSON 返回展示搜索失败，不冒充空结果。旧版源码中的硬编码凭证不迁移；替代方案是浏览器直连百度，因跨域限制不采用。不新增依赖或复制旧 UI。

## 影响与验证

2026-11-13 发送交互更新：点击收藏或搜索表情直接调用既有发送用例，单独发送 `[img]URL[/img]`；不读取、拼接或清空文字及引用草稿。入队成功关闭面板，失败在面板提示，网络发送失败继续使用消息行重试，重试沿用 clientMessageId。图片消息缩略图从 320px 调整为 214px（约缩小三分之一），保留比例和窄屏上限；点击图片/键盘激活后按需挂载放大 Dialog，支持加载、失败重试、Esc 与关闭后焦点归还。手机长按不同时触发图片预览，保留原消息菜单。图片查看局部状态只属于对应图片，不提升到页面，不新增请求协议或依赖。验证直接发送不污染草稿/引用、失败重试、缩略图尺寸与图片点击预览，沿用全部主题、双模式和三视口矩阵。

2026-11-13 交互更新：收藏网格取消常驻移除按钮，以 shared/ui/ContextMenu 提供右键与键盘移除；手机另有 44px 更多入口，提供放大预览与移除。搜索结果同样通过菜单收藏。shared/ui/HoverPreview 提供桌面延迟悬停/聚焦预览、Portal 边界定位、Esc 关闭及滚动/卸载清理，不改变图片布局或分页；菜单的放大预览使用既有 Dialog，供手机和持久查看使用。图片使用 contain 保留原貌，预览覆盖加载/失败反馈。移除仍复用同一账号用例，不引入排序接口或新依赖。以全部注册主题 × 双模式 × 三视口验证右键、键盘、手机更多、预览与关闭、移除失败重试及分页。

2026-11-13 兼容修复：后端 JsonConfig 对 Long 使用 ToStringSerializer，收藏分页 total 为十进制字符串。适配层同时接受安全非负整数和十进制数字字符串，转换后交给领域模型；不接受空值、布尔值、小数、指数形式、负数或超出 JavaScript 安全整数范围的值。收藏 ID 保持字符串，不做数值转换。单测及浏览器夹具覆盖后端实际字符串总数，避免数字夹具掩盖协议错误。

菜单方向键、Esc 和焦点继续由 Radix 管理。手机和粗指针在此网格禁用长按上下文菜单，使用 44px 更多按钮，避免图片手势与点击冲突；不修改原消息菜单的长按行为。悬停预览从 window 捕获 Escape，先于弹窗处理，仅关闭当前预览。

复用当前图片安全规则与发送失败重试；不新增消息类型或 WebSocket 连接。关闭面板取消读取，账号切换取消读写并丢弃旧反馈。收藏写入以服务端返回 true 为成功。

运行 npm run check；单测验证协议和取消、失败、去重，浏览器以合成数据验证全部注册主题 × 双模式 × 桌面/375/390 的添加、搜索、收藏续载、删除、草稿、发送及失败恢复、焦点、滚动和溢出；外部真实搜索可用性与真实账号写入单独报告。
