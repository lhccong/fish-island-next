# ADR-021 账号资料卡与资料编辑

状态：已采用。日期：2026-11-12。

## 原因与范围

账号入口原来仅展示名称和退出按钮。参考旧摸鱼岛，将其改为资料卡与编辑表单，迁移用户名（必填、无空白、最多 10 字）、头像、朋友圈背景和个人简介（最多 100 字）。2026-11-12 按完整旧版弹窗补齐默认头像、邮箱验证码绑定、称号即时设置、会员资料及破蛋日，不复制旧框架或巨型组件。

## 决策与影响

- 2026-11-12 按反馈重整资料编辑视觉：清晰分区、头像操作与地址分行、背景/称号区域并排卡片、桌面并排的会员与破蛋日摘要，手机顺序排列。保留所有既有业务和即时生效规则；操作按钮按 ADR-026 采用桌面 32px、手机 44px 及主题动作色。
- 称号选择复用 shared/ui/Select，基于 Radix Select 实现 combobox/listbox 语义和完整的展开面板，包含键盘、输入匹配、焦点归还、外部点击关闭和可用空间内上下展开。不用操作菜单替代选值语义；选择器基础设施遵循 ADR-024。

- domain/auth 扩展资料字段和修改、图片上传端口；infrastructure/auth 映射旧版 POST /api/user/update/my 及图片上传协议，保留 Sa-Token 鉴权。
- features/auth 拥有编辑草稿、上传与反馈；认证控制器在保存确认后更新会话，再回读用户信息，不调用会进入 checking 状态的 restore，避免卸载业务与丢失草稿。回读网络失败保留已确认修改并提示，避免重复提交修改用户名。
- 资料仅保存在会话内存，禁止将用户信息、图片内容和凭证写入日志或源码。取消不保存表单；上传图片本身已经到服务器，取消不自动删除远端文件。
- 采用现有 Dialog、Button 和语义 token，不增加依赖或外壳分支；桌面双栏表单、手机单栏，支持安全区域和弹窗内滚动。
- 邮箱发送/绑定复用 /api/user/email/send 与 /email/bindToAccount；绑定成功独立生效。称号从 /api/user/title/list 读取，默认等级称号和管理员监督员沿用旧版规则，POST /title/set?titleId=... 即时生效。两种独立操作均回读会话并保留未保存草稿，取消基础资料不会撤销已经成功的绑定/称号。
- 会员读取 /api/user/vip/get/my 与 /vip/check/permanent，逐区处理 loading/empty/error/success 并提供重试；不伪造会员身份。破蛋日使用 createTime，以 Asia/Shanghai 解析无时区时间并计算生活天数；日期无效时明确显示暂无记录。
- 使用局部 profile 语义色保留会员与破蛋日卡片、绿色已绑定/当前称号状态；暗夜模式单独提供可读颜色，全部主题共用。保存按钮的旧版橙色已按 ADR-026 移除，改用当前主题动作色。

## 替代方案

不复制旧 AvatarDropdown 的巨型组件及 UI 框架；不在组件内直接请求 API；不通过整页刷新更新头像。

## 验证

执行 npm run check。测试旧协议、服务器拒绝、鉴权失效、保存后回读、取消和草稿保留；按注册表全部主题 × 明暗模式 × 桌面/375px/390px 验证查看、编辑、上传、失败、保存及关闭流程。
