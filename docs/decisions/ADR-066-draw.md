# ADR-066 你画我猜迁移

状态：采用。日期：2026-11-14。

原因：恢复旧版独立你画我猜入口，替换误指向卧底的路由，复用真实房间、猜词和画布协议。

决策：domain/draw 定义端口和模型，infrastructure/draw 校验旧 HTTP 及 WebSocket 数据，features/draw 分离房间同步、画布和猜词草稿；app 注入账号凭证并复用唯一账号连接。不复制旧页面、不新增依赖。游戏目录、最近玩过、独立窗口和 /game/draw/:roomId? 共用功能实现。

绘画使用固定 900×600 坐标及 Pointer Events，显示尺寸自适应，缩放不清空画布。刷新事件读取服务端快照。画纸与颜料作为作品素材保持原貌，界面使用主题语义变量。桌面画布与玩家/猜词双栏，窄屏纵向重排，手机仅画布区域禁用触摸平移，页面仍可滚动。颜色选择使用共享 Select。房主结束/退出通过共享确认框。

手动保存（2026-11-22）：恢复旧版由绘画者点击「保存」提交完整 PNG 的交互。画笔、橡皮、撤销及清空只修改本地画布，避免自动上传未完成画作和触发房间刷新。画布下方使用共享 Button 和 LoadingIndicator，保留现有下一轮、结束和退出的未保存保护。保存只允许单个请求在途，失败可再次点击，保存期间产生的新修改须再次点击才提交。复用现有 HTTP 和 WebSocket 协议，整页、独立小窗及全部外观共用实现。浏览器矩阵验证编辑不上传、点击上传、失败重试、请求期间继续编辑，以及外观切换和小窗收起后保留本地修改。

房间聊天与颜料（2026-11-22）：参考旧版，把房间发言、系统消息和输入放进聊天室，绘画者、已猜中及画作尚未上传时使用聊天文案，其余玩家猜词。复用后端既有 `/guess` 的聊天与猜词分支，遵守进行中和房间成员限制；发送成功后在发件人窗口补齐本地回显。房间快照按既有刷新帧更新，聊天消息只进入当前聊天室。桌面聊天室在画布旁，手机紧跟画布，猜词记录与玩家列表独立。整页画室沿用五子棋的工作台状态插槽留空，给画布和聊天室保留触控空间，回大厅恢复用户的工作时间显示偏好。画笔提供更多预设和共享 Popover 内的十六进制自定义色，颜料属于作品素材。保留现有端口及连接，避免增加聊天连接、公共聊天状态及系统色板。浏览器矩阵覆盖角色文案、发信回显、房间隔离、颜色应用、键盘与触屏、布局和外观切换。

布局补充（2026-11-22）：按参考图将工具和本轮信息归入画板上沿，右栏从上到下排列玩家分数、聊天与猜词记录。窄容器先排本轮操作及画布，再排聊天与猜词记录，末尾放玩家分数。聊天室和猜词记录共用外层面板，各自保留可访问的滚动区。房间页和独立小窗复用相同排列及业务组件。验证覆盖上沿对齐、窄屏顺序、焦点和记录滚动，以及保存、猜词、轮换和退出。

替代方案：复制旧 Ant Design 页面违反分层和 UI 规范；新增独立连接破坏单连接边界；逐点广播没有现有服务协议支持，不采用。

影响：保留旧服务端权限、轮换、词库、得分与猜词规则。未新增离线游戏或多人逐点同步协议；同步以服务端确认的整幅作品为准。

协议校正（2026-11-16）：旧服务将 Long 序列化为十进制字符串，适配层接受非负安全整数及其十进制字符串，继续拒绝空串、小数、负数、非有限值及越界值。`roundEndTime` 按服务端 Unix 秒协议转换为领域 `endTime` 毫秒时间戳，空值或零保留为 0，并校验转换后不溢出；列表与详情共用同一解码。浏览器夹具同步采用秒字符串，验证真实协议形态下的房间列表和倒计时递减，避免毫秒夹具掩盖错误。无需修改服务端、外壳、主题或请求生命周期。

验证：端口测试覆盖解码、鉴权、协议和错误；浏览器以合成服务覆盖全部注册皮肤×明暗×1440/375/390 的加载、空、失败、创建、绘画、猜词、轮换、结束、退出与布局。真实多人联机需部署后联调，未完成前不得宣称已验证。

2026-11-16 回归：`npm run check` 通过（475 项单元测试，含绘画协议 25 项）；84 项 Chromium 浏览器用例通过，覆盖摸鱼岛、摸鱼岛像素风、WPS 表格、微信绿、企业微信、飞书蓝、钉钉蓝 × 明亮/暗夜 × 1440/375/390px，包含独立窗口、加载/空/失败/成功、列表解析、倒计时递减、绘画/猜词/轮换/结束/退出及换肤状态保留。已抽查桌面与手机实际截图；本次使用合成服务，未验证生产接口和真实多人联机。
