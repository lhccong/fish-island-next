# ADR-066 你画我猜迁移

状态：采用。日期：2026-11-14。

原因：恢复旧版独立你画我猜入口，替换误指向卧底的路由，复用真实房间、猜词和画布协议。

决策：domain/draw 定义端口和模型，infrastructure/draw 校验旧 HTTP 及 WebSocket 数据，features/draw 分离房间同步、画布和猜词草稿；app 注入账号凭证并复用唯一账号连接。不复制旧页面、不新增依赖。游戏目录、最近玩过、独立窗口和 /game/draw/:roomId? 共用功能实现。

绘画使用固定 900×600 坐标及 Pointer Events，显示尺寸自适应，缩放不清空画布。落笔自动保存完整 PNG，保存串行合并最新版本，失败保留画作供手动重试；刷新事件读取服务端快照。画纸与颜料作为作品素材保持原貌，界面使用主题语义变量。桌面画布与玩家/猜词双栏，窄屏纵向重排，手机仅画布区域禁用触摸平移，页面仍可滚动。颜色选择使用共享 Select。房主结束/退出通过共享确认框。

替代方案：复制旧 Ant Design 页面违反分层和 UI 规范；新增独立连接破坏单连接边界；逐点广播没有现有服务协议支持，不采用。

影响：保留旧服务端权限、轮换、词库、得分与猜词规则。未新增离线游戏或多人逐点同步协议；同步以服务端确认的整幅作品为准。

协议校正（2026-11-16）：旧服务将 Long 序列化为十进制字符串，适配层接受非负安全整数及其十进制字符串，继续拒绝空串、小数、负数、非有限值及越界值。`roundEndTime` 按服务端 Unix 秒协议转换为领域 `endTime` 毫秒时间戳，空值或零保留为 0，并校验转换后不溢出；列表与详情共用同一解码。浏览器夹具同步采用秒字符串，验证真实协议形态下的房间列表和倒计时递减，避免毫秒夹具掩盖错误。无需修改服务端、外壳、主题或请求生命周期。

验证：端口测试覆盖解码、鉴权、协议和错误；浏览器以合成服务覆盖全部注册皮肤×明暗×1440/375/390 的加载、空、失败、创建、绘画、猜词、轮换、结束、退出与布局。真实多人联机需部署后联调，未完成前不得宣称已验证。
