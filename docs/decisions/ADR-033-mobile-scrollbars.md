# ADR-033 手机隐藏滑轨并保留滚动行为

状态：已采用。日期：2026-11-12。

## 原因与方案

按用户要求，手机视口（沿用 760px 断点）隐藏所有可视滚动条，内容继续使用既有原生滚动容器与 Radix ScrollArea。应用全局基础样式通过 scrollbar-width 与 WebKit 滚动条伪元素隐藏原生滑轨，包含 textarea、弹窗、菜单和横向分类栏；共享 ScrollArea 在手机隐藏 Radix 滑轨外观和指针命中，保留其布局测量与原有 viewport。桌面滚动条不变。

不得修改 overflow、scrollTop、触屏事件、键盘事件、焦点或滚动状态；不能通过 overflow:hidden、阻止默认触摸事件、替换容器或清空位置实现。reserved gutter 的手机 20px 与正文留白继续保留，不因滑轨不可见而缩减。

## 规范调整与替代方案

AGENTS.md 新增手机滚动条规则，并修订第 13 条：主动显示滑轨的要求仅用于桌面；手机检查滑轨隐藏、内容间距、完整滚动与首末焦点。component-standards.md 同步修订，覆盖 ADR-025 中手机必须显示滑轨的历史要求。仅隐藏 thumb 仍会留下滑轨，不满足本次要求；禁用 overflow 会破坏功能，拒绝采用。

## 验证

全部注册主题 × 明暗模式 × 桌面、375px、390px 检查主内容、热榜内部列表、成员列表、弹窗与原生滚动容器；验证键盘/触屏、scrollTop、焦点及底部内容可达，不改变请求或草稿。真实设备系统软键盘单列未验证。
