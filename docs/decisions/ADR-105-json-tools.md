# ADR-105 工具导航与 JSON 格式化

状态：已采用。日期：2026-11-23。

## 决定

复用工作台桌面导航和手机发现菜单。`/utils` 转到旧版公开地址 `/utils/json`，商城保留其独立入口。页面按需加载并复用同一个编辑器。桌面并排展示输入和结果，手机纵向排列，复用站内明暗模式、主题语义变量与共享控件。

工具页的应用层注册表同时提供路由、页签名称和按需加载的内容。页签使用独立地址，支持浏览器前进与后退。方向键和 Home/End 移动焦点，Enter 或空格打开工具，加载期间页签栏仍可操作。当前只注册 JSON 格式化。相比在编辑器内部维护页签索引，地址作为选中依据，可直接打开工具且不依赖访问顺序。

编辑器独立持有草稿、处理选项、树展开状态和文件操作，换肤和模式切换保留当前编辑内容。格式化、压缩、校验和 YAML 转换在浏览器本地执行。文件读取、复制和下载只使用浏览器本地能力，输入与结果仅存在页面内存。JSON 严格解析，不执行输入。格式化和压缩只改变空白字符，保留长数字、转义和重复键的原文。支持示例、清空、将 JSON 结果放回输入、缩进选择和自动处理。文件读取限制为 2 MiB。树展开按层控制，节点过多或嵌套过深时显示完整文本结果。

## 依赖与替代方案

复用旧工具所用的 `yaml` 包（ISC），在工具路由的异步依赖图中固定版本，通过 npm 的单一锁文件管理。使用库处理字符串转义、集合和多行标量，避免手写 YAML 序列化。JSON 使用浏览器原生解析器。旧版 UI 与树查看器依赖由共享控件和功能内的展开组件取代，外观沿用站内全局设置。

## 验证

执行 `npm run check`。覆盖全部注册主题、明亮和暗夜模式，以及桌面、375px 和 390px。检查工具入口、返回、加载、空白、解析和读取失败、成功输出、树展开、文件操作、选择器焦点返回与纵向滚动。验证外观切换保留草稿和输出。

页签额外验证单工具显示、键盘和触屏操作、选中与聚焦样式、窄屏布局。浏览器测试通过临时注册第二个工具验证地址与页签联动。
