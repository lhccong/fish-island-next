# ADR-039 摸鱼股市迁移与日 K 成交标记

日期：2026-11-13。状态：采用。

## 原因与方案

旧版积分指数交易只有实时行情、持仓和分页交易记录，无法从实时点位还原真实 OHLC。新增 domain/stock 端口、infrastructure/stock 协议适配、features/stock 展示与请求状态，app 注入服务并懒加载鉴权路由 `/game/stock`。游戏目录增加股市入口；业务逻辑不复制旧版 Ant Design 页面，不增加依赖。

后端新增鉴权 `/index/chart?indexCode=...&days=60|120|250`，仅允许现有五个指数。独立服务通过固定 HTTPS 腾讯行情地址获取日 K，校验日期、数值及 OHLC，缓存公共行情 60 秒；用户标记每次按当前登录账号、指数及行情日期范围查询，不缓存用户记录。返回最多 5000 条标记并显式报告截断。所有有成交净值与份额的买入/卖出都展示，卖出待结算不等于未成交。成交点位为既有净值 × 1000，日期使用下单的上海日期，不能用结算日替代；非交易日成交不移到其他蜡烛，显示未匹配数量。

## 表现与影响

2026-11-13 按用户提供的 Web 参考图调整：首页使用铺满工作区的四项资产概览、市场行情/我的持仓/交易记录页签，指数卡片桌面三列、手机单列。移除 1200px 最大宽度及首屏常驻 K 线，点击指数进入 `/game/stock/:indexCode` 详情，详情再按需加载 K 线与 B/S。同一可选参数路由保留概览请求与页签状态；返回概览恢复来源页签，交易记录首次打开加载并保持分页。主题外壳仅改变呈现，不复制业务逻辑。今日盈亏按实时指数日涨跌幅与当前持仓市值估算，不使用持仓成本收益率冒充日涨跌；缺少行情时显示不可用。单指数 0 点占位显示行情暂不可用，不让一个失效指数遮蔽其余有效行情。兼容旧版持仓响应遗漏 frozenShares（未提供时按 0 处理）。

使用原生 SVG 蜡烛和 HTML B/S 标记，不增加图表库。图表在窄屏保持可读高度，展示完整所选范围；同日同方向聚合一个至少 44px 的标记，点击/聚焦查看该日逐笔成交，B/S 位置分置图上/下方避免遮挡。采用语义 token，涨买使用 danger、跌卖使用 accent-text，同时有文字、形状说明。主题/模式切换不参与数据依赖，不清空交易输入。交易沿用服务端积分、锁定、手续费和结算规则，提交结果与刷新失败分别反馈；失败不自动重试交易。

交易记录使用共享滚动分页，串行、取消、ID 去重、空/重复页停止；图表标记使用独立范围查询，不依赖记录列表已经翻到哪一页。loading/empty/error/success 分区显示，行情失败不造数据。

## 替代方案与验证

拒绝以单点行情伪造 K 线、仅用第一页成交作标记、引入第二套 UI 或图表依赖。后端新增协议需部署才可使用图表；旧服务未部署时显示明确错误，现有买卖能力独立可用。

验证：OHLC 解码、标记归组/范围、请求鉴权与取消、后端解析及账号过滤单测；浏览器全注册主题 × 明暗 × 桌面/375/390 验证图表、成交详情、交易确认、失败重试、滚动分页和无横向溢出。结果和限制记录在 docs/audits/stock-market.md。

## 历史展开缩放（2026-11-13）

按用户要求，历史滑块从平移固定20根窗口改为固定最新交易日、向过去累积展开；初始最近20根，拖至最远显示当前已读取范围全部60/120/250根。图内蜡烛宽度按数量等比例缩小，纵轴按全部可见OHLC重新计算，不裁掉最新K线，不改变后端请求和交易规则。视口内同方向相邻买卖标记间距不足56px时，按时间顺序聚合为含日期范围和逐笔记录的B/S计数标记；触控入口仍为44px，避免缩小后覆盖或堆成多行。主题/模式切换不重置缩放或触发取数。验证最新日保持、显示根数、缩小宽度、范围首末买卖点、聚合明细和全主题明暗/桌面375/390的实际拖动与无溢出。

## 成交价锚定修正（2026-11-13）

用户指出图外B/S没有标在K线上。现改为每笔成交按真实下单日期对齐对应蜡烛中心，按成交净值×1000映射纵轴，在图内绘制成交圆点。纵轴同时容纳蜡烛OHLC和可见成交价，禁止把真实价格强制贴到最高/最低价或伪造均价。B/S可点击标签紧邻实际成交点，避让时用引线准确连接；缩小时标签可以聚合，但所有原始成交点保留，聚合标签锚定其中一笔真实成交，不生成虚拟买卖价。图外上下标记带取消。验证日期/价格坐标、引线端点、首末范围、密集标签避让、B/S明细及全主题明暗×桌面/375/390。
