# ADR-002：微信基础外壳与公开热榜优先接入

- 日期：2026-11-11
- 状态：采用

## 决策与原因

用户要求优先提供微信风格基础框架并接通热榜，因此在聊天闭环前先交付公开热榜。默认首页进入热榜，初始化演示保留在 /foundation，/chat 明确显示未接入状态，不伪造会话和消息。

采用独立 domain/hot-board 领域契约、infrastructure/hot-board HTTP 适配、features/hot-board 状态与业务界面，app 创建适配器并注入功能。shells/wechat 仅接收导航、侧栏、页头和内容插槽，不订阅业务状态。现有聊天插槽契约保留供聊天使用，新增工作台插槽契约承载非聊天页面。

旧系统接口：POST https://api.yucoder.cn/api/hot/list，响应 code/data/message；已实测 code=0，来源 ID 实际为字符串，data 包含多个来源及条目。公开读取不携带用户凭证。默认复用此公开地址，可通过 VITE_API_BASE_URL 替换；空值使用默认公开地址。服务端已经允许本地跨域访问，当前不新增代理或后端。

适配器校验 unknown 响应、标准化 ID、过滤无标题条目、去重、屏蔽非 HTTP(S) URL，并有 15 秒超时。失败显示错误与重试，刷新失败保留上次数据。组件只渲染纯文本，不使用 HTML。

## 设计与约束

根据用户提供的微信桌面版参考图，采用浅灰窄导航栏（#dfdfdf）、灰色来源列表（#e8e8e8）、近白主内容区（#fafafa）、中性黑灰文字及实绿色选中行（#10b46c），收紧圆角与留白，不使用深色导航或大幅宣传区。窄屏转为顶部导航和来源选择，不让侧栏挤压内容。语义 token 增加外壳和热榜状态色，第三方皮肤可导入 token 白名单仍为两项，不自动扩大。

来源切换、分类和搜索均在已取回的只读数据上计算，不重复请求。每个来源默认展示 8 条，支持展开/收起；使用服务端顺序作为原始排名，不按搜索结果重新编号。不引入新依赖。手动刷新，暂不轮询或持久缓存。

## 验证

单元测试覆盖 DTO 校验、错误、URL 和重复数据；浏览器夹具测试覆盖筛选、搜索、展开、失败重试、刷新保留数据、桌面与窄屏。另单独执行真实接口浏览器验证，不能用 mock 测试冒充已对接。
