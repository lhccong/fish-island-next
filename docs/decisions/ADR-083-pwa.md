# ADR-083：PWA 安装与离线外壳

状态：已采用。日期：2026-11-16。

## 原因与方案

支持摸鱼岛安装到桌面或手机主屏幕。使用原生 Web App Manifest、PNG 安装图标和 Service Worker，不增加依赖。浏览器提供安装入口；iOS 使用 Safari 分享菜单的“添加到主屏幕”。不增加自定义安装弹窗，保留全部主题、外壳、明暗模式和响应式布局。

Vite 本地构建插件从发布产物生成精确缓存清单及内容版本，预缓存 HTML、JS、CSS 和安装图标。公共素材目录不整库预取。worker 只读取精确白名单静态缓存，导航返回该版本的静态 HTML，确保页面和分块版本一致；其余请求直接联网，不做动态缓存。仅应用路由导航提供离线外壳，API、WebSocket、代理及文件路径不回退 HTML。请求凭证、API、聊天记录、用户图片和第三方资源不进入 Cache Storage。离线不支持登录、收发消息或提交业务，不提供离线队列。

注册属于 app 启动生命周期，开发环境不注册。注册失败只记录固定错误说明，不输出请求或账号数据，不影响正常页面。更新沿用 waiting 生命周期，不调用 skipWaiting、不自动重载；所有旧窗口关闭后新版本接管并清理本应用旧版本缓存。主题和模式切换不参与注册，不改变业务状态、连接或偏好。SkinProvider 将浏览器 theme-color 同步为当前主题和模式的 color-canvas；manifest 的静态启动背景采用暗夜基色。安装图标独立于可伪装的标签页图标；不将用户本机标签图标覆盖到 Apple 安装图标。

## 替代方案与影响

- vite-plugin-pwa / Workbox：当前仅静态外壳缓存，不需引入额外依赖及运行时策略；复杂离线能力另立 ADR。
- 自动激活刷新：会打断草稿与游戏，拒绝采用。
- 缓存 API 或离线消息：引入账号隔离、过期和同步问题，不在本次范围。

首次安装预取构建 JS/CSS，增加一次静态资源下载。缓存不足或任何必需资源下载失败时 worker 安装失败，旧版与在线应用仍可使用。应用素材未缓存，离线时部分图片可能无法显示，保持原有失败反馈。

## 部署

生产需要 HTTPS（本地 localhost 例外），按现有约定部署在域名根目录。`/sw.js` 和 `/index.html` 使用 `Cache-Control: no-cache`，`/manifest.webmanifest` 使用正确 MIME `application/manifest+json` 并允许重新验证；带内容哈希的构建资源可以长期缓存。CDN 不得将 sw.js、manifest 或图标缺失响应重写为 HTML；保留应用路由 history fallback。发布需同时上传完整产物，旧哈希资源建议保留至少一个发布周期。

## 验证

执行 npm run check。独立 Playwright 配置使用生产 preview 验证 manifest、图标、注册、静态缓存、API/第三方排除、离线路由与错误、更新 waiting 及旧缓存清理；按注册主题 × 明暗 × 桌面/375px/390px 检查离线外壳和无横向溢出。操作系统真实安装、Safari/iOS 安装及线上 HTTPS/CDN 响应头需部署后实机验收。
