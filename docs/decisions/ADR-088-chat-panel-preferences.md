# ADR-088 聊天侧栏本机偏好与网站名称同步

状态：采用。日期：2026-11-16。

## 原因

经典聊天的成员列表、鱼小圈收起状态仅存于组件内存，刷新或重新进入后丢失；经典导航品牌名称写死，未同步网站设置。

## 决策与影响

appearance 独立 store 保存两个布尔偏好，使用版本化 localStorage 键，仅保存界面显隐，不包含账号或聊天内容。读取异常、字段非法时按字段回退默认值；写入受限时仍保留本次会话选择。app 经公开入口订阅并注入受控的经典成员呈现，chat 不依赖 appearance。鱼小圈沿用 hideSidebar 保持挂载；手机弹窗及群聊详情不持久化，不受桌面收起偏好影响。换肤、明暗切换不修改偏好或通信生命周期。

经典导航订阅已有网站名称 store，与标签页共用保存成功后的名称；长名称在有限宽度内省略并保留完整 title，避免挤出导航。其他外壳维持各自入口。

## 替代方案

组件内自行读写存储会分散外观状态且在重挂载时难以共享；服务端保存会新增协议且改变本机偏好语义，均不采用。

## 验证方式

单元测试覆盖默认值、字段校验、持久化恢复及存储不可用。Playwright 合成接口验证全部注册主题 × 明暗 × 桌面/375px/390px，覆盖刷新、路由返回、切换外观、四态、手机弹窗及无横向溢出；网站设置验证名称即时同步、刷新恢复及长名称边界。交付执行 npm run check，临时验收产物在提取结论后清理。

- `npm run check` 通过，106 个单测文件、432 项测试通过，生产构建成功；既有分块体积和 MomentEditor 混合导入警告仍存在。
- Chromium 合成接口下，摸鱼岛、摸鱼岛像素风、WPS 表格、微信绿、企业微信、飞书蓝、钉钉蓝 × 明亮/暗夜 × 1280px 桌面、375px、390px 的 129 项浏览器矩阵通过；经典成员四态另 6 项通过。390px 四态曾因共用服务器随另一测试进程结束而断开，独立重跑 2 项通过。
- 覆盖两个侧栏的独立保存、刷新/路由恢复、主题与模式切换保留草稿且不新增历史请求/连接、手机弹窗开关、动态真实触屏滚动、失败重试、网站名称即时同步与刷新恢复、60 字名称边界；人工检查桌面及手机截图。
