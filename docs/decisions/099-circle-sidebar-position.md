# ADR-099 鱼小圈左右布局本机偏好

状态：采用。日期：2026-11-17。

## 原因

经典聊天室鱼小圈固定在左侧，用户需要在左侧、右侧之间选择并在刷新后恢复。

## 决策与影响

扩展 ADR-088 的 appearance store，在原有版本化 localStorage 对象中增加 circlePosition，合法值为 left/right，旧数据、非法值和读取失败默认 left。写入受限时保留当前会话选择，与收起偏好独立保存，不含账号、消息或草稿。

经典鱼小圈标题工具区提供 shared/ui/Select 图标入口，明确选项为聊天室左侧/聊天室右侧；手机聊天顶部提供同一选择，标为鱼小圈电脑布局，保存电脑布局偏好，手机继续使用单列聊天。其余主题保持原有外壳，切回经典主题恢复位置。

app 经 appearance 公开入口订阅并注入 WorkspaceLayout → WechatShell 的 sidebarPosition 纯呈现属性，仅经典聊天室使用。桌面通过 CSS grid 调换侧栏与聊天室列宽和位置；不改变 DOM/组件身份、滚动容器、请求依赖或业务状态。收起后聊天仍占完整区域，恢复时保持所选位置。全部主题与明暗模式复用共享选择器语义 token，不新增依赖。

## 替代方案

条件分支交换 React 子树会重挂载输入和列表；各组件直接读写存储会分散偏好；服务端保存会新增协议并改变本机设置语义，均不采用。
