# ADR-035 公共群聊实时接收

日期：2026-11-12。状态：采用。

后续 ADR-036 已补齐首次 HTTP 历史和向上滚动续读；下文“不读取历史”是本 ADR 最初阶段范围。

## 2026-11-13：静默状态与自动重连

按用户要求隐藏聊天顶部连接说明、漏收提示和手动重连入口，连接状态仅提供不占布局空间的读屏播报。保留通信层现有指数退避：基准 1、2、4、8、16、30 秒，每次取基准的 75%～100% 随机抖动；到上限后持续自动重试。短暂 open 不重置，稳定 30 秒后才重置；15 秒握手超时继续退避。离线暂停，online 立即恢复；认证失效和主动退出停止。替代方案是保留常驻提示栏/固定间隔重试，不符合本次展示要求及退避规范。无新依赖、无连接所有权变化，断线补拉限制仍存在，不能因隐藏提示宣称无丢失。用假时钟精确验证增长、上限、稳定重置、离线和清理；浏览器验证全部主题 × 明暗 × 桌面/375/390 隐藏状态、不占位、自动恢复、草稿及消息保留。

## 原因与范围

按旧版 services/websocket.ts 和 Chat 页面核对协议，迁移公共群聊连接、接收、断线重连、撤回推送及本人撤回请求；不接入消息发送。本轮不读取历史接口，也不将游戏、房间事件误作公共群消息。

## 决策

- domain/chat 定义已确认消息、连接状态和可释放通信端口；infrastructure/chat 负责 unknown 校验、WebSocket 与协议；features/chat 持有归一化 Zustand store、批量提交及虚拟消息列表；app 在账号生命周期内唯一拥有连接。主题、模式和路由切换不影响连接。登出清空消息与待处理事件。
- 沿用旧协议 `/ws/?token=`（令牌仅用于建连，不输出到日志或持久化新副本）。open 后 `{type:1}`，每 25 秒 `{type:4}`。接收 `chat.data.message`、`userMessageRevoke.data`；撤回请求 `{type:2,userId:-1,data:{type:'userMessageRevoke',content:id}}`。服务端撤回推送才是成功事实；超时展示失败、允许重试。
- 重连有指数退避、随机抖动、30 秒上限与连接超时；离线暂停，在线恢复；认证关闭码 1008/4001/4401 停止自动重试并触发会话复核。旧协议未证明心跳响应格式，不能猜测 pong 或依赖不存在的 ack。没有 cursor/seq 补拉协议，重连只恢复实时接收，提示期间可能漏收。
- 16ms 入站批量更新，队列达到 200 条立即提交，不丢弃后台事件。消息以服务端稳定 ID 归一化，重复投递首次内容为准，撤回幂等且清空正文。撤回先到时保留有界墓碑。按 timestamp、ID 排序；不伪造时间或 ID，拒绝不安全数字 ID。仅安全纯文本呈现，HTML 不执行。
- 活跃消息窗口最多 1000 条；逐出时记录排序下界，拒收下界之前的重放，防止旧消息重新出现。撤回墓碑最多 10000 条，优先适配当前窗口；不宣称无限历史或无限期乱序撤回一致性。刷新/登出不保留聊天正文。历史、图片/富文本解析、引用跳转另行迁移。
- Virtuoso 使用 shared/ui/ScrollArea 实际视口；消息行只订阅本实体，列表只订阅 ID，草稿仍由 Composer 独立持有。靠近底部跟随；离开底部提示新消息，不强行滚动。

## 替代方案与影响

不复制旧页面巨型状态和 WebSocket 单例 UI 副作用；不新增依赖。拒绝通过内容去重（同文不同 ID 是两条合法消息）。不使用乐观删除模拟撤回成功。连接始终跟随认证生命周期，离开聊天页面仍维护有界实时窗口。

## 验证

### 补充：头像与图片呈现

2026-11-12：接收 sender.avatar，经 infrastructure 校验为 HTTP(S) 图片地址后进入领域模型；头像默认显示，通过群聊详情中“群聊名称”下方的共享 Switch 隐藏/显示，并由现有 ChatPreferencesPort 保存浏览器偏好。偏好状态由 ChatRealtimeProvider 独立持有，消息行和详情共用；偏好切换不改变消息实体或通信生命周期。无头像/失败时复用 MemberAvatar 姓名占位。

正文新增领域纯规则解析旧版 `[img]URL[/img]`，只允许无内嵌凭证的 HTTP(S) URL；不执行 HTML，也不将任意文本 URL 误识别为图片。单条消息最多渲染 12 张，其余标记保留原文，避免异常正文引发大量请求。feature 按正文版本 memo 解析，每张图有固定 4:3 预留区域、等比 contain、懒加载、加载中/失败与重试；不改变原图配色。图片加载不会改变行高；头像切换由同一虚拟列表处理尺寸变化，保持靠底跟随及回看行为。不新增依赖、上传或发送能力。

验证增加安全/畸形图片标记、混排与头像解码的单元测试，以及全部主题 × 明暗 × 桌面/375/390 的图片加载/成功/失败/重试、头像显隐与偏好恢复、草稿/连接不重置、无溢出和滚动位置验证。

单元测试覆盖重复 ID、同文不同 ID、撤回先到/重复撤回、撤回后重放、窗口上限、排序、畸形帧、重连与释放。浏览器合成协议覆盖全部主题 × 明暗 × 桌面/375/390，验证状态、重复投递、撤回、长列表滚动、草稿及无横向溢出。运行 npm run check。真实后端断线期间补拉、30 分钟稳定性和性能 p95 未测时必须明确披露。
