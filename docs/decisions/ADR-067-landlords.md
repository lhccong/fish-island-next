# ADR-067 斗地主迁移

状态：采用。日期：2026-11-14。

## 原因与范围

将旧版斗地主接入游戏目录、最近玩过、独立窗口及 `/game/landlords/:roomId?`，保留经典房间、准备、叫分、选牌出牌、不出、托管、房间聊天和结算。旧版癞子入口没有可用的后端房间实现（GameTypeEnum.isLandlords 仅认可经典），不将枚举存在当成功能可用。

## 方案与影响

domain/landlords 定义模型、纯牌面规则与通信端口；infrastructure/landlords 校验旧 game* 协议并复用 app 注入的账号唯一 WebSocket，不新建连接；features/landlords 分离对局控制器、手牌选择、房间聊天和排行榜。app 组装路由、账号和端口。排行榜沿用服务端 Top 50 快照，不伪造分页。

只按服务端状态确认操作；失败保留手牌与输入，等待确认期间禁止重复操作，超时可同步房间。重连重新加入以恢复私有手牌，卸载仅释放本地订阅，不隐式发离房命令。对局中显式离房先确认服务端托管后返回大厅，可从限制房间返回。

视觉使用现有 surface/canvas/text/muted/border/action/accent 变量，牌面红色使用 danger 并保留花色文字。桌面对手横排、中央出牌、底部手牌；手机手牌分行且每张至少 44px，操作自然换行。全部主题及明暗模式共用实例，切换不新增连接、请求或重置选牌和草稿。

## 替代方案

拒绝复制旧 Ant Design 页面、旧全局模型和专用 WebSocket；会破坏依赖方向并产生重复连接。暂不移植不完整的旧客户端牌型校验，以后端为出牌裁决来源，避免客户端拒绝服务端允许的牌型。

## 验证

2026-11-15 样式优化沿用既有语义 token：主题强调底色形成独立牌桌，对手信息取消重复卡片包裹；宽内容区聊天置于侧栏，窄内容区与手机重排为单列。出牌、准备、叫分及托管统一在手牌操作区，通过 ReactNode 插槽保留独立选牌状态。手牌增加角标和选中抬起反馈，减少动态效果时关闭过渡；不改变协议或新增业务状态。

执行 npm run check；协议测试覆盖私有手牌、部分状态、失败和隔离。浏览器用合成协议覆盖全部注册主题 × 明暗 × 1440/375/390 的大厅、失败、准备、叫分、出牌、托管、聊天、结算和离房，以及外观切换无额外请求。真实三账号联机需另行实测，不以夹具替代生产验证。
