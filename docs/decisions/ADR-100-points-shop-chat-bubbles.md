# ADR-100 积分商城聊天气泡

状态：采用。日期：2026-11-19。

## 决策与影响

- 商城新增「聊天气泡」分类。数据库初始化原有六款，各 300 积分。兑换成功起有效 30 天（30 × 24 小时），期间不重复扣费，过期可再兑换。账号可启用一款或恢复默认。
- 商品目录 `chat_bubble_product` 保存名称、价格和图片配置，与账号权益分表。管理员可在后端新增款式及调价。兑换事务同时锁定账号积分与商品当前价格，客户端带上已确认价格，报价变化则拒绝扣费。调价只影响后续兑换。
- 前端沿用积分商城领域端口、静默积分刷新与共享滚动/确认控件，沿用一次读取目录的接口。界面依据权益到期时间更新状态。
- HTTP 与旧 WebSocket 发送快照有效样式 ID 和图片配置，已发消息保留原样。历史、实时和发送回执共用消息协议；旧的内置快照仍使用随前端发布的图片。纯图片、奖励卡片、独立音乐卡片和系统事件沿用原呈现。
- 动态款使用管理员提供的公开 HTTPS 九宫格图片。商城和聊天共享渲染，暗夜可用单独图片，文字色依据主题或商品配置。切换主题、明暗和装扮无需重连，不新增消息订阅、每行计时或历史查询。

## 替代方案

复用永久道具或头像框表会混合权益语义；每次读历史查询当前穿戴会使过去的消息随装扮变化。本次采用独立限时权益表与消息快照。

## 验证与发布

先执行后端 SQL 迁移，再部署后端与前端。验证覆盖迁移保留已有权益和改过的售价、管理员权限、按数据库价格扣费、旧报价拒付、消息快照兼容和商城兑换。按全部主题 × 明亮/暗夜 × 桌面/375px/390px 检查新增款预览、聊天渲染及价格变化反馈，运行 `npm run check` 和后端相关测试。
