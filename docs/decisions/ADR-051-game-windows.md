# ADR-051：游戏独立浮窗

状态：采用。日期：2026-11-14。

## 原因与决定

游戏目录中的农场、人生重开和股市支持与阅读器类似的独立窗口。app 持有跨路由的已打开游戏与当前窗口选择，懒加载业务组件并注入原有服务；feature 不引用彼此或 app。既有游戏路由保留。

共享 FloatingWindow 基于现有 Radix Dialog 的非模态能力，统一标题、拖动、尺寸调整、最大化、收起、Esc 和焦点返回。一次展示一个游戏，底部继续入口切换已打开游戏；切换、收起和跨路由导航隐藏已挂载的内容，保留当前局、交易输入与滚动位置。关闭明确结束对应窗口。账号变更卸载受保护游戏，防止账号数据串用；匿名用户在窗口内使用既有登录弹窗。

手机沿用 760px 断点，窗口占据可用视口，固定标题和安全区，正文使用 reserved ScrollArea；桌面使用可调整尺寸窗口。不新增依赖、通信或缓存协议，不提供操作系统窗口或文档画中画。

## 影响与替代方案

只打开页面不能跨路由继续游戏；iframe 会复制认证、外观和请求生命周期，因此沿用 React 单一业务组件与 app 组合。每个游戏都保留独立挂载实例，但只显示一个窗口，避免手机多窗遮挡。

## 验证

执行 npm run check；浏览器覆盖注册表全部主题 × 明暗 × 桌面/375/390，验证三款游戏入口、loading/empty/error/success、登录、收起恢复、窗口切换、关闭、拖动/尺寸与最大化、Esc、焦点和滚动。未实测部分在交付中明确列出。

补充：保留目录原有整页入口；独立窗口入口统一使用带可访问名称的 44px 图标按钮，卡片右下角和三款游戏页头左侧均可用。WorkspaceLayout 通过可选 headerAction 组合入口，手机仅返回呈现时仍保留该操作，不复制外壳或业务逻辑。

游戏页返回入口补充：农场、人生重开、股市统一使用 WorkspaceLayout 的纯箭头图标链接，桌面与手机均可用，保留 title、可访问名称和至少 44px 命中范围；移除人生重开专有的文字返回按钮及样式。股市详情仍先返回股市概览，其余游戏页返回游戏目录。

## 聊天快捷入口与伙伴浮窗（2026-11-17）

用户要求移除聊天标题栏的椰树按钮及其打开我的小岛面板的行为，改为农场、宠物两个直接操作图标。app 组合统一的 44px 图标入口；WPS 桌面放在工作表工具区，手机仍放在聊天标题栏，标题允许收缩以保留触控范围。既有像素/经典侧栏保持原功能。

将 pet 加入现有游戏窗口标识，懒加载公开的 PetWorkspace，注入 petService、当前账号、积分及既有账号刷新回调。农场窗口内的伙伴入口也切换到伙伴浮窗，避免离开聊天。收起、切换保留挂载和表单；关闭释放对应内容，账号变化由既有账号边界释放。颜色与交互继承现有语义变量和共享 FloatingWindow/ScrollArea/Button，不新增依赖或业务协议。

替代方案：跳转 /pet 会打断聊天操作；另建宠物弹窗宿主会重复窗口及焦点管理。因此复用现有游戏宿主和营地业务组件。验证覆盖全部注册主题 × 明暗 × 桌面/375px/390px 的入口、两窗切换、收起恢复、关闭焦点、滚动、loading/empty/error/success，以及换肤不增加请求、不丢聊天草稿。

窗口内部跳转沿用可见的外部入口作为焦点返回目标；共享 FloatingWindow 卸载时读取最新的入口 ref，避免 WPS 与普通聊天布局切换后返回已卸载的旧按钮。

验收：Chromium 生产构建覆盖摸鱼岛、像素岛、WPS、微信、企业微信、飞书、钉钉全部七个主题 × 明暗 × 1440/375/390px，共 42 个组合。合成接口覆盖两个浮窗的加载、空数据、错误重试、成功操作、触屏与键盘滚动、gutter/滑轨、切换保留表单、Esc/关闭焦点、换肤不增加请求及聊天草稿保留；滚动断言等待到底后再返回顶部，微信明亮桌面组合已单独复验通过。截图检查覆盖微信桌面与手机明暗呈现。npm run check 通过（117 个测试文件、524 项单元测试）。未验证真实手机/软键盘、Safari/Firefox 和真实后端业务操作。
