# ADR-051：游戏独立浮窗

状态：采用。日期：2026-11-14。

## 原因与决定

游戏目录中的农场、人生重开和股市支持与阅读器类似的独立窗口。app 持有跨路由的已打开游戏与当前窗口选择，懒加载业务组件并注入原有服务；feature 不引用彼此或 app。既有游戏路由保留。

共享 FloatingWindow 基于现有 Radix Dialog 的非模态能力，统一标题、拖动、尺寸调整、最大化、收起、Esc 和焦点返回。一次展示一个游戏，底部继续入口切换已打开游戏；切换、收起和跨路由导航隐藏已挂载的内容，保留当前局、交易输入与滚动位置。关闭明确结束对应窗口。账号变更卸载受保护游戏，防止账号数据串用；匿名用户在窗口内使用既有登录弹窗。

手机沿用 760px 断点，窗口占据可用视口，固定标题和安全区，正文使用 reserved ScrollArea；桌面使用可调整尺寸窗口。不新增依赖、通信或缓存协议，不提供操作系统窗口或文档画中画。

## 影响与替代方案

只打开页面不能跨路由继续游戏；iframe 会复制认证、外观和请求生命周期，因此沿用 React 单一业务组件与 app 组合。每个游戏都保留独立挂载实例，但只显示一个窗口，避免手机多窗遮挡。

## 验证

执行 npm run check；浏览器覆盖注册表全部主题 × 明暗 × 桌面/375/390，验证三款游戏入口、loading/empty/error/success、登录、收起恢复、窗口切换、关闭、拖动/尺寸与最大化、Esc、焦点和滚动。未实测部分在交付中明确列出。

补充：保留目录原有整页入口；独立窗口入口统一使用带可访问名称的 44px 图标按钮，卡片右下角和三款游戏页头左侧均可用。WorkspaceLayout 通过可选 headerAction 组合入口，手机仅返回呈现时仍保留该操作，不复制外壳或业务逻辑。

游戏页返回入口补充：农场、人生重开、股市统一使用 WorkspaceLayout 的纯箭头图标链接，桌面与手机均可用，保留 title、可访问名称和至少 44px 命中范围；移除人生重开专有的文字返回按钮及样式。股市详情仍先返回股市概览，其余游戏页返回游戏目录。
