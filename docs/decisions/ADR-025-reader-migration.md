# ADR-025 阅读功能迁移

状态：采用。日期：2026-11-12。

后续修订：默认阅读凭证策略已由用户明确要求的 ADR-028 覆盖；下文保留首次迁移决策背景。

## 原因与范围

迁移旧 Reader 和 GlobalFloatingReader 的可用功能：本地书架、在线多源 SSE 搜索和分页、目录筛选/刷新/跳转、章节内容与进度、普通/全局悬浮阅读、拖动/尺寸恢复、点击穿透、工作伪装、紧急隐藏、画中画、阅读主题/自定义主题、排版与朗读。旧版本地导入和全文搜索存在占位：本次提供真实 TXT 导入与已缓存正文搜索，不宣称支持 EPUB/MOBI 或未下载章节的全文检索。

## 设计与影响

domain/reader 定义书籍、章节、设置和服务/存储端口；infrastructure/reader 实现旧 reader3 协议、fetch SSE 解码与本地存储校验；features/reader 持有独立控制器和阅读表现；app 注入适配器，发现栏添加 /reader，首次打开阅读器后挂载全局宿主，跨路由保留。跨模块通过 index.ts。

画中画通过 Document Picture-in-Picture API，将同一个阅读 DOM 宿主移入新窗口，不复制业务逻辑；同步样式和根 token，pagehide 返回原窗口，关闭/隐藏释放窗口和朗读。所有弹层仍在主文档打开，画中画发起设置/目录操作时先返回主窗口。无 API 时明确说明限制并保留页内悬浮窗，不伪造置顶能力。

不复制旧源码内的固定 accessToken。服务地址可配置；独立阅读凭证仅存内存，关闭或刷新后需重新输入，不能放浏览器环境变量或持久化。旧 reader3 协议通过 accessToken 查询参数传输，存在服务/代理日志记录风险；部署端宜提供同源代理，前端不记录完整请求 URL。保留旧书架/设置键的只读兼容解析，只保存白名单业务字段，不迁移 accessToken。存储失败显示提示，原数据保留。

阅读配色采用专属语义变量（默认值定义于 app 样式）；内置阅读主题按明暗分别配置，用户主动选择的自定义正文颜色不影响控件/弹层。主题与模式切换不重置阅读或发请求。手机使用全屏阅读和固定操作条，支持安全区；桌面支持受限拖动/调整尺寸。

## 替代方案

不复制旧版数千行 Ant Design 组件与手写 DOM 菜单；不新增 UI、状态或解析依赖。视频画中画无法提供可访问的文本交互，因此不作为文档画中画替代。全文搜索限于本地/已加载内容并明确标识。

## 验证

单元测试覆盖协议解码、SSE、旧数据兼容、TXT 分章、去重、请求竞态与失败。Playwright 使用合成内容覆盖全部内置主题 × 明暗 × 375/390/桌面，覆盖空书架、搜索 loading/error/empty/success、目录/正文/进度/设置/删除/跨路由与画中画生命周期；真实服务凭证与操作系统朗读、系统置顶另行标注实测范围。交付前执行 npm run check。
