# ADR-050 摸鱼农场迁移

状态：采用。日期：2026-11-14。

## 原因与方案

在游戏目录接入旧摸鱼岛农场 `/game/farm`，保留已有后端的积分、农场等级、作物、地块、浇水、好友与偷菜协议。旧 React 页面依赖 Ant Design 且业务、通信、样式混合，不能直接搬入；新增 domain/farm 纯模型和规则、infrastructure/farm 校验与 HTTP 适配、features/farm 控制器和呈现，由 app 注入账号级服务并懒加载鉴权页面。不新增依赖。

呈现采用原创像素农田、树木与木屋，参考掌机游戏菜单和田园游戏的信息层级，不引入第三方游戏素材。沿用 pet 场景语义 token；面板、按钮、弹窗使用工作台语义 token。桌面六列、手机三列，全部注册主题、明暗模式共享业务状态，切换外观不请求、不重挂载。

视觉修订：移除卡片式地块、白色信息栏和草地网格线。已开垦田地通过同一 SVG 土壤纹理连成连续耕地，仅绘制外侧田埂；按钮保持透明语义命中区，作物直接位于田垄上，名称和成熟反馈作为场景内文字。未开垦区域融入草地，以地号和锁标识。桌面六列、手机三列分别计算地形，无 CSS 缩放或旋转交互容器。新增 color-farm-soil/furrow/edge/soil-ink/grass-ink 明暗语义配色，仅用于原创场景，不影响主题动作色和第三方白名单。

## 影响与边界

像素菜单修订：好友面板采用原创木框/羊皮纸像素菜单，新增通用 color-pixel-paper/ink/muted/border/wood 系列明暗 token；局部语义变量映射让搜索、按钮、列表统一纸面配色，普通主操作仍使用当前主题 action。shared/ui/Select 新增可选 appearance="pixel"，触发器与 Portal 面板共用像素配色及直角，不改变默认外观或键盘/触屏行为。头像框改为像素方框，原图保持原貌；不新增字体和素材依赖。

反馈与好友修订：新增 shared/ui/Toast 无业务浮动提示，农场处理和结果通过 Portal 固定在页面顶部，不占正文高度，结果 5 秒后消失、处理状态保持；卸载清理计时器，主题切换不重挂载。错误详情与重试仍保留在原表单或加载错误区。好友弹窗参考旧版木质面板与列表结构，保留同玩/访客两项真实能力、等级排序、昵称搜索、可偷/冷却状态、本人底栏，头像只使用服务端安全 URL 并提供缺失/失败回退；不复制旧版未实现的微信、邀请和申请入口。Farmer/Friend/Visitor 模型补充头像与好友冷却字段，沿用已有协议，不新增网络调用或依赖。

紧凑呈现修订：农场名称、统计与刷新合并到紧凑页头，去掉英文标签和重复说明；桌面同排、窄屏两行，长昵称省略但保留完整可访问名称。场景最大内容宽度缩至 1040px，景观高度上限 120px，地块约 96px、作物 44px，手机保留至少 44px 触控范围。本人成熟地块点击或键盘激活直接调用既有收获用例，不再打开详情弹窗；未成熟、空地、锁地及好友操作保持原有流程。复用串行提交锁、处理状态、失败反馈和刷新失败保护，不修改服务端规则。

种植与收获支持单块和批量；浇水保留单块与批量独立结果、30 分钟冷却和每日每株 10 次限制，以后端为准；解锁展示服务端等级和费用并确认后提交。好友来自互相关注列表，偷菜只允许服务端 canSteal；访客记录支持已读。读请求取消、切换拜访身份丢弃旧响应；变更串行且只提交一次，失败保留界面并明确恢复方式。变更成功后刷新，刷新失败明确区分已提交与数据未同步，避免盲目重复变更。

旧界面未实现的商店、仓库、任务、微信好友和邀请入口不呈现为可用功能。伙伴养成复用已有 `/pet` 路由。现有列表为服务端完整数组协议，无客户端页码或加载更多按钮。

## 替代方案

复制旧页会引入第二套 UI、moment 与耦合状态，拒绝。只实现静态场景会伪装真实能力，拒绝。改后端游戏规则超出迁移范围。

## 验证

执行 npm run check；纯规则和协议测试覆盖边界、鉴权和变更请求。浏览器使用合成接口验证全部主题 × 明暗 × 1440/375/390，包括 loading/empty/error/success、播种、收获、浇水、解锁、好友切换、偷菜、访客已读、失败重试、焦点、滚动和无溢出。截图仅用于本次自查，验收后清理。真实账号与线上积分操作不使用合成测试替代，交付时说明实测边界。
