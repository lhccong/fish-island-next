# ADR-031 阅读状态布局与旧版设置呈现

状态：采用。日期：2026-11-12。

## 原因

切章的 loading/error 分支没有占据阅读器剩余弹性空间，使翻章栏停在中间；设置把旧版分组展开成一长列数字框和下拉框，偏离旧版 GlobalFloatingReader 的三页签、滑条和色卡设计。

## 决策

阅读状态区与正文共享伸展约束，翻章栏在 loading/empty/error/success 中固定在窗口底部，覆盖页内悬浮、全屏及画中画。保留请求、缓存与进度控制器，不因呈现切换重挂载业务宿主。

设置改为紧凑 Dialog，固定标题、阅读/主题/朗读三页签及底栏，正文通过统一 ScrollArea 独立滚动。按旧版使用字体选择、排版滑条、正文颜色选择、内置/自定义色卡、朗读开关/声音/语速音调音量。已有窗口、快捷键和服务配置收进折叠区，保留功能与草稿；所有页签内容保持挂载，切换不丢失编辑内容。采用可键盘切换的 tablist/tab/tabpanel 语义。

shared/ui 新增 Slider（完整定制原生 range 的 WebKit/Firefox 滑轨、滑块、焦点和禁用状态）与 Switch（原生 button 的 switch 语义），不新增依赖；Select 继续使用既有 Radix 包装。颜色选择使用带键盘支持的原生 details/button 与统一局部样式，保留六位颜色输入，不调用系统 color 弹窗。内置色块使用 reader 语义变量，用户自选正文颜色沿用已存在的自定义主题模型。

## 替代方案与验证

失败重试保存原请求的书籍、章节与刷新意图，不再从上一次已确认进度推断，防止切至下一章失败后重试上一章。颜色通过领域纯函数将三位/六位十六进制统一成六位小写形式；设置保存和存储解码共用，兼容生产 CSS 压缩后的色值及已保存的短色值，继续拒绝任意 CSS 表达式。

不复制旧 Ant Design 依赖或手写可点击 div，也不通过绝对定位覆盖正文来固定翻章栏。原生 range 保留键盘与触屏能力，并对两套浏览器绘制引擎完整设计外观。

验证全部内置主题 × 明暗 × 桌面/375px/390px：控制请求时机验证切章 loading、失败重试、空目录和成功后的翻章栏位置；检查三个设置页签、滑条键盘/触屏、色卡/自定义颜色、声音禁用、展开配置、关闭与焦点返回、持久化及画中画返回。执行 npm run check；不将移动视口测试冒充真机软键盘/系统声音实测。
