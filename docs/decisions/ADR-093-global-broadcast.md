# ADR-093 全体播报

状态：已采用。日期：2026-11-16。

## 原因与边界

从管理页发布即时文字播报，在线用户在所有路由顶部看到飘过的内容。功能名称和展示文案统一为“全体播报”，不绑定发布者身份，便于后续接入其他播报来源；当前发布入口沿用 Sa-Token 管理员权限及账号唯一 WebSocket，不新增依赖、数据库表或连接。

## 决策与影响

- 后端 POST `/api/admin/broadcast/publish` 仅管理员可调用，接收 `{content}`，去除首尾空白，限制 1–200 个 UTF-16 单元并拒绝不可见控制字符（换行、回车和 Tab 除外）；以纯文字发送。生成 UUID、毫秒时间，广播 `{type:"broadcast",data:{id,content,publishedAt}}`，返回 `true` 表示服务端已提交推送，不保证每个客户端收到。
- domain/broadcast 定义事件与只读订阅端口，infrastructure/broadcast 校验未知帧并分发；app 将 receive 接到既有实时扩展。features/broadcast 独立持有有界队列（20 条）和去重记录（最近 200 个 ID），账号变化清理，不将播报送入聊天消息 store。
- 管理入口 `/admin/broadcast` 复用 admin 端口和 shared/ui 控件，提交中禁用，失败保留草稿并明确提示，成功清空；外观不参与请求依赖。
- 全局宿主覆盖全部主题/模式/外壳和路由，顶部安全区浮层，仅本身接收指针。按用户参考图采用轻薄金色提示条，使用 warning/surface/text/border 组合局部配色，无重阴影；按内容自然宽度水平居中，仅在 640px 或视口可用宽度处收窄并触发溢出播放，不给短文固定长条。右上角 14px 关闭图标保留 44px 触控范围。
- 短文字完整静置 3 秒；溢出文字先停留 1.2 秒，再以 40px/s 向左滚动到末尾，末尾停留 1.2 秒，完整播完后退出，不强制 3 秒截止。减少动态效果时静态换行，按每秒 10 个字符估算阅读时间，至少 3 秒。
- 播放测量与计时由独立呈现 Hook 持有，不改变队列、端口或请求。计时仅绑定当前事件，排队不重启；主题/模式、视口或字体变化按同一开始时间调整剩余播放，不重置进度。手动关闭和卸载清理定时器、动画、测量与系统偏好订阅。读屏仅朗读独立通知，不把整页设为 live region。
- 仅实时在线用户接收，不保存或补播；队列满时忽略后续事件，防止长期堆积。重连不创建第二条连接；普通用户无法通过 HTTP 或 WS 发布此类消息。

## 替代方案

独立播报连接会重复认证和重连生命周期；将播报塞入聊天状态会使非聊天页面依赖消息列表；历史公告表与离线补发不属于本次即时播报需求。

## 2026-11-17：后端业务自动播报

原因：奖励与成就需要在已有全体播报区域即时展示，沿用现有协议、连接和呈现，不新增前端状态或依赖。

- 后端独立 AchievementBroadcastService 负责门槛、纯文字文案及提交后推送。业务服务仅在实际结算成功的分支调用；回滚不发送，自动推送失败不向业务抛出、不重试。管理员手动发布仍沿用原有失败反馈。
- 挖宝仅本次成功结算 10 积分时触发，重复 finish 或条件完成未命中不触发；爬塔仅胜利且通关层数 > 30 时触发；装备仅成功升到 > 10 级时触发，失败或未写入不触发。
- 词条刷新只统计本次重新生成的红词条；锁定保留的不算，一次刷新生成多条合并为一条播报，包含装备位置和新红词条数量。
- 按用户确认，打赏仅指网站赞助到账，不包含鱼小圈积分打赏或管理页手动维护打赏榜。支付回调以订单 ID + PENDING 条件原子更新抢占处理权，重复或并发回调未命中时不执行赞助结算及播报；原聊天室感谢消息保留。
- 文案只使用公开昵称、装备位置、层数及奖励/赞助金额，不公开留言、账号、支付单号或凭证；昵称清理控制字符并限制长度，空昵称回退为“岛民”。业务服务到播报服务的依赖不反向引用；延迟注入已有用户及推送服务，避免扩展既有依赖环。
- 仍为在线即时尽力推送，不保存补播；不保证进程在提交后退出时的投递，不引入 outbox 或自动无限重试。

替代方案：在事务内直接推送会出现回滚后的虚假成功；在积分通用入口推送会混淆奖励来源和阈值；前端根据返回值发起播报会被重复请求或客户端篡改影响，因此在后端成功分支统一触发。

验证：后端测试覆盖五项门槛、事务提交/回滚、失败隔离、重复结算、锁定红词条、支付重复回调及写入失败；执行前端 npm run check。本次不修改界面与播报协议，不将既有主题/明暗/视口验收当作本次实测，真实数据库、支付回调与跨账号 WS 联调须另行验证。

本次结果：后端离线 Maven 编译及 34 项针对性测试通过。前端 npm run check 首次被并行聊天改动的格式问题中断，该文件恢复规范后完整重跑通过，含 112 个文件、487 项单元测试和生产构建。现有播报浏览器回归覆盖 moyu-island、pixel-island、wps、wechat、wecom、feishu、dingtalk × light/dark × 1280px 桌面、375px/390px 触屏，包含发布中、失败重试、成功、空草稿、权限、跨路由接收、排队去重、长短文完整播放、减少动态效果、关闭及切换外观保留连接与状态。首轮 48 项中 47 项通过；375px 钉钉暗夜一项因动画期间两次边界测量差为 2.066px、超过 2px 阈值而失败，独立复验通过。已查看桌面暗夜、375px 明亮及 390px 像素暗夜实际截图。全部使用合成 HTTP/WS，未新增界面实现；真实数据库并发、支付平台回调、跨账号推送、实机及读屏尚未验证。
