# ADR-093 全体播报

状态：已采用。日期：2026-11-16。

## 原因与边界

从管理页发布即时文字播报，在线用户在所有路由顶部看到飘过的内容。功能名称和展示文案统一为“全体播报”，不绑定发布者身份，便于后续接入其他播报来源；当前发布入口沿用 Sa-Token 管理员权限及账号唯一 WebSocket，不新增依赖、数据库表或连接。

## 决策与影响

- 后端 POST `/api/admin/broadcast/publish` 仅管理员可调用，接收 `{content}`，去除首尾空白，限制 1–200 个 UTF-16 单元并拒绝不可见控制字符（换行、回车和 Tab 除外）；以纯文字发送。生成 UUID、毫秒时间，广播 `{type:"broadcast",data:{id,content,publishedAt}}`，返回 `true` 表示服务端已提交推送，不保证每个客户端收到。
- domain/broadcast 定义事件与只读订阅端口，infrastructure/broadcast 校验未知帧并分发；app 将 receive 接到既有实时扩展。features/broadcast 独立持有有界队列（20 条）和去重记录（最近 200 个 ID），账号变化清理，不将播报送入聊天消息 store。
- 管理入口 `/admin/broadcast` 复用 admin 端口和 shared/ui 控件，提交中禁用，失败保留草稿并明确提示，成功清空；外观不参与请求依赖。
- 全局宿主覆盖全部主题/模式/外壳和路由，顶部安全区浮层，仅本身接收指针。按用户参考图采用轻薄金色提示条，使用 warning/surface/text/border 组合局部配色，无重阴影；右上角 14px 关闭图标保留 44px 触控范围。
- 短文字完整静置 3 秒；溢出文字先停留 1.2 秒，再以 40px/s 向左滚动到末尾，末尾停留 1.2 秒，完整播完后退出，不强制 3 秒截止。减少动态效果时静态换行，按每秒 10 个字符估算阅读时间，至少 3 秒。
- 播放测量与计时由独立呈现 Hook 持有，不改变队列、端口或请求。计时仅绑定当前事件，排队不重启；主题/模式、视口或字体变化按同一开始时间调整剩余播放，不重置进度。手动关闭和卸载清理定时器、动画、测量与系统偏好订阅。读屏仅朗读独立通知，不把整页设为 live region。
- 仅实时在线用户接收，不保存或补播；队列满时忽略后续事件，防止长期堆积。重连不创建第二条连接；普通用户无法通过 HTTP 或 WS 发布此类消息。

## 替代方案

独立播报连接会重复认证和重连生命周期；将播报塞入聊天状态会使非聊天页面依赖消息列表；历史公告表与离线补发不属于本次即时播报需求。

## 验证

后端测试覆盖发布权限注解、有效发布、长度与空值校验、推送失败；前端测试覆盖协议校验、订阅释放、权限、发布结果、去重与队列。浏览器以合成 HTTP/WS 覆盖全部注册主题 × 明暗 × 桌面/375px/390px 的发布中、失败、成功、空草稿、手动关闭及跨路由接收，验证布局、触屏、减少动态效果和 2999ms/3000ms 自动退出边界；外观切换保留草稿、队列和剩余计时。执行 npm run check；实际部署服务的跨客户端联调另行记录。
