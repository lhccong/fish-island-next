# ADR-081 摸鱼论坛迁移

状态：采用。日期：2026-11-15。

## 原因与决策

发现区在伙伴和游戏之间加入摸鱼论坛，保留旧 /post、/post/create、/post/:id、/post/edit/:id 路径。按 domain/forum → infrastructure/forum → app 注入 features/forum 分层，不复制旧 Ant Design 页面。公开阅读，写操作由登录态及服务端权限共同校验。

迁移最新/热门/精华/本人/收藏、搜索、标签、正文、发布编辑、图片上传、点赞收藏、加精删除、评论及回复。所有分页使用共享 InfiniteScroll，重复/空页停止、失败手动重试、账号/筛选切换取消旧请求。列表在详情打开期间保留挂载和滚动位置；输入与评论分别拥有草稿。

新增唯一 Markdown 解析依赖 marked（MIT），仅论坛异步块加载；现有 DOMPurify 统一清理 Markdown 生成的 HTML，移除脚本、内联样式及事件，只允许安全链接和图片。替代方案是复制旧 Vditor/ReactMarkdown/高亮依赖链，体积与双模式适配代价更高；纯文本则不能兼容旧帖。编辑采用 Markdown 文本与预览，不增加第二套 UI 或状态体系。

## 影响与验证

所有注册主题、明暗与桌面/375px/390px 复用同一组件；手机单栏、44px 触控，桌面保留阅读宽度。使用语义背景/文字/边框/动作色；弹窗 reserved ScrollArea。外观切换不属于请求依赖，不清空草稿或分页。

首页依据旧版论坛布局：左列标签/折叠搜索卡片、五项分类页签和帖子列表，右列热门话题与论坛公告。使用容器宽度适配工作台侧栏及 WPS 外壳，窄容器将右栏下移，手机页签换行而不缩小点击范围；热门话题是前十名固定榜单，不作为分页列表。

帖子列表沿用旧版作者及管理员权限：编辑、管理员设为精华/取消精华、删除收拢至每行 44px 三点菜单，使用 shared/ui/DropdownMenu；删除通过 Dialog 二次确认，取消和 Esc 恢复三点入口焦点。服务端明确允许管理员编辑他人帖子，因此编辑路由使用相同权限判断。删除仅移除当前记录，保留其余数据和滚动位置。评论兼容旧 [img] 标记，并保留上传与粘贴图片入口。

运行 npm run check、协议和 HTML 安全测试、浏览器状态/分页/写入失败重试/权限测试及全部主题模式视口矩阵。真实生产写入需要实际账号，测试只使用合成夹具，不在源码或日志保存凭证。旧版点赞抽奖和兑奖入口在本次一并以独立面板迁移，兑奖内容仅在当前面板显示，不记录日志。
