# 初始化验证记录

日期：2026-11-11。环境：Windows，Node.js 20.20.2，npm 10.8.2。

## 已验证

- `npm ci`：按精确依赖和锁文件重新安装成功，没有强制忽略依赖兼容性。
- `npm run check`：格式、ESLint 零警告、严格类型、2 个皮肤契约测试、生产构建通过。
- `PLAYWRIGHT_CHANNEL=chrome` 下运行 `npm run test:e2e`：桌面与 Pixel 7 模拟视口共 2 个流程通过。使用本机安装的 Chrome，CI 配置仍使用 Playwright 管理的 Chromium。
- 浏览器流程验证：首页、切换配色及实际 CSS 变量、按钮状态、弹窗打开、Escape 关闭、焦点归还、无页面异常与横向溢出。
- 已检查桌面与窄屏截图，输出位于忽略提交的 `test-results/`，再次运行浏览器测试可重建。
- 初始化页构建产物：单个 JS 块约 308.04kB / gzip 98.98kB，CSS 6.24kB / gzip 1.85kB。这是初始化页面数据，不能作为未来聊天入口结论。

## 未验证与范围限制

本轮没有登录、后端、真实消息、完整外壳或皮肤导入，因此未测量聊天输入延迟、滚动、丢包、历史锚定或长期内存。性能文档中的指标全部是未来目标。

浏览器 smoke 使用开发服务器，未将其计时作为性能结果。Git 仓库已初始化，未创建提交、远程仓库或部署。
